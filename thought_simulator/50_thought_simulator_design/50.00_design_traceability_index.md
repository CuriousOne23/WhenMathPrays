## Change Control

This index is a release-coupled governance artifact. It must be updated in the same change set whenever any file in thought_simulator/50_thought_simulator_design/ is added, renamed, deleted, or materially changed. Updates must include path corrections, row additions or removals, and any required anchor updates so cross-layer mappings remain canonical and auditable.

## Deterministic Update Rules

Rows in the mapping table must remain alphabetically sorted by Macro / Domain (case-insensitive lexical order). Sorting and comparisons must use deterministic ordering only; no timestamp, filesystem order, or locale-dependent ordering is allowed.

## CI Enforcement Rules

CI must fail if this index is out of sync with thought_simulator/50_thought_simulator_design/ contents. CI failure conditions include:

- Any 50-series design file exists in the directory but is missing from the table.
- Any table row references a non-existent 50-series file.
- Any file is renamed without updating the table.
- Any file is deleted without updating the table.
