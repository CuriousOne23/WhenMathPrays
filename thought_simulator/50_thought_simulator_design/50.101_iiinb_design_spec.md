## 1. Purpose and Scope

The **Input Inference/Repair Basin (IIInB)** implements stage wire `input_semantic_repair` on the Track H intake path. It is responsible for:

- consuming versioned InB handoffs (`inb_to_iiinb_v1`)
- `profile_enabled` gating with zero semantic effect when disabled
- read-only USP snapshot load pinned by content-addressed `usp_version_ref`
- profile-gated pattern→expansion repair with APPLIED/ESCALATED outcomes (escalate without guess)
- intake-bound TP field writes only; envelope guard on Pipeline B fields
- one `iiinb_repair_record` per repair pass in conversation-scoped audit storage
- apply cap (16) and segment cap (32) with truncate-with-audit
- non-blocking escalation references to routing/CIL
- deterministic replay digest and diagnostic export

IIInB **does not**:

- perform InB surface canonicalization
- mutate `exec_plan`, `exec_trace`, `semantic_core`, or `TP.TR` on repair paths (envelope guard)
- participate in RB→OB→TR→TB chain
- implement CIL→UPI FIFO wire (owned by [50.33](50.33_cil_design_support.md) / [50.103](50.103_upi_design_spec.md))
- resolve MI_VAGUE/MI_INCOMP without dedicated messy-input fixtures (W1 residual)

**Pipeline ordering (normative):** `InB → IIInB → RB` (HLR-20.101-003). When `profile_enabled = false`, stage sequence jumps `inb_surface_norm → routing` with no USP load and no repair record.

**Out of scope:** CIL→UPI orchestration (50.33/50.103), IMR same-cycle isolation, integrated strip-replay compose (W5), parent 20.10/20.30 cross-check.

## 3. Contracts and Invariants

**Core invariants (normative, from 10.50.101 + 30.101 evidence)**

- **Profile gate (HLR-001–004):** When `profile_enabled = false`, skip repair with zero semantic effect; no `iiinb_repair_record`; ordering preserved outside RB→OB→TR→TB chain.
- **InB handoff validation (HLR-10.50.101-001):** Reject handoffs failing InB accept contract with `INB_HANDOFF_REJECTED`; no USP apply on reject path.
- **Read-only USP (HLR-005–012):** Load USP via immutable snapshot; pin `usp_version_ref` on every repair record; ACTIVE rule precedence; bounded pattern→expansion; APPLIED or ESCALATED — never guess.
- **Intake-bound writes (HLR-014–018):** TP writes limited to intake-bound fields; `semantic_core` and `TP.TR` guarded.
- **Envelope guard 024a (HLR-024):** On repair path, `exec_plan` and `exec_trace` MUST remain unchanged (evidence: `positive_pipeline_b_envelope_unchanged`). **HLR-024 split:** 024a (positive guard) is fully implemented in 30.101; 024b (negative `FAIL_ENVELOPE` verdicts) is exercised only in [30.207](../../30_verification/30.207_replay_prototypes/) strip/regen scope and deferred to W5 program closure.
- **Caps (HLR-019–020):** Apply cap 16; segment cap 32; truncate-with-audit under overflow.
- **Audit record (HLR-016, -022):** Exactly one `iiinb_repair_record` per repair pass; append to `audit_records` (not `exec_trace`).
- **Deterministic replay (HLR-021, -026–028):** Identical InB output + `usp_version_ref` + profile state → identical repair tags, escalation refs, and `state_digest`.
- **Reason codes (HLR-017):** Fixed `REASON_CODES` registry with assert-on-emission.
- **TCU cost (HLR-021):** Repair record carries TCU cost attribution per 20.101.

**`iiinb_repair_record` contract (normative shape)**

- `repair_outcome`: `APPLIED` | `ESCALATED`
- `usp_version_ref`: content-addressed pin
- `applied_rule_count`, `cap_status`, `segment_count`
- `escalation_refs`: non-blocking routing/CIL references when ESCALATED
- `reason_codes`: registry members only

**Handoff consumption**

- Upstream schema: `inb_to_iiinb_v1` (HLR-10.50.101-002)
- Required accept fields from InB handoff; missing/invalid → `INB_HANDOFF_REJECTED`

## 4. Operation Flow and State Transitions

**Track H repair flow**

1. Receive InB handoff (`inb_to_iiinb_v1`)
2. Validate handoff accept contract → reject with `INB_HANDOFF_REJECTED` if invalid
3. If `profile_enabled = false`: emit skip output, jump to routing stage — end
4. Load read-only `UspSnapshot` pinned by `usp_version_ref`
5. Apply ACTIVE rules with apply/segment caps
6. On match: APPLIED with intake-bound TP writes
7. On no match / policy block: ESCALATED with escalation refs (no guess expansion)
8. Append one `iiinb_repair_record` to `audit_records`
9. Enforce envelope guard before return
10. Hand off toward RB per `InB → IIInB → RB` ordering

**Envelope guard (024a)**

- Before and after repair: assert `semantic_core`, `TP.TR`, `exec_plan`, `exec_trace` unchanged on repair path
- Negative `FAIL_ENVELOPE` verdicts (024b) exercised in 30.207 strip/regen scope — not IIInB isolated harness

**Stage constants (reference impl)**

- `INTAKE_PATH_STAGES`: includes `inb_surface_norm`, `input_semantic_repair`, `routing`
- `BASIN_CHAIN_STAGES`: RB→OB→TR→TB — IIInB explicitly excluded

## 5. Data and IO Contract

**Input**

- InB handoff payload (`inb_to_iiinb_v1`)
- `profile_enabled`: bool
- `usp_snapshot`: read-only USP (when profile enabled)
- TP envelope with `semantic_core`, `TP.TR`, `exec_plan`, `exec_trace` (guarded)

**Output**

- `skipped`: bool (true when profile disabled)
- `usp_loaded`: bool
- `usp_version_ref`: string (pinned digest)
- `iiinb_repair_record`: object | null
- `audit_records`: list (append-only per pass)
- `reason_codes`: list
- `state_digest`: replay pin
- `repair_outcome`: `APPLIED` | `ESCALATED` | null

**Diagnostic export (`export_repair_diagnostics`)**

- Deterministic sorted-key JSON over repair records
- Order-independent of input list ordering (`positive_diagnostic_export_ordering`)

**Digest input (replay contract)**

- `{record, tp_intake_fields}` — repair record plus intake-bound TP field snapshot

## 6. Observability and Logging

IIInB SHALL emit:

- `iiinb_repair_record` with full audit fields per pass
- `usp_version_ref` on output and record (pinning evidence)
- `reason_codes` including `INB_HANDOFF_REJECTED` on upstream reject
- `export_repair_diagnostics` with stable ordering
- `state_digest` for replay comparability
- escalation refs (non-blocking) on ESCALATED path

Envelope guard violations MUST be detectable in verification harness; positive guard evidenced in 30.101; negative envelope replay verdicts deferred to 30.207.
