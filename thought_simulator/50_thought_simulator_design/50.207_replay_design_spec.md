## 1. Purpose and Scope

The **Execution Replay** subsystem at component `.207` provides W1 GATE-A verification for Track H intake replay and E1 strip/regen scaffold. It is responsible for:

- runnable REPLAY_CLASS_7 fixtures C7-A through C7-E with falsifiable assertions
- deterministic canonical JSON digest and replay diagnostic export ordering
- live compose of upstream InB (30.220) and IIInB (30.230) on intake path scenarios
- E1 strip of Pipeline B envelopes (`exec_plan`, `exec_trace`) while retaining `semantic_core`
- regen input validation and fixture-root merge for omitted fields
- B envelope field guards (`lane_id`, `tp_id` forbidden reads)
- `b_regeneration_equivalent` scaffold (input validation; E2 execution deferred)
- verdict taxonomy: `PASS`, `FAIL_REGEN_INPUT`, `FAIL_REGEN_FORBIDDEN_READ`

**W1 scope boundary:** Class 7 intake-path replay and E1 strip/regen **scaffold** — not full dual-pipeline PoC (Classes 1–6, live E2, stale-epoch negatives, YAML golden import).

**W1 Class 7 rationale:** Class 7 is the only replay class required for W1 because it exercises the full Track H intake path (InB → IIInB → routing) without requiring Pipeline B execution or live UPI/GB wire.

**Out of scope (deferred)**

- Classes 2–6 unified runners (W5)
- Live `b_regeneration_equivalent` E2 execution (W5)
- `REGEN_STALE_EPOCH` / commit-mismatch negatives (W5)
- Live UPI/GB wire for C7-D/E (W2) — W1 uses simulated commit outcomes
- YAML golden file import (W5)
- `FAIL_ENVELOPE` negative replay (024b) — named in 30.240 delta; full closure W5

## 4. Operation Flow and State Transitions

**Class 7 runner flow**

1. Load fixture definition (C7-A..E)
2. Compose live InB → IIInB for B/C paths (or skip for A)
3. Inject simulated UPI/GB outcomes for D/E only (W1)
4. Execute assertions; record verdict `PASS` or failure class
5. Export replay diagnostics with digest
6. On suite rerun: assertion maps MUST match (determinism)

**E1 strip/replay flow**

1. Load full trace with Pipeline B envelopes
2. `strip_b_envelopes` → stripped trace
3. Assert `semantic_core` unchanged
4. Validate regen input against stripped trace + fixture root
5. Emit verdict (`PASS`, `FAIL_REGEN_INPUT`, `FAIL_REGEN_FORBIDDEN_READ`)
6. E2 live regen execution — deferred W5

**Verdict taxonomy (W1 exercised)**

| Verdict | Meaning |
|---------|---------|
| `PASS` | All assertions satisfied |
| `FAIL_REGEN_INPUT` | Incomplete regeneration input |
| `FAIL_REGEN_FORBIDDEN_READ` | Forbidden lane/TP read in regen path |

Deferred: `FAIL_REGEN_DIFF`, `FAIL_ENVELOPE`, `REGEN_STALE_EPOCH` — W5 program scope.

## 5. Data and IO Contract

**Fixture record shape (normative skeleton)**

- `sub_id`: `C7-A` | `C7-B` | `C7-C` | `C7-D` | `C7-E`
- `fixture_id`: REPLAY_CLASS_7 identifier
- `assertions`: falsifiable predicate map
- `mode`: `live` | `simulated_upi_gb`

**Strip I/O**

- Input: full trace with `exec_plan`, `exec_trace`, `semantic_core`
- Output: stripped trace without B envelopes; `semantic_core` preserved

**Regen input**

- Merged from stripped trace + fixture root for omitted fields
- Validation rejects incomplete or forbidden-read paths deterministically

**Replay diagnostic export**

- Sorted-key canonical JSON
- Assertion map + digest for tamper/replay detection

## 6. Observability and Logging

Replay host SHALL emit:

- per-fixture assertion results and verdict
- suite-level deterministic assertion map (rerun comparable)
- strip diff artifacts showing removed B envelope keys only
- regen validation diagnostics with stable reason codes
- compose lineage referencing 30.220/30.230 run artifacts

C7-D/E logs MUST flag simulated vs live UPI/GB wire explicitly in W1 artifacts. C7-D/E use simulated UPI/GB outcomes in W1; live wire deferred to W2.
