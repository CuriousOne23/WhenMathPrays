## 1. Design Decision: Canonical Signal Packet Format

**Decision:**  
All Tier 1 Signal Monitors SHALL emit signals using a standardized, deterministic `SignalPacket` structure.

**Rationale:**
- Provides clear, typed communication between tiers.
- Enables deterministic behavior, logging, and replayability.
- Supports future extensibility.

## 2. Signal Packet Definition

```python
@dataclass
class SignalPacket:
    monitor_id: str           # e.g., "DriftMonitor"
    signal_type: str          # "drift", "oscillation", "contradiction", "population"
    value: float              # Normalized magnitude (0.0 - 1.0)
    severity: float           # Severity of the condition (usually = value)
    timestamp: int            # Cycle number
    metadata: Dict[str, Any]  # Optional, kept minimal and non-semantic
