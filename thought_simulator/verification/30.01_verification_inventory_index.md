## Index maintenance and CI

Update this index in the **same change set** when:

- A `30.*_prototypes/` (or `30.*_*/`) module folder is **added, renamed, or removed**
- Capsule or delta **paths** change
- Promotion **status** changes (seeded → promoted → approved)
- Optional **40 source** or **10/50 cross-links** change

Do **not** update this index for capsule/delta **content-only** edits, new harness scenarios, or JSON artifact content changes within an existing module.

**Local / CI checks** (non-blocking warnings):

| Script | Compares |
|--------|----------|
| `scripts/validate_30_inventory_index.py` | `30.*` module directories ↔ this table |
| `scripts/validate_30_10_50_pairing.py` | `promoted` / `approved` rows ↔ `10.50.{band}_*.md` in `10_thought_simulator_req/50_design/` |

Pairing rule is **one-way** (30 → 10.50 only). `seeded` rows are excluded. Orphan `10.50` files without a 30 module are not reported. See [30.00](30.00_verification_user_guide.md) § Promotion completeness.
