# 70.60 Benchmark Reporting Format

## Purpose
Defines required report schema for benchmark runs.

## Required Fields
- benchmark_family
- suite_id
- fixture_version
- execution_signature
- comparator_definition
- pass_fail_outcome
- deterministic_replay_check
- policy_reason_code_summary
- falsification_result
- artifact_links

## Reporting Rules
- report all required fields for every run
- include deterministic replay verification result
- include falsification checks and outcomes
- include run artifact references sufficient for audit
