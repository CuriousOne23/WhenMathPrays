# 70.40 Benchmark Specification

## Purpose
Defines benchmark families and deterministic measurement protocol for TS evaluation.

## Benchmark Families
- deterministic replay benchmark
- policy enforcement benchmark
- long-horizon reliability benchmark
- bounded failure benchmark
- meaningful cognitive step benchmark
- TCU efficiency benchmark

## Protocol Requirements
- identical fixture sets per comparator run
- fixed execution signatures
- full-system accounting for measured outcomes
- explicit falsification criteria per benchmark family
