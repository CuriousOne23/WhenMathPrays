# 60 Review File Numbering Convention

This folder contains architecture-review artifacts in project-number order.

## Core Sequence

- `60.10_architectual_draft_review.md`
  - Primary review draft (date in header).
- `60.20_architectual_draft_review_answers.md`
  - Structured answers to all questions in the draft.
- `60.30_architectual_draft_review_evidence_matrix.md`
  - Evidence status mapping and proof gaps.
- `60.40_architectual_draft_review_derisk_plan.md`
  - Actionable de-risking roadmap and experiment plan.
- `60.50_architectual_draft_review_decision_log.md`
  - Decisions, confidence shifts, and stop/pivot criteria updates.

## Notes

- Keep numbering stable; increment by `10` for new artifact classes.
- Keep filenames stable; record dates in file headers and decision entries.
- Preserve `architectual` spelling for all files in this sequence for consistency.
