# 60.00 Review File Numbering Convention

This folder supports multiple independent review bundles.

## Grouped Model

- Group folder: `60.XXXX_<review_slug>/`
  - `XXXX` is a four-digit review group identifier (for example: `0100`, `0200`, `0300`).
- Artifact files inside each group: `60.XXXX.YY_<review_slug>_<artifact>.md`
  - `YY` increments by `10` for stable artifact classes (`10`, `20`, `30`, `40`, `50`, ...).

## Current Review Bundle (0100)

- `60.0100_architectual_draft_review/60.0100.10_architectual_draft_review.md`
  - Primary review draft (date in header).
- `60.0100_architectual_draft_review/60.0100.20_architectual_draft_review_answers.md`
  - Structured answers to all questions in the draft.
- `60.0100_architectual_draft_review/60.0100.30_architectual_draft_review_evidence_matrix.md`
  - Evidence status mapping and proof gaps.
- `60.0100_architectual_draft_review/60.0100.40_architectual_draft_review_derisk_plan.md`
  - Actionable de-risking roadmap and experiment plan.
- `60.0100_architectual_draft_review/60.0100.50_architectual_draft_review_decision_log.md`
  - Decisions, confidence shifts, and stop/pivot criteria updates.

## Notes

- Keep group identifiers stable once assigned.
- Keep `YY` increments stable across groups so artifact semantics stay consistent.
- Preserve `architectual` spelling for this sequence for continuity with existing artifacts.
