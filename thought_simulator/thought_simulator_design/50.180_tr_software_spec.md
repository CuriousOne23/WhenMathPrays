## 1. Purpose and Scope

The Thought Router (TR) subsystem supplies **semantic routing state** for Thought Packets: primarily `TP.TR` and the `tr_needs_update` stale/fresh gate in production TS.

This design specification covers:

- **Implemented proxy (Phase B):** deterministic standalone `route()` for basin selection and ΔH% tagging — evidence in 30.180 / 40.240.
- **Target integration (Phase C / production):** Semantic Interpretation Flow per `20.37` — not yet verified; architectural contracts in §3.2 and §4.2 only.

TR does **not** perform OB evidence extraction, DCB trajectory observation, or GB mutation. TR routine is the **exclusive writer** of `TP.TR` in the target architecture.

## 3. Contracts and Invariants

### 3.1 Proxy contracts (implemented — HLR-20.437-*)

- **Determinism:** Identical `input_message` SHALL yield identical output dict (route, priority, delta_h or error).
- **Basin selection:** Keyword proxy maps content to `math_basin`, `thought_basin`, or `general_basin` per 10.50.180.TR.20.
- **ΔH% tagging:** Fixed values per route class: 0.15 / 0.08 / 0.05 per 10.50.180.TR.30.
- **Error path:** Missing/empty payload (`{}`, null coerced to `{}`) SHALL return `{"route": "error", "reason": "invalid_input"}` with no `delta_h` and no side effects.
- **Separation:** Proxy SHALL NOT mutate TP/MTP, write `TP.TR`, or set `tr_needs_update`.
- **Statelessness:** No global mutable routing state between calls.

### 3.2 Target integration contracts (architectural — not proxy-proven)

Authoritative detail in `20.37`; summary invariants:

- **OB:** Writes TR-input to `TP.input_fields`; may set `tr_needs_update = true`; never writes `TP.TR`.
- **DCB:** Observes trajectory after OB; ephemeral events; does not set `tr_needs_update`; not consumed by RB.
- **RB:** Routes to TR routine iff `tr_needs_update = true`; consumes committed `TP.TR` for downstream routing.
- **TR routine:** Exclusive `TP.TR` writer; reads TR-input, MTP (read-only), optional DCB events; clears `tr_needs_update` only on successful commit.
- **Failure:** TR reject/error leaves `tr_needs_update = true`.

### 3.3 TR field contract (target — 20.37 §6)

`TP.TR` SHALL include: stance, intent, affect, epistemic_shading, tension, politeness, commitment, reservation, logical_structure, semantic_deltaH, lineage_additions, routing_semantics. Population rules belong in 50-series Phase C / reference algorithms (20.35), not in this proxy spec.

## 4. Operation Flow and State Transitions

### 4.1 Proxy operation flow (implemented)

```text
harness / caller → route(input_message) → {route, priority, delta_h} | {route: error, reason}
```

No TP lifecycle participation in the proxy build.

### 4.2 Target integration flow (20.37 — Phase C)

```text
RB → OB → [DCB observes] → RB checks tr_needs_update
  → (if true) TR routine → RB
```

Semantic path: OB TR-input + stale flag; TR derive/commit/clear. Geometric path: DCB hints consumed only when TR runs.

## 5. Data and IO Contract

### 5.1 Proxy IO (implemented)

**Inbound**

```python
input_message: dict  # requires key "content": str for success paths
```

**Outbound (success)**

```python
{
  "route": "math_basin" | "thought_basin" | "general_basin",
  "priority": "high" | "medium" | "low",
  "delta_h": float  # 0.15 | 0.08 | 0.05
}
```

**Outbound (error)**

```python
{"route": "error", "reason": "invalid_input"}
```

### 5.2 Target IO (integration — not implemented in 40.240)

- Inputs: `TP.input_fields`, TP snapshot, MTP snapshot (read-only), ephemeral DCB event list when enabled.
- Outputs: atomic `TP.TR` write; `tr_needs_update` clear on success only.
- Serialization and schema versioning: per 20.37, 20.39, 20.95 when Phase C is specified.

### 5.3 Harness artifact schema (verification)

Promoted JSON includes: `run_id`, `timestamp`, `evidence_scope: proxy_only`, `hlr_proven`, `hlr_deferred`, `phase`, `total_tests`, `passed_tests`, `results[]` with per-TC pass flags.

## 6. Observability and Logging

### 6.1 Proxy

- Harness records per-TC input, output, pass/fail in JSON artifacts.
- No TP audit fields written by proxy.

### 6.2 Target

- TR routine commit SHALL be logged in deterministic replay artifacts per 20.37 §9–12.
- Failed TR paths SHALL preserve stale flag and emit reject-with-audit behavior.
