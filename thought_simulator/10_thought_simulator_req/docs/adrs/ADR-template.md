# ADR Template

## Title

Short, decision-focused title.

## ADR ID

Assigned at creation time (for example: ADR-YYYYMMDD-XXX).

## Status

One of: proposed, accepted, superseded.

## Context

Describe the problem framing, constraints, and relevant canonical background needed to understand the decision.

## Decision

State the canonical decision being made, in direct and testable prose.

## Alternatives Considered

List meaningful alternatives, including rejected options, and summarize why they were not selected.

## Rationale

Explain why this decision is correct now, given current evidence, risks, and priorities.

## Consequences

Document expected effects:

- Positive outcomes
- Negative tradeoffs
- Follow-on impacts and required future work

## Canonical Impact

Describe what changes in canonical layers only:

- `10_thought_simulator_req`
- `50_thought_simulator_design`
- `30_verification`

Do not define exploratory layers as authoritative dependencies.

## Verification Implications

Describe how canonical verification evidence will be updated to support this decision and how existing evidence is affected.

## Supersession

If this ADR supersedes an earlier ADR, identify it and summarize what changed and why.

If not applicable, state: None.

## References

Optional narrative references for human context.

References are explanatory only and do not create formal traceability edges.
