# 10.40_Scheduler Requirements (Canonical)

## 1. Purpose

This document is the canonical scheduler requirement anchor for promotion-governed tick scheduling behavior.

## 2. Canonical HLR Set

- `HLR-20.440-001`: Scheduler selection order must remain deterministic and replayable for identical inputs and event sequences.
- `HLR-20.440-002`: Scheduler fairness policy must provide bounded progress for active ThoughtPoints and prevent starvation under configured limits.
- `HLR-20.440-003`: Scheduler contract validation must reject malformed inputs that could break deterministic execution (including empty TP IDs, non-monotonic ticks, and unsupported policy values).

## 3. Canonical Scope

This canonical scheduler requirement anchor governs:

- deterministic per-tick selection behavior
- fairness and starvation-prevention obligations
- scheduler input validation and negative-path enforcement
- replay-safe scheduler observability evidence
