**Status:** Approved — W1 GATE-A ready (CP review 2026-06-08; 30.207 / 40.207 evidence)

## 1. Purpose

Canonical realization anchor for **Track H intake replay and E1 strip/regen scaffold** at GATE-A scope: `REPLAY_CLASS_7` fixtures C7-A..E, deterministic strip of Pipeline B envelopes, regen input validation, and intake-path compose with live InB/IIInB. Translates [20.36](../../20_requirements/20.36_canonical_end_to_end_trace.md) §9 Class 7 and [20.207](../../20_requirements/20.207_execution_replay_specification.md) E1 obligations verified in 30.207.

**Scope boundary:** This anchor covers W1 intake-path replay and E1 strip/regen **scaffold** — not full dual-pipeline PoC closure (Classes 1–6, live E2 execution — W5).

**W1 Class 7 rationale:** Class 7 is the only replay class required for W1 because it exercises the full Track H intake path (InB → IIInB → routing) without requiring Pipeline B execution or live UPI/GB wire.

**C7-D/E note:** C7-D (cross-turn USP) and C7-E (GB veto) use **simulated** UPI/GB commit outcomes in W1; live wire deferred to W2 per [40.510](../../40_thought_simulator_playground/40.510_refactor.md) (rows 40.103, 40.36).
