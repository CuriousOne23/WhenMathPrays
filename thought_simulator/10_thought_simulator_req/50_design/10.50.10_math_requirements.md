# 10.50.10_Math Requirements (Canonical)

## 1. Purpose

This document is the canonical requirement anchor for deterministic math contracts promoted from `40.330_math_prototypes`.

## 2. Canonical HLR Set

- `HLR-20.410-001`: Math projection operations must remain deterministic and replayable for equivalent vector and matrix inputs.
- `HLR-20.410-002`: Distance calculations must remain deterministic and schema-stable for equivalent vector pairs.
- `HLR-20.410-003`: Math contract validation must reject dimension mismatches and non-finite numeric inputs.

## 3. Canonical Scope

This canonical math requirement anchor governs:

- deterministic projection and distance output behavior
- numeric input validation and negative-path rejection
- replay-safe digest-bearing math evidence outputs

## 10.50.10.TCU Math CPU Execution Cycle Requirements

**Anchor authority:**
- 20.150_tcu_budgeting_requirements.md
- 10.10.10_system_architecture.md

### 10.50.10.TCU.10 Bounded per-tick cost
- Requirement ID: 10.50.10.TCU.10
- Statement: For any tick with fixed input cardinality N and fixed configuration, the subsystem
  MUST complete its work within a bounded number of CPU cycles C_max(math) per tick phase,
  as constrained by 20.150. No unbounded or data-dependent worst-case growth is permitted.

### 10.50.10.TCU.20 Deterministic behavior under fixed conditions
- Requirement ID: 10.50.10.TCU.20
- Statement: For fixed seed, fixed input cardinality N, fixed configuration, and fixed hardware/runtime profile,
  the subsystem MUST exhibit deterministic CPU cycle consumption within
  [C_min(math), C_max(math)] for the same scenario ID, as defined in 20.150.

### 10.50.10.TCU.30 Provisional vs measured budgets (promotion-controlled)
- Requirement ID: 10.50.10.TCU.30
- Statement: The subsystem MUST maintain two distinct TCU budgets:
  - provisional-budget(math): design-time estimate used for planning and scheduling.
  - measured-budget(math): empirically measured values produced by 40_playground harnesses and verified in 30_verification capsules.
  These MUST NOT be conflated in normative documents.
  measured-budget(math) MAY ONLY be updated through promotion-controlled evidence from 30.

### 10.50.10.TCU.40 Tick budget share
- Requirement ID: 10.50.10.TCU.40
- Statement: The subsystem MUST declare its target percentage of the global tick budget
  (per 20.150) as a provisional-budget(math) value, and MUST be verifiable against
  measured-budget(math) from 30_verification capsules.
