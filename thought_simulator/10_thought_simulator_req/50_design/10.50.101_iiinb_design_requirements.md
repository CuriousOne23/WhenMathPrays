# 10.50.101 IIInB Design Requirements (Canonical)

**Document ID:** 10.50.101  
**Date:** 2026-06-08  
**Status:** Draft — W1 promotion anchor (30.101 / 40.101 evidence)

## 1. Purpose

Canonical realization anchor for **Input Inference/Repair Basin (IIInB)** — stage wire `input_semantic_repair`: profile-gated, read-only USP apply, intake-bound TP writes, escalate-without-guess, and non-blocking CIL escalation handoff. Translates [20.101](../../20_requirements/20.101_iiinb_requirements.md) and W1 verification into design-layer obligations.

## 2. Canonical HLR Set (verified W1 scope)

Evidence-backed obligations (25/28 from 20.101 demonstrated in 30.101):

- `HLR-20.101-001` … `HLR-20.101-004`: `profile_enabled` gate; skip with zero semantic effect; **`InB → IIInB → RB`** ordering; not in RB→OB→TR→TB chain.
- `HLR-20.101-005` … `HLR-20.101-012`: Read-only USP snapshot; version ref pinning; ACTIVE rule precedence; bounded pattern→expansion; APPLIED/ESCALATED outcomes.
- `HLR-20.101-014` … `HLR-20.101-022`: Intake-bound writes only; envelope guard on `semantic_core` / `TP.TR`; fixed `REASON_CODES` registry with assert-on-emission.
- `HLR-20.101-019` … `HLR-20.101-021`: Apply cap (16) and segment cap (32); deterministic replay digest; TCU cost on repair record.
- `HLR-20.101-024`: Positive envelope guard — `exec_plan` / `exec_trace` unchanged on repair path (24a).
- `HLR-20.101-026` … `HLR-20.101-028`: Full harness fixture matrix; deterministic `export_repair_diagnostics` ordering.

**Design-layer intake integration (W1 GATE-A):**

- `HLR-10.50.101-001`: IIInB SHALL reject handoffs that fail InB accept contract (`INB_HANDOFF_REJECTED` reason path).
- `HLR-10.50.101-002`: Upstream handoff schema `inb_to_iiinb_v1` from [10.50.100_inb_design_requirements.md](10.50.100_inb_design_requirements.md) / 40.100 evidence.

## 3. Canonical Scope

This anchor governs:

- read-only USP consumption per `usp_version_ref`
- one `iiinb_repair_record` per repair pass (`audit_records`)
- non-blocking escalation references to routing/CIL
- segmentation with truncate-with-audit under caps
- Pipeline B envelope non-mutation on intake repair paths (positive guard)

**Out of scope:** surface canonicalization (InB), full CIL FIFO wire (W2), IMR same-cycle isolation, live `FAIL_ENVELOPE` replay negatives (30.207 / W5).
