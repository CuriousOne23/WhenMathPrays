# 10.50.80 USP Design Requirements (Canonical)

**Document ID:** 10.50.80
**Date:** 2026-06-08  
**Status:** Approved — W2 GATE-B anchor; CP 30.00 review 2026-06-08 (30.250 / 40.80 evidence)

## 1. Purpose

Canonical realization anchor for the **User Shorthand Profile (USP)**: versioned shorthand rule store, read-only to IIInB, writable only through UPI commit paths. Translates [20.102](../../20_requirements/20.102_usp_requirements.md) and W2 verification evidence into design-layer obligations.

## 2. Canonical HLR Set (verified W2 scope)

Evidence-backed obligations (exploratory coverage via 30.250 harness matrix):

- `HLR-20.102-006`–`008`: IIInB read-only snapshot load; immutable for repair pass; deterministic read-failure policy.
- `HLR-20.102-009`–`012`: Monotonic `usp_version_id`, content-addressed `usp_version_ref`, safe-boundary transitions, supersede precedence.
- `HLR-20.102-013`–`015`: Rule lifecycle (`ACTIVE` / `SUPERSEDED` / `REVOKED`) with deterministic transitions.
- `HLR-20.102-014`: GB veto SHALL NOT create `ACTIVE` entries.
- `HLR-20.102-016`: Active rule cap overflow rejects with fixed reason code.
- `HLR-20.102-018`–`019`: Replay-identical active rule sets and `usp_version_ref` under identical commit sequences.
- `HLR-20.102-020`–`022`: Audit append on version transitions; fixed reason codes on reject paths.
- `HLR-20.102-024`: Deterministic fixture matrix (empty, single, supersede, revoke, cap, veto).

**Design-layer obligations (W2):**

- `HLR-10.50.80-001`: USPStore SHALL import struct shapes and digest helpers from the 10.50.42 / 30.140 anchor — no duplicate snapshot schema.
- `HLR-10.50.80-002`: COB pin integration ([20.102-010](../../20_requirements/20.102_usp_requirements.md)) is evidenced jointly with [30.220](../../30_verification/30.100_cob_prototypes/30.100_cob_prototypes_verification_capsule.md) W2 extension.

## 3. Canonical Scope

- `USPStore.apply_commit` (create / supersede / revoke)
- `export_snapshot` (ACTIVE-only rules)
- GB veto path without active mutation
- IIInB read-only load contract

**Out of scope:** UPI FIFO orchestration ([20.103](../../20_requirements/20.103_upi_requirements.md)), live CIL wire ([20.33](../../20_requirements/20.33_cil_requirements.md)), per-turn meaning construction.
