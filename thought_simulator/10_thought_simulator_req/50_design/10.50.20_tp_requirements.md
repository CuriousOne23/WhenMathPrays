# 10.50.20_TP Requirements (Canonical)

## 1. Purpose

This document is the canonical TP requirement anchor for promotion-governed TP lifecycle behavior.

The TP requirement IDs are retained as `HLR-20.30-*` for continuity with existing canonical design and verification records.

- `HLR-20.30-001`: TP identity and lifecycle state must remain deterministic, observable, and traceable across creation, movement, and entropy updates.

## 10.50.20.TCU TP CPU Execution Cycle Requirements

**Anchor authority:**
- 20.150_tcu_budgeting_requirements.md
- 10.10.10_system_architecture.md

### 10.50.20.TCU.10 Bounded per-tick cost
- Requirement ID: 10.50.20.TCU.10
- Statement: For any tick with fixed input cardinality N and fixed configuration, the subsystem
  MUST complete its work within a bounded number of CPU cycles C_max(tp) per tick phase,
  as constrained by 20.150. No unbounded or data-dependent worst-case growth is permitted.

### 10.50.20.TCU.20 Deterministic behavior under fixed conditions
- Requirement ID: 10.50.20.TCU.20
- Statement: For fixed seed, fixed input cardinality N, fixed configuration, and fixed hardware/runtime profile,
  the subsystem MUST exhibit deterministic CPU cycle consumption within
  [C_min(tp), C_max(tp)] for the same scenario ID, as defined in 20.150.

### 10.50.20.TCU.30 Provisional vs measured budgets (promotion-controlled)
- Requirement ID: 10.50.20.TCU.30
- Statement: The subsystem MUST maintain two distinct TCU budgets:
  - provisional-budget(tp): design-time estimate used for planning and scheduling.
  - measured-budget(tp): empirically measured values produced by 40_playground harnesses and verified in 30_verification capsules.
  These MUST NOT be conflated in normative documents.
  measured-budget(tp) MAY ONLY be updated through promotion-controlled evidence from 30.

### 10.50.20.TCU.40 Tick budget share
- Requirement ID: 10.50.20.TCU.40
- Statement: The subsystem MUST declare its target percentage of the global tick budget
  (per 20.150) as a provisional-budget(tp) value, and MUST be verifiable against
  measured-budget(tp) from 30_verification capsules.
