# 10.80_Event Log Requirements (Canonical)

## 1. Purpose

This document is the canonical requirement anchor for deterministic event-log behavior promoted from `40.80_event_log_prototypes`.

## 2. Canonical HLR Set

- `HLR-20.480-001`: Event logs must preserve append-only deterministic ordering for equivalent event sequences.
- `HLR-20.480-002`: Event replay contracts must produce stable verification digests for equivalent traces.
- `HLR-20.480-003`: Event ingestion must reject malformed events and non-monotonic sequence numbers.
