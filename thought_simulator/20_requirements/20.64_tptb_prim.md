**20.64 — TPTB Primitive (TP Truth Basin Tags)**

## **1 — Informative Overview (no SHALLs)**  
The **TPTB primitive** represents the set of **truth‑evaluation tags** produced by Path A after running interpretive basins, including the Truth Basin. These tags summarize the truth‑relevant outcomes of Path A’s evaluation of the user’s propositions.  

TPTB is **not** a truth engine and does not contain the Truth Basin itself. Instead, it provides a **safe, Path‑B‑readable metadata layer** that communicates whether Path A detected contradictions, misalignments, factual conflicts, or other truth‑relevant conditions.

TPTB enables Path B to express disagreement, qualification, correction, or clarification **without performing truth evaluation**, preserving A/B separation and 20.12 invariants.

TPTB is attached to the TP and MTP as part of Path A finalization.

---

## **2 — TPTB Structure (informative)**  
A TPTB object contains fields that describe:

- Whether a truth conflict was detected  
- The type of conflict  
- The truth alignment classification  
- A reference to the truth‑basis used  
- A human‑readable explanation  
- Optional scalar confidence or hypothesis‑band values  

These fields are used by Path B realization primitives to select appropriate expressive behavior.

---

## **3 — Requirements**

### **HLR‑20.64‑001**  
The system **SHALL** represent Path‑A truth‑evaluation outcomes using a TPTB object attached to the TP and MTP.

### **HLR‑20.64‑002**  
The TPTB object **SHALL** contain a boolean field $tptb.truth\_{conflict}$ indicating whether Path A detected a contradiction or misalignment.

### **HLR‑20.64‑003**  
The TPTB object **SHALL** contain a field $tptb.truth\_{conflict\\_type}$ whose value is selected from a finite, versioned enumeration defined in the TPTB schema.

### **HLR‑20.64‑004**  
The TPTB object **SHALL** include a field $tptb.truth\_{alignment}$ whose value expresses the alignment classification computed by Path A.

### **HLR‑20.64‑005**  
The TPTB object **SHALL** include a field $tptb.truth\_{basis}$ referencing the truth‑evaluation basis used by Path A.

### **HLR‑20.64‑006**  
The TPTB object **SHALL** include a human‑readable explanation field $tptb.truth\_{explanation}$ summarizing the reason for the truth classification.

### **HLR‑20.64‑007**  
The TPTB schema **SHALL** support optional scalar fields for hypothesis‑band or confidence values, represented using GitHub‑friendly math formatting.

Example:

$$
tptb.hypothesis\_{band} \in \\{low,\ medium,\ high\\}
$$

### **HLR‑20.64‑008**  
Path B **SHALL** treat all TPTB fields as read‑only metadata and **SHALL NOT** perform any truth evaluation.

### **HLR‑20.64‑009**  
The TPTB object **SHALL** be included in the $semantic\_{snapshot\\_ref}$ passed to Path B.

---

## **4 — Example (informative)**  
Below is an illustrative example of a TPTB object:

```
tptb:
  truth_conflict: true
  truth_conflict_type: CONTRADICTION
  truth_alignment: MISALIGNED
  truth_basis: tb_ref_20240618_001
  truth_explanation: "User claim contradicts established factual relation A → B."
  hypothesis_band: medium
```

This example is non‑normative and provided only for clarity.
