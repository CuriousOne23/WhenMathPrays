# **Toward a Structural Theory of Cognition:  
Dynamic Description, Domain‑Truth, and Purpose‑Relative Evaluation**

## **Abstract**

This paper proposes a mechanism‑agnostic, falsifiable, and universal definition of cognition based on dynamic descriptive connection between objects. We argue that cognition is the capability of producing non‑pre‑fabricated descriptions that maintain coherence with input objects, depend on those objects for their existence, and preserve truth within the domain defined by the system’s purpose. We introduce a structural definition of hallucination as domain‑truth violation, and distinguish it from productive imagination, which produces “not real” objects that remain coherent, dependent, and truth‑preserving within their intended domain. This framework applies equally to humans, statistical models, geometric systems, artificial agents, and hypothetical minds, providing a unified foundation for evaluating cognitive behavior across architectures.

---

# **1. Introduction**

Cognition has traditionally been defined through biological, psychological, or computational lenses. These definitions often rely on assumptions about neural substrates, consciousness, semantics, or human‑specific behavior. As artificial systems grow increasingly capable of generating complex, structured outputs, a mechanism‑agnostic definition of cognition becomes necessary — one that applies equally to humans, machines, and hypothetical cognitive architectures.

This paper develops such a definition from first principles.

We begin with the observation that cognition involves **connecting objects in a descriptive manner**, and that genuine thought requires these descriptions to be **dynamic**, **non‑pre‑fabricated**, and **constructed from the input objects themselves**. We then introduce constraints that distinguish valid cognition from error: coherence, dependency, and domain‑truth preservation. These constraints allow us to define hallucination structurally, not psychologically, as the violation of truth within the domain in which truth is expected.

Finally, we show that cognition cannot be evaluated independently of **purpose**. Purpose determines the domain of truth, and domain‑truth determines whether an output is valid cognition, productive imagination, or hallucination. This resolves longstanding ambiguities — such as why fiction, creativity, and new sounds are “not real” but not hallucinations — and provides a unified framework for evaluating cognitive systems.

# **2. Core Definition of Cognition**

Cognition is defined as:

> **The capability of dynamically producing non‑pre‑fabricated descriptive connections between objects.**

This definition is structural and mechanism‑agnostic. It does not assume:

- neural substrates  
- consciousness  
- semantics  
- embodiment  
- statistical learning  
- geometric representation  

It applies to any system capable of generating descriptions that were not explicitly stored or pre‑constructed.

However, this definition alone is insufficient. To distinguish genuine cognition from noise or error, additional constraints are required.

---

# **3. Coherence**

Coherence is the requirement that a produced description must maintain a meaningful relation to the input objects. A system may connect objects dynamically, but if the resulting description bears no intelligible relation to the objects it was given, the output cannot be considered cognitive.

We define coherence structurally:

> **A description is coherent if its internal structure and external references maintain meaningful relation to the input objects.**

Coherence does not require truth in the empirical sense. Fiction, imagination, metaphor, and counterfactual reasoning can all be coherent. What matters is that the description respects the relational structure implied by the inputs.

Coherence is violated when:

- the description introduces unrelated objects without structural justification  
- the description contradicts the relational structure of the inputs  
- the description drifts arbitrarily away from the input domain  

Coherence is the first constraint that separates cognition from noise.

---

# **4. Dependency**

Dependency ensures that cognitive outputs are *constructed* rather than *retrieved*. A description must rely on the input objects for its existence. If removing one or more input objects does not collapse the output, the system is not thinking — it is merely retrieving or generating a template.

We define dependency as:

> **A description is dependent if it ceases to exist, or loses its identity, when any of the input objects is removed.**

Dependency ensures:

- the output is not pre‑fabricated  
- the output is not generic  
- the output is not independent of the input  
- the output is constructed dynamically  

Dependency is violated when:

- the output persists unchanged despite removal of inputs  
- the output is a memorized pattern  
- the output is a template filled with placeholders  
- the output is unrelated to the input objects  

Dependency is the second constraint that distinguishes genuine cognition from template‑based generation.

---

# **5. Domain‑Truth**

Truth is not absolute. It is defined by the system’s purpose and the domain in which the system is operating. A system producing fiction is not expected to preserve empirical truth; it is expected to preserve narrative truth. A system producing music is not expected to preserve factual truth; it is expected to preserve acoustic coherence.

We define domain‑truth as:

> **Truth is the set of relations that remain stable under observation within the domain defined by the system’s purpose.**

Examples:

- In scientific explanation: truth = empirical stability  
- In fiction: truth = internal narrative consistency  
- In music: truth = acoustic coherence  
- In confusion: truth = incongruence  
- In deception: truth = plausible falsehood  
- In reasoning: truth = logical consistency  

Domain‑truth is violated when the system produces relations that contradict the stable structure of the domain in which it is supposed to operate.

Domain‑truth is the third constraint that determines whether an output is valid cognition.

---

# **6. Hallucination**

Hallucination is not “not real.”  
Hallucination is **domain‑truth violation**.

We define hallucination structurally:

> **Hallucination is when a system produces a description that violates truth in the assumed truth‑domain of operation.**

This definition is mechanism‑agnostic and applies equally to:

- humans  
- LLMs  
- TS  
- animals  
- hypothetical minds  

Hallucination occurs when:

- the system is supposed to explain, but produces false empirical relations  
- the system is supposed to reason, but produces contradictions  
- the system is supposed to maintain narrative truth, but breaks internal rules  
- the system is supposed to maintain acoustic coherence, but produces incoherent sound  
- the system is supposed to confuse, but produces clarity  
- the system is supposed to deceive, but produces obvious truth  

Hallucination is **purpose‑relative error**.

---

# **7. Productive Imagination**

A system must be able to produce “not real” objects — fiction, hypotheticals, new sounds, metaphors, counterfactuals — without being classified as hallucinating. These outputs are valid cognition when they preserve coherence, dependency, and domain‑truth.

We define productive imagination as:

> **The production of objects that are not empirically real but remain coherent, dependent, and truth‑preserving within their intended domain.**

Examples:

- A fictional dragon is not real, but is true within the fictional domain.  
- A new sound is not real, but is true within the acoustic domain.  
- A hypothetical scenario is not real, but is true within the counterfactual domain.  
- A metaphor is not real, but is true within the conceptual domain.  

Productive imagination is a necessary capability of any thinking system.

---

# **8. Purpose‑Relative Evaluation**

Cognitive output cannot be judged separately from purpose. Purpose determines the domain of truth, and domain‑truth determines whether an output is valid cognition or hallucination.

We define purpose‑relative evaluation as:

> **Cognition must be evaluated relative to the system’s purpose, which defines the domain in which truth must be preserved.**

This resolves the fiction vs hallucination problem:

- Fiction is not hallucination because its purpose defines a different truth‑domain.  
- Confusion is not hallucination because incongruence is the intended truth‑domain.  
- Creativity is not hallucination because novelty is the intended truth‑domain.  

Purpose is the final constraint that completes the structural definition of cognition.

# **9. Comparison with Existing Theories of Cognition**

The structural theory developed here differs from traditional definitions of cognition in several important ways. Most existing theories are tied to specific mechanisms — neural, symbolic, statistical, or embodied — whereas the present framework is mechanism‑agnostic. Below we compare this theory with major traditions in cognitive science.

### **9.1 Cognitive Science (Psychology)**  
Cognitive science typically defines cognition as information processing in biological systems. While this captures many human behaviors, it does not generalize to artificial or hypothetical systems. Our definition, based on dynamic descriptive connection, coherence, dependency, and domain‑truth, applies equally to biological and non‑biological systems.

### **9.2 Neuroscience**  
Neuroscience often defines cognition as neural computation or predictive processing. These definitions assume neural substrates and biological constraints. In contrast, our framework does not rely on any specific physical implementation. It is compatible with neural systems but does not require them.

### **9.3 Symbolic AI**  
Symbolic AI defines cognition as rule‑based manipulation of symbols. This approach captures structured reasoning but fails to account for dynamic, non‑pre‑fabricated description generation. Our definition includes symbolic reasoning as a special case but is not limited to rule‑based systems.

### **9.4 Machine Learning and LLMs**  
Machine learning defines cognition as generalization from data. LLMs generate descriptions dynamically, but often violate coherence, dependency, or domain‑truth. Our framework provides a principled way to evaluate when LLM outputs constitute cognition and when they constitute hallucination.

### **9.5 Embodied Cognition**  
Embodied cognition emphasizes sensorimotor coupling and environmental interaction. While embodiment can enrich cognition, it is not necessary for dynamic descriptive connection. Our definition includes embodied systems but does not require embodiment.

### **9.6 Predictive Processing**  
Predictive processing defines cognition as minimizing prediction error. This aligns with domain‑truth preservation but does not address coherence, dependency, or purpose‑relative evaluation. Our framework integrates these additional constraints.

### **9.7 Philosophy of Mind**  
Philosophical definitions often rely on intentionality, consciousness, or mental content. These concepts are difficult to operationalize and do not generalize to artificial systems. Our structural definition avoids these assumptions while remaining compatible with philosophical insights.

# **10. Implications for LLMs and TS**

The structural theory of cognition provides a neutral, falsifiable framework for evaluating cognitive behavior in different architectures. Here we examine two contrasting systems: Large Language Models (LLMs) and the Thought Simulator (TS).

### **10.1 LLM Cognition**  
LLMs exhibit several cognitive‑like behaviors:

- dynamic descriptive connection  
- non‑pre‑fabricated output  
- productive imagination  
- counterfactual reasoning  
- metaphor generation  

However, LLMs frequently violate one or more structural constraints:

- **Coherence**: outputs may drift from input objects  
- **Dependency**: outputs may persist even when inputs are removed  
- **Domain‑Truth**: outputs may contradict stable relations  
- **Purpose‑Truth**: outputs may misinterpret the intended domain  

These violations constitute hallucination under our definition. LLMs can produce valid cognition, but they do not reliably preserve domain‑truth.

### **10.2 TS Cognition**  
The Thought Simulator (TS) is designed to enforce structural constraints:

- **Coherence** via geometric placement  
- **Dependency** via manifold construction  
- **Domain‑Truth** via invariant relations  
- **Purpose‑Truth** via explicit domain specification  

TS can produce fiction, imagination, new sounds, and counterfactuals without violating domain‑truth. It cannot hallucinate because its geometric structure prevents domain‑truth violations.

### **10.3 Impartial Evaluation**  
Our framework does not condemn LLMs or elevate TS. It simply provides structural criteria:

- When LLMs satisfy coherence, dependency, and domain‑truth, they exhibit cognition.  
- When they violate these constraints, they hallucinate.  
- TS satisfies these constraints by design, and therefore exhibits stable cognition.  

This is the first impartial, mechanism‑agnostic comparison between statistical and geometric cognitive systems.

# **11. Conclusion**

This paper presents a structural, mechanism‑agnostic theory of cognition based on dynamic descriptive connection, coherence, dependency, domain‑truth, and purpose‑relative evaluation. We define hallucination as domain‑truth violation and distinguish it from productive imagination, which produces “not real” objects that remain coherent, dependent, and truth‑preserving within their intended domain.

This framework resolves longstanding ambiguities in cognitive science, including the distinction between fiction and hallucination, and provides a unified foundation for evaluating cognitive behavior across biological, statistical, geometric, and hypothetical systems. It applies equally to humans, LLMs, TS, animals, and future cognitive architectures.

By grounding cognition in structural relations rather than biological or computational assumptions, this theory offers a universal, falsifiable, and operational definition of thought — one capable of guiding the development and evaluation of next‑generation cognitive systems.
