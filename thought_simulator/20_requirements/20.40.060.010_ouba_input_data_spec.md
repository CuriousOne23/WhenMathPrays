# **20.40.060.010 — OuBA Input Data Specification (v0.1)**  
**Status:** Normative — Data Specification  
**Scope:** Defines the **input object** consumed by OuBA and the **output object** produced by OuBA (SSR).  
**Excludes:** Path‑A semantics (20.31), Path‑B semantics (20.110), realization substrate, truth determination (TPTB/TPSF).

---

# **0. Introduction**

This document defines the **data structures** used by the OuBA primitive.  
OuBA receives a **TP‑local meaning snapshot** and produces a **Semantic Snapshot Record (SSR)**.  
SSR is the **sole output** of Pipeline A and the **sole input** to Pipeline B.

This specification defines:

- the OuBA input object  
- the SSR output object  
- field definitions  
- structural invariants  
- commit‑time rules  

No semantic behavior is defined here; see **20.31_patha_semantic_spec.md** for Path‑A semantics.

---

# **1. Purpose**

The purpose of this document is to:

- define the **schema** of the OuBA input object  
- define the **schema** of the SSR output object  
- define the **normative invariants** required for commit  
- ensure deterministic, auditable, reproducible meaning transfer from Path A → Path B  

This document does **not** define:

- truth determination  
- safety determination  
- realization behavior  
- Path‑B routing  
- global meaning stores  

---

# **2. OuBA Input Object**

OuBA receives a **frozen TP snapshot** at the end of Pipeline A.  
This snapshot is a **pure data object**, not a semantic engine.

## **2.1 Input Object Fields**

The OuBA input object contains:

- `proposition_set[]`  
- `truth_evidence[]`  
- `completion_state`  
- `TP.metadata.delta_h_percent`  
- `TP.metadata.messy_input_record`  
- `TP.semantic.semantic_tags[]`  
- `TP.semantic.lane_local_identity`  
- `ob_trace[]`  
- `tb_trace[]`  
- `policy_markers[]`  

These fields are copied **verbatim** from TP at commit time.

### **HLR‑20.40.060.010‑001 — Input Object Integrity**  
OuBA input **SHALL** be a verbatim, immutable copy of TP fields at commit time.

---

# **3. SSR Output Object (OuBA Output)**

SSR is the **Semantic Snapshot Record**, the frozen meaning object consumed by Pipeline B.

SSR contains:

- `ssr_id`  
- `proposition_set[]`  
- `truth_evidence[]`  
- `completion_state`  
- `TP.metadata.delta_h_percent`  
- `TP.semantic.semantic_tags[]`  
- `TP.metadata.messy_input_record`  
- `policy_markers[]`  
- `TP.semantic.lane_local_identity`  
- `ob_trace[]`  
- `tb_trace[]`  
- `commit_timestamp`  
- `routing_epoch_id`  

SSR does **not** contain:

- realization fields  
- truth tags (TPTB)  
- safety flags (TPSF)  
- Path‑B routing structures  
- global meaning stores  

### **HLR‑20.40.060.010‑002 — SSR Immutability**  
SSR **SHALL** be immutable once produced.

### **HLR‑20.40.060.010‑003 — SSR Completeness**  
SSR **SHALL** contain all fields listed in Section 3.  
No field may be omitted.

---

# **4. Commit‑Time Rules**

Commit occurs when Path A completes meaning construction.

## **4.1 Deterministic Commit**

Commit must be deterministic given:

- TP state  
- seed  
- OB/TB/IB traces  
- policy markers  

### **HLR‑20.40.060.010‑004 — Deterministic Commit**  
Commit **SHALL** produce identical SSR output given identical TP input and identical seeds.

---

## **4.2 H% Commit Rule**

H% is copied directly from TP.

$H_{SSR} = H\\%\_{TP}$


### **HLR‑20.40.060.010‑005 — ΔH% Fidelity**  
SSR **SHALL** preserve H% exactly as computed in TP.

---

## **4.3 Completion State Commit Rule**

Completion state is copied directly from TP.

$C\_{SSR} = C\_{TP}$

### **HLR‑20.40.060.010‑006 — Completion Fidelity**  
SSR **SHALL** preserve completion state exactly as computed in TP.

---

# **5. Structural Invariants**

## **5.1 Proposition Set Invariant**

The proposition set must be identical between TP and SSR.

### **HLR‑20.40.060.010‑007 — Proposition Fidelity**  
SSR **SHALL** preserve `proposition_set[]` exactly.

---

## **5.2 Evidence Invariant**

Truth evidence must be identical between TP and SSR.

### **HLR‑20.40.060.010‑008 — Evidence Fidelity**  
SSR **SHALL** preserve `truth_evidence[]` exactly.

---

## **5.3 Tag Fidelity**

Semantic tags must be preserved exactly.

### **HLR‑20.40.060.010‑009 — Tag Fidelity**  
SSR **SHALL** preserve `TP.semantic.semantic_tags[]` exactly.

---

## **5.4 Policy Marker Fidelity**

Policy markers must be preserved exactly.

### **HLR‑20.40.060.010‑010 — Policy Marker Fidelity**  
SSR **SHALL** preserve `policy_markers[]` exactly.

---

# **6. Routing Metadata**

SSR includes a `routing_epoch_id` used by Path B.

### **HLR‑20.40.060.010‑011 — Routing Epoch Determinism**  
`routing_epoch_id` **SHALL** be deterministically derived from commit‑time metadata.

---

This document defines:

- the OuBA input object  
- the SSR output object  
- commit‑time invariants  
- deterministic fidelity rules  
- GitHub‑friendly math formatting
