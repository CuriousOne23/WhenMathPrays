## Purpose
This glossary contains canonical definitions for all TP-holding, TP-reading, and TP-modifying atomic primitives in the TS pipeline, with special focus on the Object Basin (OB) family and related low-level mechanics.

**Scope:** This glossary defines atomic TS primitives only. Data structures, policies, and governance terms are defined in 20.700.030 and 20.700.040.

## Entries

### InB (Input Basin) — 20.100
**Path:** A  
**Purpose:** Deterministic, non-inferential front door for all external signals.  
**Focus:** Schema validation, surface canonicalization, FIFO preservation; no meaning inference.  
**When:** First deterministic stage after external input.  
**Why:** Normalize wire form without guessing user intent.  
**Is not:** Semantic repair (IIInB); inquiry (IB); truth interpretation (TB); routing authority.  
**Example:** "teh" → canonical token; "Yeah Baby!" → tagged, not interpreted.  
**Normative home:** 20.100; messy-input classes in 20.17.

### IIInB (Input Inference/Repair Basin) — 20.101
**Path:** A  
**Purpose:** Apply bounded, user-sanctioned shorthand expansions before context extraction.  
**Focus:** Deterministic semantic-shorthand repair via USP rules; no meaning construction.  
**When:** InB → IIInB → IE.  
**Why:** Apply user-approved shorthand expansions without inference.  
**Is not:** Interpretation; candidate generation; truth evaluation; meaning construction.  
**Example:** USP expands "quicker-ish" → canonical form.  
**Normative home:** 20.101.

### IE (Intake Envelope) — 20.109
**Path:** A  
**Purpose:** Provide a deterministic, bounded, replayable representation of user input.  
**Focus:** Structured, normalized, repaired intake object from InB → IIInB.  
**When:** After IIInB; before CEx.  
**Why:** Downstream components require deterministic, replayable intake.  
**Is not:** Semantic interpretation; candidate generator; truth evaluator.  
**Normative home:** 20.109.

### CEx (ContextExtractor)
**Path:** A  
**Purpose:** Produce a bounded, replayable context slice (CE) for ISc without exposing global state.  
**Focus:** Deterministic extraction of only the context-relevant information from CIL.  
**When:** InB → IIInB → IE → CEx → CE → candidate_set{} → ISc.  
**Why:** ISc requires contextual information but cannot read CIL or global state directly.  
**Is not:** Semantic interpreter; meaning constructor; TP writer.  
**Normative home:** 20.33 (CIL), 20.44 (ISc).

### CE (ContextEnvelope) — 20.44
**Path:** A  
**Purpose:** Deliver safe, isolated context to ISc without exposing global conversation state.  
**Focus:** Bounded, deterministic, replayable context object.  
**When:** Produced immediately before ISc.  
**Why:** Provide ISc with the minimal, safe context required for scoring.  
**Is not:** History; semantic object; TP writer; global-state container.  
**Normative home:** 20.44.

### ISc (Inference Scorer) — 20.44
**Path:** A  
**Purpose:** Deterministically score interpretation candidates by applying truth_hypotheses-prc.  
**Focus:** Read CE and candidate_set{}; produce scoring fields for TPU.  
**When:** Path-A inference sequence.  
**Why:** Provide deterministic, local scoring for routing and TPU while preventing global-state leakage.  
**Is not:** Semantic generator; meaning constructor; truth evaluator; global inference engine.  
**Normative home:** 20.44.

### TPU (Thought Packet Updater) — 20.46
**Path:** A only  
**Purpose:** Sole safe writer to TP for Path-A correction.  
**Focus:** Deterministic, boundary-enforced TP updates; inserts/corrects message-items, referents, constraints.  
**When:** Path-A correction flow.  
**Why:** Enforce the single-writer invariant for meaning construction.  
**Is not:** Topology engine; semantic interpreter; Path-B primitive.  
**Scope invariant:** MUST NOT be invoked by Path B.  
**Normative home:** 20.46.

### SOB (Structural OB) — 20.40.010
**Path:** A  
**Purpose:** Extract first-pass structural cues from TP content.  
**Focus:** Clause boundaries, syntactic shape, punctuation, negation, modality markers.  
**When:** First OB stage in Path A.  
**Why:** Provide deterministic low-level structural residue.  
**Output:** `SOB_ATOM_SET` (see 20.710).  
**Is not:** Semantic interpreter; truth evaluator.  
**Normative home:** 20.40.010.

### SROB (Structural Refinement OB) — 20.40.020
**Path:** A  
**Purpose:** Refine and canonicalize SOB structural residue.  
**Focus:** Structural normalization, anchor refinement.  
**When:** After SOB.  
**Output:** `SROB_GRAPH` (see 20.710).  
**Is not:** Constraint resolver; semantic interpreter.  
**Normative home:** 20.40.020.

### CnOB (Constraint OB) — 20.40.030
**Path:** A  
**Purpose:** Extract constraint-level residue and metadata.  
**Focus:** Constraint cues, missing-slot signals, conflicts.  
**When:** After SROB.  
**Output:** `CONSTRAINT_LATTICE` (see 20.710).  
**Is not:** Semantic interpreter.  
**Normative home:** 20.40.030.

### SmOB (Semantic OB) — 20.40.040
**Path:** A  
**Purpose:** Extract pre-semantic cues and compress residue for routing.  
**Focus:** Semantic-adjacent patterns + deterministic pre-semantic hashing / TR-input cues.  
**When:** After CnOB.  
**Output:** `SEMANTIC_SKELETON` (see 20.710).  
**Is not:** Semantic interpreter; truth evaluator.  
**Normative home:** 20.40.040.

### SSG (Structural Signature Generator) — 20.47
**Path:** A  
**Purpose:** Convert SmOB output into deterministic structural signature vector.  
**Focus:** Arc patterns, residue entropy, curvature, motif frequencies.  
**When:** SmOB → SSG → RB.  
**Is not:** Semantic embedding; meaning construction.  
**Normative home:** 20.47.

### RB (Relational Basin) — 20.50
**Path:** A  
**Purpose:** Perform deterministic routing arbitration in Path A.  
**Focus:** Select next OB based on structural residue, ΔH%, lineage.  
**When:** After OB/TR evaluation.  
**Is not:** SRP; Path-B computation.  
**Normative home:** 20.50.

### IdOB (Identity Object Basin) — 20.40.050
**Path:** A  
**Purpose:** Perform identity-conditioned meaning refinement on the routed TP.  
**Focus:** Apply identity-specific rules after RB routing.  
**When:** After stable routing decision.  
**Is not:** A structural OB layer; does not modify OB outputs.  
**Normative home:** 20.40.050.

### OuBA (Output Basin — Path A Commit) — 20.40.060
**Path:** A  
**Purpose:** Commit the finalized Path-A meaning state into immutable semantic snapshot.  
**Focus:** Freeze semantic_core for DF intake.  
**When:** After meaning construction stabilizes.  
**Is not:** Governance primitive; truth evaluator.  
**Normative home:** 20.40.060.
