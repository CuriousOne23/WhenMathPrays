# **CoHI (Conversation History Integrator) — 20.113**

**Purpose:**  
The Conversation History Integrator (CoHI) imports conversation‑level structural continuity from the Conversation Object Basin (COB) into the frozen Path A TP snapshot, producing deterministic continuity_fields for use by LI and all downstream Path B primitives.  
**HLR‑20.113‑001:** CoHI SHALL read conversation‑level structures from COB and convert them into continuity_fields attached to the TP snapshot.

**Focus:**  
CoHI reads COB’s persistent structures (structural_history, referential_history, conversation_objects, topic_threads, continuity_markers) and normalizes them into a stable, per‑turn continuity substrate.  
**HLR‑20.113‑002:** CoHI SHALL generate continuity_fields including structural_history, referential_history, conversation_objects, topic_threads, and continuity_markers.  
**HLR‑20.113‑003:** CoHI SHALL write continuity_fields into the TP without modifying any other TP fields.  
CoHI performs no inference, no scoring, no routing, and no planning.

**When:**  
CoHI runs after TPTB and TPSF finalize A‑side metadata and before LI commits local meaning. It executes once per turn at the start of Path B.  
**HLR‑20.113‑004:** CoHI SHALL execute after TPSF and before LI on every Path B turn.

**Why:**  
CoHI ensures that LI, REx, RPlan, and RPU operate on a TP enriched with cross‑turn continuity, enabling stable referential resolution, topic persistence, and coherent multi‑turn behavior without requiring Path B primitives to read COB directly or perform memory operations.

**Is not:**  
CoHI is not an inference engine, a planner, a scorer, a router, a semantic interpreter, a memory modifier, or a continuity reasoner. CoHI does not modify COB and does not generate meaning.

**Example:**  
If COB contains a conversation_object representing “the dataset we discussed earlier,” along with referential links and topic‑thread markers, CoHI imports these into continuity_fields. LI then uses these fields to correctly interpret an utterance such as “run it again,” enabling continuity‑aware meaning commitment.

**Normative home:** 20.113.
