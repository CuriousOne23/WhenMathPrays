# **20.33 CIL Requirements (v0.2 — Architecture‑Aligned)**  
**Status:** Draft v0.2 — Architecture Alignment (2026‑06‑12; CuriousOne23, Copilot)

---

# **Purpose (Updated)**

Defines deterministic **Conversation Integration Layer (CIL)** behavior as the **reference‑only global context layer** responsible for:

- maintaining TP/MTP conversation state  
- maintaining lineage, commitments, referents, and active objects  
- providing deterministic supervisory escalation  
- providing clarification FIFO for Track H  
- supporting CEx by allowing **read‑only** access to global state  

CIL is **not** a pipeline stage.  
CIL does **not** perform scoring, repair, interpretation, or semantic work.  
CIL does **not** interact with IIInB, ISc, Merge, TPU, IB, or TB except through approved wires.

---

# **Architectural Position (New Section)**

### **Updated Architecture Placement**

CIL sits **outside** all four TS pipelines:

```
Normal Path:        InB → OB → RB → Path B → OuB
Clarification Path: InB → IIInB → Path B → OuB → User
Inference Path:     InB → IIInB → CEx → CE → ISc → Merge → TPU → TP
Post‑TS Path:       TP → IB → TB → GBIB → GB
```

### **CIL’s role:**

- **Reference layer only**  
- **Read‑only global context provider for CEx**  
- **Clarification FIFO owner**  
- **Supervisory escalation handler**  
- **Never a pipeline stage**  
- **Never a semantic engine**  
- **Never a writer to USP, TP, or CE**

---

# **Parent Decomposition Scope (Updated)**

CIL decomposes obligations from 20.10 and 20.30, and now additionally:

- SHALL support **CEx** as the only primitive allowed to read CIL  
- SHALL NOT provide context directly to ISc  
- SHALL NOT be invoked by IIInB except via escalation  
- SHALL NOT appear in any TS pipeline diagram  
- SHALL NOT perform semantic interpretation or scoring  
- SHALL NOT generate candidate sets

# **New Requirements (Inserted per Architecture Paper)**

### **CIL as Reference Layer Only**

34. **HLR‑20.032‑033010:** CIL SHALL NOT appear in any TS pipeline (Normal, Clarification, Inference, Post‑TS).  
35. **HLR‑20.032‑033020:** CIL SHALL NOT perform semantic scoring, interpretation, or candidate generation.  
36. **HLR‑20.032‑033030:** CIL SHALL NOT construct or modify CE.  
37. **HLR‑20.032‑033040:** CIL SHALL NOT provide context directly to ISc.

### **CEx Integration**

38. **HLR‑20.032‑033050:** CEx SHALL be the **only** primitive permitted to read CIL.  
39. **HLR‑20.032‑033060:** CIL SHALL expose only bounded, deterministic, read‑only views suitable for CEx extraction.  
40. **HLR‑20.032‑033070:** CIL SHALL NOT expose raw global structures to any primitive except CEx.  
41. **HLR‑20.032‑033080:** CIL SHALL NOT embed semantic meaning or interpretation into any view consumed by CEx.

### **Forbidden Interactions with TS Primitives**

42. **HLR‑20.032‑033090:** CIL SHALL NOT interact with IIInB except via escalation FIFO.  
43. **HLR‑20.032‑033100:** CIL SHALL NOT interact with ISc, Merge, or TPU.  
44. **HLR‑20.032‑033110:** CIL SHALL NOT interact with IB, TB, GBIB, or GB except via approved supervisory wires.  
45. **HLR‑20.032‑033120:** CIL SHALL NOT influence or modify the inference path.

### **Replay & Determinism Reinforcement**

46. **HLR‑20.032‑033130:** CIL SHALL ensure that identical global state + identical IIInB escalations yield identical CE‑relevant slices when read by CEx.  
47. **HLR‑20.032‑033140:** CIL SHALL NOT introduce nondeterministic ordering, filtering, or selection behavior visible to CEx.

# **Functional Boundaries (Updated)**

- CIL owns conversation‑level TP/MTP integration, lineage, commitments, referents, and clarification FIFO.  
- CIL does **not** participate in any TS pipeline.  
- CIL provides **read‑only** global context to **CEx only**.  
- CIL does **not** provide context to ISc, Merge, TPU, IIInB, IB, or TB.  
- CIL does **not** perform semantic work.  
- CIL does **not** generate candidate sets.  
- CIL does **not** write USP or TP.  

---

# **Verification Focus (Updated)**

- CEx is the only consumer of CIL global state.  
- No CIL → ISc, CIL → TPU, or CIL → Merge interactions.  
- No CIL participation in TS pipelines.  
- Deterministic CE‑relevant slices when read by CEx.  
- Deterministic clarification FIFO behavior.  
- Deterministic supervisory escalation.
