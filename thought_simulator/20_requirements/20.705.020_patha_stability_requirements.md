**Path-A Stability Requirements** (Working Draft v0.2)

### 0. Purpose
This document defines the stability requirements for Path-A, integrating the behavior of COB, CST, and CIL.

Path-A stability ensures that identity layers, referent maps, lineage, ambiguity, relevance, and context signals remain deterministic, replay-safe, and stable across turns and sessions.

This paper complements 20.705 Path A / Path B flow and the COB/CST/CIL papers.

### 1. Path-A Stability Overview
Path-A stability means:
Given identical inputs, the system reconstructs identical identity layers, referent maps, lineage, ambiguity, relevance, and stability signals.

Path-A stability is achieved through:
- Deterministic COB state
- Deterministic CST metrics and signals
- Deterministic CIL intake behavior
- Deterministic replay of all stability operations

Path-A must never depend on stochastic sampling, randomization, external state, wall-clock time, or nondeterministic ordering.

### 2. COB Stability Requirements
COB is the long-term identity substrate. It must maintain:

**Identity Layer Stability**
- Identity layers must be deterministic and replay-safe.
- No spontaneous creation, deletion, or mutation.
- All structural changes must be triggered by CST signals.

**Referent Map Stability**
- Referent → identity mappings must be deterministic.
- No nondeterministic assignment or drift.
- All updates must be logged and replay-safe.

**Lineage Stability**
- Lineage pointers must be deterministic.
- No cyclic lineage.
- No lineage mutation without CST signals.

**Ambiguity Stability**
- Ambiguity values must be deterministic.
- Ambiguity must only change due to deterministic cues or CST signals.

**Relevance Stability**
- Relevance values must be deterministic and bounded.
- All relevance changes must be deterministic.

### 3. CST Stability Requirements
CST is the stability engine for Path-A. It must ensure deterministic replay of all stability operations.

**Deterministic Metrics**
CST must compute all metrics deterministically (drift, ambiguity, continuity, collapse, relevance stability, decay progression).

**Deterministic Thresholds**
Thresholds must be deterministic, monotonic, bounded, replay-safe, and independent of external state.

**Deterministic Signals**
CST must emit signals deterministically (collapse, freeze/thaw, structural, ambiguity/drift, relevance adjustments).

**Signal Ordering**
Deterministic order:
1. Collapse signals
2. Freeze/thaw signals
3. Structural signals
4. Ambiguity/drift signals
5. Relevance signals

**Deterministic Freeze/Thaw and Collapse Recovery**
Freeze must halt structural changes. Thaw must replay queued updates deterministically. Collapse recovery must follow a deterministic sequence (freeze → identify → recover → thaw → replay).

**Deterministic Logging**
CST must log all metrics, thresholds, signals, freeze/thaw events, and collapse recovery events.

### 4. CIL Stability Requirements
CIL is the short-term integration lens. It must produce deterministic intake packets for CEx.

**Deterministic Cue Integration**
CIL must integrate short-term TP/IE cues with long-term COB/CST snapshot into a deterministic intake packet.

**Deterministic Identity Selection & Flags**
Identity selection, certainty, ambiguity, stability, and structural hints must be deterministic, replay-safe, and derived only from cues + COB/CST snapshot.

**Safety Requirements**
CIL must never modify COB, emit merge/split instructions, override CST, or use external state or timing.

### 5. Path-A Replay Requirements
Path-A must guarantee:
- Identical inputs → identical SSRGn packets
- Identical packets → identical CIL intake
- Identical intake → identical CST metrics
- Identical metrics → identical CST thresholds
- Identical thresholds → identical CST signals
- Identical signals → identical COB state
- Identical COB state → identical CEx metadata

All components must log deterministically, apply updates deterministically, avoid nondeterministic ordering, and avoid external state.

### 6. Path-A Safety Requirements
Path-A must never use randomness, external state, nondeterministic ordering, mutate COB without CST signals, allow CIL to perform structural operations, or allow CEx to modify COB.

Path-A must always preserve determinism, continuity, replay safety, and stability.
