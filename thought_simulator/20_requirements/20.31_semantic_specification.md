# 20.31 Semantic Specification

## 1. Core Meaning Semantics (TP/MTP)
The canonical meaning schema for TP and MTP SHALL include the following fields and semantics:

- propositions: explicit semantic claims carried by TP/MTP
- stance: declared position relative to propositions
- affect: structured emotional valence and intensity fields
- intent: declared action or communicative objective
- Delta-H%: bounded entropy contribution and missing-mass accounting
- lineage: deterministic provenance and ancestry chain
- semantic tags: explicit classification tags for routing and interpretation
- truth hypotheses: structured truth-evaluation fields
- done state: deterministic completion state for the current cycle or objective
- stability metadata: deterministic stability and degradation indicators
- overflow metadata: deterministic overflow tags and boundedness event fields

## 2. OB Semantics (Local Extraction)
OB modules SHALL extract local meaning fragments from projected TP views using deterministic semantics.

OB semantics SHALL define:

- visible vs suppressed semantics: deterministic projection boundaries for what each OB can observe
- Delta-H% contribution rules: deterministic contribution and missing-mass accounting per OB output
- evidence field structure: canonical, typed evidence fields emitted by each OB
- projection semantics: deterministic mapping from TP semantic fields to lane-local representations

## 3. TB Semantics (Interpretation)
TB modules SHALL produce deterministic interpretation fields from OB and TP/MTP evidence without latent, opaque state mutation.

TB semantics SHALL include:

- stance interpretation
- affect interpretation
- intent interpretation
- logic interpretation
- social interpretation

Each interpretation SHALL be explicit, auditable, and attributable to deterministic input evidence.

## 4. IB Semantics (Inquiry Evolution)
IB semantics SHALL define deterministic inquiry evolution across cycles.

IB semantics SHALL include:

- Delta-H% evolution: deterministic uncertainty change tracking for inquiry progression
- inquiry state: explicit deterministic inquiry lifecycle state
- evidence accumulation: deterministic accumulation and conflict tracking for inquiry evidence
- split/merge semantics: deterministic supervisory-safe partition and convergence rules
- promotion/retirement semantics: deterministic criteria and transitions for IB lifecycle control

## 5. COB Semantics (Conversation Identity)
COB semantics SHALL define conversation-level deterministic identity and lifecycle behavior.

COB semantics SHALL include:

- identity: deterministic conversation object identity definition
- lineage: deterministic conversation provenance chain
- compaction: deterministic state compaction semantics
- replay: deterministic conversation replay semantics
- promotion/deprecation: deterministic lifecycle transitions for conversation objects

## 6. MCS Semantics (Meaningful Cognitive Step)
A Meaningful Cognitive Step (MCS) is a logged, attributable, state-changing transition that advances the task toward a declared success condition.

MCS semantics SHALL require that each counted step is:

- logged
- attributable
- state-changing
- success-path aligned

MCS semantics SHALL prohibit:

- micro-step inflation
- repeated artifacts
- formatting-only steps

## 7. Deterministic Replay Semantics
TS SHALL achieve 100% deterministic replay for identical (input, MTP state, seed) tuples.

Replay determinism SHALL hold across OB, RB, TB, Delta-H%, merging, truth/done evaluation, and MTP update stages.

## 8. Deterministic Policy Enforcement Semantics
All policy constraints SHALL be enforced deterministically at RB/TB safe boundaries with zero unlogged violations.

Policy enforcement outcomes SHALL be logged with deterministic reason codes and replayable evidence.
