# 20.30.090 RSG Mapping Rules

## 1. Purpose and Scope

This document defines the complete rule system used by RSG to map SSR to expression manifold coordinates and then to surface form (OuBB). RSG performs forward projection, gradient-based selection, and back-transfer using a finite offline manifold table of patterns.

RSG operates only on finalized SSR; it does not modify SSR, TP, or grounding.

HLR-20.30.090-001: RSG SHALL map SSR to final surface form using only the rules and offline table defined in this document.

## 2. Design Intent

TS translates user natural language into SSR via Path A (TP extraction) and Path B (grounding with KnC, KnM, KnF). KnDt is fully atomized using the Atomizer and Atomizer Checker. SSR is the canonical internal representation: atomic, deterministic, non-narrative, and manifold-ready.

RSG (defined in 20.30.085_rsg_prim.md) is the manifold mapper. It converts atomic SSR into human-readable output while preserving truth, safety, clarity, and tone.

RSG assumes SSR is atomic, bounded, non-narrative, and contains no semantic ambiguity.

HLR-20.30.090-002: RSG SHALL operate exclusively on atomized SSR fields.

## 3. Inputs to RSG

RSG receives the following SSR fields:

- Identity
- Relation
- Domain anchor
- Qualifier
- Time anchor
- Truth/safety metadata
- Tone metadata
- Continuity metadata
- Realization metadata (tone, continuity, clause-shape hints) from Path A

RSG never receives raw KnDt sentences.

## 4. Forward Projection Rules (SSR → Manifold Coordinates)

Each SSR field maps to one or more coordinates in the expression manifold using the following projection operators:

- P_id: identity → identity coordinate
- P_rel: relation → relation coordinate
- P_dom: domain anchor → domain coordinate
- P_qual: qualifier → qualifier coordinate
- P_time: time anchor → temporal coordinate
- P_truth: truth metadata → truth gradient weight
- P_safe: safety metadata → safety gradient weight
- P_tone: tone metadata → tone coordinate
- P_cont: continuity metadata → continuity coordinate

HLR-20.30.090-003: RSG SHALL compute manifold coordinates for every provided SSR field using the defined projection operators.

HLR-20.30.090-004: RSG SHALL resolve projection conflicts using the priority hierarchy truth > safety > clarity > brevity > tone > continuity.

## 5. Priority Gradient System

The gradient hierarchy is: truth > safety > clarity > brevity > tone > continuity.

Gradients operate as successive filters, collapsing the manifold by eliminating patterns that violate higher-priority constraints. Gradient collapse always produces a single manifold address.

HLR-20.30.090-005: RSG SHALL apply gradients in the fixed priority order above.

HLR-20.30.090-006: RSG SHALL downgrade patterns (fine → medium → coarse) when higher-priority gradients cannot be satisfied simultaneously.

## 6. Selection Rules

RSG selects from the offline table:
- Clause-shape patterns (based on number of referents, relation type, tense/aspect/mood, tone, continuity)
- Connective patterns
- Compression/omission patterns
- Tone variants
- Truth/safety surfacing patterns

**Compression/Downgrade Rules**  
- fine → medium when brevity > tone  
- medium → coarse when brevity > clarity  
- coarse → identity-only when brevity dominates all lower gradients

**Omission Rules**  
- omit qualifier when brevity > clarity  
- omit time anchor when brevity > continuity  
- omit domain anchor when brevity > tone

HLR-20.30.090-007: RSG SHALL select the pattern address that best satisfies the priority gradient after manifold collapse.

HLR-20.30.090-008: RSG SHALL apply omission only when lower-priority gradients (brevity) dominate after truth and safety are satisfied.

## 7. Back-Transfer Rules (Manifold → Surface Form)

RSG maps the selected manifold point (address + gradient) to surface form using the offline table by:

- Selecting clause shape
- Filling identity slot
- Filling relation slot
- Filling domain slot (if not omitted)
- Filling qualifier slot (if not omitted)
- Filling time slot (if not omitted)
- Applying tone variant
- Applying connective pattern
- Applying redundancy elimination
- Applying pronoun strategy
- Applying tense/aspect/mood

HLR-20.30.090-009: RSG SHALL realize surface form strictly from the selected table entry and gradient parameters.

## 8. Offline Manifold Table Requirements

The expression manifold is realized through a finite, offline table containing clause-shapes, connective patterns, compression/omission templates, tone variants, and truth/safety surfacing patterns.

The table SHALL contain: pattern ID, clause shape, connective pattern, compression template, omission template, tone variant, truth/safety surfacing pattern, ordering rule, pronoun strategy, tense/aspect/mood pattern.

The table is small (megabytes), resides in RAM, and supports fast lookup. RSG only selects an address + gradient; the table performs realization.

HLR-20.30.090-010: RSG SHALL use only the pre-defined offline table for realization. No generative rules outside the table are permitted.

## 9. Determinism and Testability

All mapping steps are deterministic. Given identical SSR input and table state, RSG produces identical output.

RSG SHALL expose its selected manifold address for debugging and verification.

HLR-20.30.090-011: RSG SHALL produce fully reproducible results for any valid SSR input.

## 10. Examples

**Example 1: Simple Assertion**  
SSR: Identity=User, Relation=Location, Domain=Current, Qualifier=Immediate  
Manifold coordinates → Gradient collapse (truth+safety dominant)  
Selected pattern: Direct declarative clause-shape  
Surface form: "You are here now."

**Example 2: Qualified Plan with Constraint**  
SSR: Identity=Agent, Relation=Action, Domain=Future, Qualifier=Conditional, Truth=High, Safety=Critical  
Manifold coordinates → Priority gradient resolves safety first  
Selected pattern: Cautionary conditional with safety surfacing  
Surface form: "If you proceed, you must verify safety constraints first."

**Example 3: Downgrade for Brevity**  
SSR: Identity=Michael Jordan, Relation=basketball player, Qualifier=greatest, Time=1980s  
Gradient: brevity dominates after truth/safety  
Selected pattern: Compressed form with omission  
Surface form: "Michael Jordan was a basketball player."
