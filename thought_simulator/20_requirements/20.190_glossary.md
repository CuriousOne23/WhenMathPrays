# 20.190 Glossary

## Purpose
Canonical glossary for the refactored 20-series.

## Core Terms
- Thought Simulator (TS): deterministic fixed-tick engine for structured meaning construction.
- Thought Packet (TP): mobile state unit carrying semantic and lineage fields.
- Master Thought Packet (MTP): global semantic state merged from lane TPs.
- Object Basin (OB): local evidence extraction primitive.
- Relational Basin (RB): deterministic routing and projection primitive.
- Truth Basin (TB): truth interpretation primitive.
- Governing Basin (GB): global context constraint primitive.
- Inquiry Basin (IB): ambiguity-handling primitive.
- Monitoring Basin (MB): non-intrusive diagnostic primitive.
- Conversation Integration Layer (CIL): deterministic conversation-intake and integration layer that preserves FIFO ordering, snapshot coherence, and supervisory escalation pathways.
- Conversation Object Basin (COB): deterministic conversation-object lifecycle layer that governs continuity identity, lineage, replay-horizon semantics, and export/redaction policy behavior.
- Coprocessor (COP): optional propose-only asynchronous subsystem with deterministic provenance, bounded queueing/fairness behavior, and safe-boundary commit visibility.
- Input Basin (InB): deterministic intake normalization and **non-inferential** surface correction only; SHALL NOT perform semantic input error correction (see Input correction terms).
- Output Basin (OuB): output realization primitive.
- DeltaHPercent: normalized hypothesis contribution metric.
- HPercent: truth/uncertainty evaluation state.
- TCU: normalized compute-cost unit.
- Random Seed Boundary: isolation rule that confines randomness to output expression selection.
- Directional Conversation Basin (DCB): geometric meta-basin that observes TP trajectory geometry and emits directional-change events.
- directional-change event: ephemeral geometric signal emitted by DCB when trajectory curvature or directional deviation exceeds a bounded invariant.
- geometric meta-basin: basin-class element that operates on trajectory geometry without semantic extraction authority.

## Dual-Pipeline Terms (20.500 — Stage 2 stack approved; normative detail in 20.205–20.207, 20.36, 20.58, 20.120)

- **Pipeline A**: Lane-parallel meaning construction; sole writer of `semantic_core` until `mtp_update`.
- **Pipeline B** (Execution Manifold): Singular realization pass per `commit_id` per cycle; no lanes, no TP input.
- **`semantic_core`**: Authoritative committed meaning envelope after Pipeline A `mtp_update`.
- **`mtp_update`**: Pipeline A commit event that freezes meaning and emits `commit_id`.
- **`commit_id`**: Canonical MTP commit marker at `mtp_update` (`mtp_snapshot_id` = deprecated alias).
- **XP** (Execution Packet): Logical wrapper indexing one `exec_plan` + `exec_trace` (+ B audit) per `commit_id`; not TP-B.
- **`exec_plan`**: B planning envelope (`opbeh_id`, `obg_id`, `xlater_id`, `routing_epoch_id`).
- **`exec_trace`**: B expression/feedback envelope (OuB refs, IMR records).
- **OpBeh** (Operational Behavior): B registry and planning primitive; ≠ basin OB.
- **OBG** (Operational Behavior Group): B register/voice identity primitive.
- **XlateR** (Translation Routine): B expression mapping primitive; ≠ TR.
- **TrigRB**: B semantic trigger detector; ≠ TR or RB.
- **SRP** (Semantic Routing Planner): Cold-path table compile; hot path = lookup only.
- **IMR** (Interpretation Mismatch Routine): B expression/feedback evaluator; Types A/B/C.
- **`routing_epoch_id`**: Published routing table epoch on B envelopes only.

## Input correction terms (follow-on program — [20.500](20.500_refactoring_for_dual_TS_pipeline.md) §7.7)

- **Semantic input error correction:** Pre–Pipeline A repair of user-specific or ambiguous meaning; **out of scope for InB**; follow-on IIInB / UPI / USP program when profile-enabled.
- **IIInB** (Input Inference/Repair Basin, draft): Optional pre–Pipeline A stage for bounded semantic correction; non-learning; consults USP when present; escalates unknown segments to clarification path.
- **UPI** (User Preference Integrator, draft): Deterministic integrator that writes user-specific semantic shorthand rules to USP after clarification; not a meaning-construction primitive.
- **USP** (User Semantic Profile, draft): Versioned, auditable store of user/conversation semantic shorthand rules; read-only to IIInB at intake.

## Usage Rules
1. HLR-20.190-001: Terms in this glossary SHALL be used consistently across all 20-series requirement modules.
2. HLR-20.190-002: Deprecated or changed terms SHALL be updated in glossary and traceability artifacts in the same change set.
3. HLR-20.190-003: CIL, COB, and COP terminology SHALL be used consistently with 20.10 and 20.30 parent decomposition semantics and SHALL NOT redefine primitive authority boundaries.

## Registry-Aligned Canonical Terms
**Thought**: Minimal semantic unit represented and transformed within TS processing.

**Thought Simulator (TS)**: Deterministic fixed-time-step simulation engine for structured meaning processing.

**Observer (External)**: Actor or system outside TS that submits inputs and receives outputs.

**Unified Entropy**: Global uncertainty representation synthesized across participating lanes.

**Object Basin (OB)**: Basin specialized for object-level extraction, persistence, and object semantics.

**Routing Basin (RB)**: Basin role focused on deterministic route selection and transition control.

**Relational Basin (RB)**: Basin role focused on relational projection and deterministic relationship handling.

**Governing Basin (GB)**: Supervisory basin authority that enforces constraints and safe-boundary commitments.

**Truth Basin (TB)**: Basin role for truth interpretation, confidence shaping, and truth-state derivation.

**Input Basin (InB)**: Boundary basin that normalizes and validates incoming external inputs.

**Output Basin (OuB)**: Boundary basin that realizes governed internal state into external outputs.

**Monitoring Basin (MB)**: Non-intrusive observation basin for diagnostics and telemetry.

**Thoughtpoint (TP)**: Tagged state-bearing unit flowing through basin processing.

**Relational Manifold**: Structured geometric/semantic space used to encode relational positioning.

**Minimal Thought Atom**: Smallest canonical thought representation used by deterministic processing.

**Anti-Collapse Stabilizer**: Constraint mechanism that reduces destabilizing collapse trajectories.

**Atomic Snapshot Write**: Single indivisible snapshot persistence operation.

**Basin**: Deterministic processing container with bounded state and transition rules.

**Basin Capacity**: Maximum bounded load a basin may hold before overflow policy applies.

**Basin Lifecycle State**: Explicit state of a basin across initialization, active, and terminal phases.

**Canonicalization**: Deterministic normalization of representations into canonical form.

**Clean Completion**: Completion path where all required conditions are met without stress signals.

**Coherence**: Consistency of semantic state across components and time.

**Completion Detection**: Rule set for determining terminal or done conditions.

**Damping Coefficient**: Parameter controlling attenuation of destabilizing dynamics.

**Deterministic Mode**: Execution mode where behavior is reproducible under identical inputs and seed conditions.

**Done / Terminal Basin**: Terminal lifecycle condition indicating basin processing completion.

**Embedding Vector**: Numeric representation encoding semantic state for deterministic comparison/projection.

**Entry Conditions**: Preconditions that must hold before entering a state or transition.

**Event Stream**: Ordered append-only sequence of recorded system events.

**Exit Conditions**: Conditions that must hold to leave a state or complete a transition.

**Fail-Safe Termination**: Safe shutdown path that preserves invariants under fault or abort conditions.

**Fanin**: Multiple inbound flows converging into a basin or operation.

**Fanout**: Single source flow distributed deterministically to multiple downstream targets.

**Fixed-Time-Step Simulation**: Simulation progression in explicit, uniform tick intervals.

**Flow Modulator**: Control component that shapes flow intensity, timing, or gating under policy.

**Highway**: High-throughput routing path for governed deterministic transfer.

**Inquiry Basin**: Basin dedicated to ambiguity handling and inquiry-oriented state refinement.

**Interpretive Manifold**: Manifold framing that supports interpretation of relational meaning state.

**Manifold Translator**: Mapping mechanism between manifold representations or coordinate frames.

**Multi-TP Concurrency**: Governed parallel handling of multiple thoughtpoints.

**No-Op Thoughtpoint Handling**: Deterministic policy for TPs that produce no state-changing action.

**Normalized Entropy Percentage**: Scaled entropy measure expressed as a normalized percentage.

**Overflow Behavior**: Defined system behavior when capacity bounds are exceeded.

**Provenance Entry**: Audit record that captures origin and transformation lineage.

**Regulator**: Constraint/control element that enforces operating bounds and stability.

**Replayability**: Ability to reproduce behavior deterministically from recorded inputs and state.

**Resource Bounding**: Explicit limits on compute, memory, and related execution resources.

**Routing and Transitions**: Deterministic policies governing movement between basins/states.

**Safe Shutdown Ordering**: Required sequence for safe subsystem termination.

**Snapshot**: Time-indexed capture of state for recovery, replay, or audit.

**Split / Merge Operations**: Deterministic operations that branch or combine processing/state paths.

**State Counter (Tagged State Counter)**: Monotonic tagged counter for state progression tracking.

**Stressed Completion**: Completion path reached under stress conditions with recorded mitigation.

**Tick Cycle**: One deterministic simulation update interval.

**Top-Down Design**: Design approach deriving lower-level detail from higher-level governing structure.

**Traceability Matrix**: Artifact mapping requirements, design, and verification relationships.

**TS Step Index**: Monotonic index identifying simulation progression steps.

**Unified Entropy Functional**: Function/operator used to compute unified entropy over system state.

**Watchdog**: Monitoring mechanism that detects stalls, violations, or liveness failures.

**Directional Conversation Basin (DCB)**: Geometric meta-basin that observes TP trajectory position, direction, and curvature and emits directional-change events without semantic interpretation.

**directional-change event**: Ephemeral geometric TR input raised when trajectory curvature or directional deviation exceeds a bounded geometric invariant.

**geometric meta-basin**: Meta-basin classification for elements such as DCB that influence routing through geometry only and do not hold OB-class semantic extraction authority.
