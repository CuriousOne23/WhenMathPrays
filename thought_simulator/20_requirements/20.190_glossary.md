# 20.190 Glossary

**Document ID:** 20.190  
**Version:** 0.2  
**Date:** 2026-06-07  
**Status:** Approved v0.2 — Primitive Intent Catalog (2026-06-07; Grok)

## Purpose

Canonical glossary and **Primitive Intent Catalog** for the refactored 20-series. This document is the **intent enforcement layer**: it defines what each primitive owns, when it runs, and what it is *not* — to prevent authority drift across modules. Normative HLRs remain in linked 20.xx modules; entries here are descriptive unless explicitly marked otherwise.

## How to Read This Catalog

Each catalog entry uses a fixed template:

| Field | Meaning |
|--------|---------|
| **Focus** | One sentence: what the primitive owns |
| **When** | Pipeline A / B / conversation layer / optional pre-A |
| **Why** | Problem it solves |
| **Is not** | Common confusions (1–3) |
| **Example** | One concrete scenario (omitted for crisp wire terms) |
| **Normative home** | Authoritative 20.xx module |

**Tier 1** entries are highest drift risk (wrong-work assignments). **Tier 2** covers basin and namespace boundaries. **Tier 3** covers metrics and taxonomies. **Registry-Aligned Reference Terms** (§Registry) holds legacy/registry vocabulary; basin and pipeline primitives that appear in the catalog are **aliases only** — do not redefine them there.

## Primitive Intent Catalog

### Tier 1 — Authority and Drift-Prone Primitives

#### InB (Input Basin) — [20.100](20.100_inb_requirements.md)

- **Focus:** Deterministic external-signal intake, schema validation, and **non-inferential** surface canonicalization.
- **When:** Pipeline A entry; first deterministic stage after external input.
- **Why:** Normalize wire form and preserve FIFO ordering without guessing user meaning.
- **Is not:** Semantic input error correction (IIInB/UPI/USP); IB inquiry; IMR output feedback; truth or routing authority.
- **Example:** `"teh"` → canonical token under profile rules; `"Yeah Baby!"` → tagged and handed off — not interpreted as affection shorthand.
- **Normative home:** [20.100](20.100_inb_requirements.md), messy-input surface classes in [20.17](20.17_messy_input_handling.md).

#### IB (Inquiry Basin) — [20.90](20.90_ib_requirements.md)

- **Focus:** GB-governed ambiguity handling via bounded inquiry-state evolution and clarification proposals.
- **When:** Pipeline A; instantiated only after GB approves an **IB-Creation-Request**.
- **Why:** Structured inquiry when commitment is blocked — without silent gap-fill or generative completion.
- **Is not:** InB (intake); IIInB (semantic input repair); IMR (post-output mismatch); automatic slot filling on `MI_VAGUE`.
- **Example:** `MI_VAGUE` with unresolved `SLOT_GOAL` → IB-Creation-Request → GB approval → IB emits evidence request — not a default goal assignment.
- **Normative home:** [20.90](20.90_ib_requirements.md), request wire in [20.17](20.17_messy_input_handling.md), [20.30](20.30_ts_functional_model.md).

#### IMR (Interpretation Mismatch Routine) — [20.45](20.45_imr_requirements.md)

- **Focus:** Post-realization mismatch classification and bounded corrective **trigger scheduling** on Pipeline B.
- **When:** After `oub_expression` / `imr_evaluation`; reads frozen `semantic_snapshot_ref` and OuB artifact refs.
- **Why:** Separate "output doesn't match committed meaning or evaluator feedback" from input repair, inquiry, and meaning construction.
- **Is not:** InB/IIInB (input); IB (inquiry); direct `semantic_core` writer; GB rule store; SRP table compiler.
- **Example:** User says "that's factually wrong" → Type B `imr_record` + optional `CorrectionTrigger` for listed fields next cycle; "too casual" → Type A realization retry on same snapshot.
- **Normative home:** [20.45](20.45_imr_requirements.md), replay classes in [20.36](20.36_canonical_end_to_end_trace.md).

#### OuB (Output Basin) — [20.110](20.110_oub_requirements.md)

- **Focus:** Governed **realization** of committed meaning into external output artifacts and `exec_trace` records.
- **When:** Pipeline B; after `exec_plan_commit`; reads frozen `semantic_core` / snapshot ref only.
- **Why:** Surface expression is singular, seed-bounded, and strippable from meaning replay.
- **Is not:** OpBeh/OBG/XlateR planning primitives; Pipeline A meaning writer; semantic input repair; contradiction smoothing without TB authorization.
- **Example:** Same `semantic_core` and `exec_plan`, different `seed_scope` → different surface text only; `semantic_core` diff empty across seeds.
- **Normative home:** [20.110](20.110_oub_requirements.md), [20.207](20.207_execution_replay_specification.md).

#### GB (Governing Basin) — [20.80](20.80_gb_requirements.md), [20.16](20.16_gb_responsibility_matrix.md)

- **Focus:** Supervisory constraint enforcement, safe-boundary commits, cap accounting, and approval gates.
- **When:** Cross-cutting; consumes supervisory queue entries; commits at deterministic safe boundaries.
- **Why:** Global governance without letting every primitive self-authorize corrective or lifecycle actions.
- **Is not:** User lexicon store (USP); COP executor; meaning construction basin; direct IMR classification engine.
- **Example:** Veto unsafe USP rule write; approve/deny IB-Creation-Request; mandate Safe-Mode on Type C IMR without silent semantic rewrite.
- **Normative home:** [20.80](20.80_gb_requirements.md), [20.16](20.16_gb_responsibility_matrix.md).

#### CIL (Conversation Integration Layer) — [20.33](20.33_cil_requirements.md)

- **Focus:** Deterministic conversation intake, FIFO-preserving integration, snapshot coherence, and escalation to supervisory paths.
- **When:** Conversation layer; bridges external conversation events to TS intake boundaries.
- **Why:** Ordered, auditable conversation integration separate from basin-level meaning construction.
- **Is not:** InB (signal canonicalization); clarification **Path B** (user dialog track — distinct from Pipeline B); IIInB semantic repair; MTP merge authority.
- **Example:** Clarification turn completes → deterministic clarification event toward UPI pathway; FIFO `integration_seq` preserved across turns.
- **Normative home:** [20.33](20.33_cil_requirements.md), pins in [20.120](20.120_mtp_schema_requirements.md).

#### COB (Conversation Object Basin) — [20.32](20.32_cob_requirements.md)

- **Focus:** Conversation-object lifecycle: continuity identity, lineage, replay-horizon semantics, export/redaction policy.
- **When:** Conversation layer; governs durable conversation-object state and manifest linkage.
- **Why:** Long-horizon conversation continuity separate from per-cycle MTP meaning envelopes.
- **Is not:** MTP / `semantic_core` (per-cycle committed meaning); raw USP rule dump; TP lane-local state.
- **Example:** TP promotion to COB-visible object requires Merge-committed `semantic_core` ref; USP snapshot versions attach under COB policy scope.
- **Normative home:** [20.32](20.32_cob_requirements.md), promotion preconditions in [20.105](20.105_tp_requirements.md).

#### COP (Coprocessor) — [20.34](20.34_cop_requirements.md)

- **Focus:** Optional **propose-only** asynchronous subsystem with deterministic provenance and bounded queueing.
- **When:** Adjacent to TS; proposals evaluated at safe boundaries; basis pinned to `commit_id`.
- **Why:** Offload propose-only work without granting direct commit authority over meaning or governance.
- **Is not:** GB executor; meaning-construction primitive; silent semantic writer; InB/IIInB intake path.
- **Example:** Proposes IB lifecycle reshape action; GB commits or denies at safe boundary; proposal basis = `cop_basis_commit_id`.
- **Normative home:** [20.34](20.34_cop_requirements.md).

#### TR (Thought Router) — [20.37](20.37_thought_router_tr_specification.md)

- **Focus:** Deterministic derivation of stance/intent channels on TP (`TP.TR`) from semantic-relevant evidence and TR-input context.
- **When:** Pipeline A; runs when `tr_needs_update` is set; **not** in Pipeline B.
- **Why:** Centralized routing of interpretive stance fields without conflating with B-side trigger detection or lane fan-out.
- **Is not:** TrigRB (B semantic trigger detector); RB (relational fan-out); XlateR (B expression mapping); OB evidence extraction.
- **Example:** TB updates interpretation fields → sets `tr_needs_update = true` → TR recomputes `TP.TR` in fixed stage order; Type B correction may list TR in `allowed_basin_passes[]`.
- **Normative home:** [20.37](20.37_thought_router_tr_specification.md); namespace rule HLR-20.012-015 in [20.12](20.12_ts_invariants.md).

#### Pipeline A — [20.500](20.500_refactoring_for_dual_TS_pipeline.md), [20.206](20.206_pipeline_a_b_synchronization_contract.md)

- **Focus:** Lane-parallel **meaning construction**; sole writer of `semantic_core` until `mtp_update`.
- **When:** Per cycle; stage order: `input → routing → splitting → ob_processing → tb_interpretation → delta_h_normalization → merging → truth_done_evaluation → mtp_update`.
- **Why:** Committed meaning is constructed once per cycle with deterministic replay authority.
- **Is not:** Pipeline B (realization); strippable execution envelopes; seed-driven expression selection.
- **Example:** Overflow tagged in cycle N → `semantic_core` carries `overflow_flag`; Pipeline B may not schedule Type B IMR re-interpretation while flag is set.
- **Normative home:** [20.500](20.500_refactoring_for_dual_TS_pipeline.md) §1, fixtures in [20.36](20.36_canonical_end_to_end_trace.md).

#### Pipeline B (Execution Manifold) — [20.500](20.500_refactoring_for_dual_TS_pipeline.md), [20.206](20.206_pipeline_a_b_synchronization_contract.md)

- **Focus:** Singular **realization pass** per `commit_id` per cycle; planning and expression over frozen meaning snapshot.
- **When:** After Pipeline A `mtp_update`; order: `trig_rb → srp_lookup → exec_plan_commit → oub_expression → imr_evaluation`.
- **Why:** Expression and feedback are regenerable and strippable without altering committed meaning (except via approved Type B A-cycle).
- **Is not:** Lane-parallel meaning construction; TP input stage; authority to write `semantic_core` directly.
- **Example:** One XP segment per (`commit_id`, `cycle_id`) unless IMR Type A `xp_pass_seq` retry marker approves bounded retry.
- **Normative home:** [20.500](20.500_refactoring_for_dual_TS_pipeline.md), [20.207](20.207_execution_replay_specification.md).

#### TP (Thought Packet) — [20.105](20.105_tp_requirements.md)

- **Focus:** Lane-local mobile state unit carrying semantic fields, lineage, and basin I/O contracts.
- **When:** Pipeline A (lane-scoped); flows through splitting, basin passes, merge.
- **Why:** Parallel lanes need bounded, auditable per-lane state before global merge.
- **Is not:** MTP / `semantic_core` (global committed envelope); XP / `exec_plan` (B artifacts); COB conversation object.
- **Example:** Lane L2 TP carries OB `evidence_fields[]` → Merge contributes ΔH% slice → MTP draft → `mtp_update` freezes global `semantic_core`.
- **Normative home:** [20.105](20.105_tp_requirements.md).

#### MTP (Master Thought Packet) — [20.115](20.115_mtp_requirements.md), [20.120](20.120_mtp_schema_requirements.md)

- **Focus:** Global semantic state merged from lane TPs; pre-commit draft and post-`mtp_update` committed envelope host.
- **When:** Pipeline A merge and `mtp_update` stages.
- **Why:** Single authoritative meaning snapshot per cycle for Truth/Done, B handoff, and replay.
- **Is not:** Per-lane TP; B execution packet; COB durable object store.
- **Example:** Merge completes → `mtp_update` emits `commit_id` and `semantic_snapshot_ref` hash → Pipeline B consumes read-only snapshot.
- **Normative home:** [20.115](20.115_mtp_requirements.md), [20.120](20.120_mtp_schema_requirements.md).

#### `semantic_core` — [20.120](20.120_mtp_schema_requirements.md), [20.500](20.500_refactoring_for_dual_TS_pipeline.md)

- **Focus:** Authoritative **committed meaning envelope** after Pipeline A `mtp_update`.
- **When:** Frozen at `mtp_update`; read-only to Pipeline B and IMR evaluation; writable only via Pipeline A pathways (including bounded Type B correction cycles).
- **Why:** Replay-equivalent meaning partition separable from `exec_plan` / `exec_trace`.
- **Is not:** Draft pre-commit MTP; expression text; supervisory audit log; USP rule store.
- **Example:** Class 1 strip test: remove B envelopes → `semantic_core` byte-identical to A-only replay for same inputs.
- **Normative home:** [20.120](20.120_mtp_schema_requirements.md), envelope rule in [20.36](20.36_canonical_end_to_end_trace.md) HLR-20.036-008.

#### IIInB / UPI / USP (Input correction program — draft) — [20.500](20.500_refactoring_for_dual_TS_pipeline.md) §7.7

- **Focus:** Optional **pre–Pipeline A** semantic input repair using user-specific rules after clarification — not InB surface work.
- **When:** Profile-enabled path after InB surface norm: **`InB → IIInB → RB`**; stage wire **`input_semantic_repair`**; IIInB reads USP; UPI writes USP after clarification.
- **Why:** User shorthand and ambiguous meaning need bounded, auditable repair without overloading InB or IMR.
- **Is not:** InB; IB; IMR; GB lexicon; silent inference on unknown segments (escalate to clarification).
- **Example:** User says "easier/quicker-ish" → clarify → UPI writes USP rule → next turn IIInB applies bounded shorthand expansion before A.
- **Normative home:** Track H program in [20.510](20.510_refactoring_for_input_correction_track_h.md); closure decision in [20.500](20.500_refactoring_for_dual_TS_pipeline.md) §7.7 (spec draft pending).

### Tier 2 — Basin and Pipeline Boundaries

#### OB (Object Basin) — [20.40](20.40_ob_requirements.md)

- **Focus:** Lane-local evidence extraction, persistence, and object-semantics fields on TP.
- **When:** Pipeline A `ob_processing` stage.
- **Why:** Structured evidence without stance assignment or truth commitment.
- **Is not:** OpBeh (B planning primitive); semantic interpreter for final user text; TR derivator.
- **Example:** Extract `evidence_fields[]` from normalized intake; set dirty flags for downstream TB/TR — no `TP.TR` write.
- **Normative home:** [20.40](20.40_ob_requirements.md).

#### RB (Relational Basin) — [20.50](20.50_rb_requirements.md)

- **Focus:** Deterministic relational projection, routing, and fan-out to downstream basin targets.
- **When:** Pipeline A `routing` stage (and related transition control).
- **Why:** Governed movement between basins without B-side routing tables.
- **Is not:** SRP (cold B table compile); TrigRB (B hot trigger detector); Thought Router TR.
- **Example:** `MI_INCOMP` routes toward IB-Creation-Request pathway per policy — no silent gap-fill.
- **Normative home:** [20.50](20.50_rb_requirements.md).

#### TB (Truth Basin) — [20.60](20.60_tb_requirements.md)

- **Focus:** Truth interpretation: `truth_hypotheses`-compatible records and confidence shaping from OB evidence.
- **When:** Pipeline A `tb_interpretation` stage.
- **Why:** Explicit interpretation channel separate from final OuB surface and from Truth/Done terminal evaluation.
- **Is not:** Truth/Done evaluator ([20.140](20.140_truth_evaluation_requirements.md)); OuB expression; TR derivation (may set `tr_needs_update` only).
- **Example:** TB emits hypothesis band from evidence; may tag `MI_INCOMP` for IB pathway — does not generate user-facing answer text.
- **Normative home:** [20.60](20.60_tb_requirements.md).

#### DCB (Directional Conversation Basin) — [20.106](20.106_dcb_requirements.md)

- **Focus:** Geometric meta-basin observing TP trajectory position, direction, and curvature; emits ephemeral directional-change events.
- **When:** Pipeline A; geometry-only observation without OB-class semantic extraction authority.
- **Why:** Trajectory signals for TR without semantic interpretation authority.
- **Is not:** OB evidence extractor; semantic interpreter; persistent meaning field writer.
- **Example:** Curvature spike → ephemeral `directional-change event` as TR input; no OB semantics assigned.
- **Normative home:** [20.106](20.106_dcb_requirements.md).

#### MB (Monitoring Basin) — [20.70](20.70_mb_requirements.md)

- **Focus:** Non-intrusive diagnostic observation and telemetry export.
- **When:** Read-only across pipelines; consumes audit records including suppressed IMR entries.
- **Why:** Visibility without corrective authority.
- **Is not:** IMR trigger scheduler; GB policy engine; meaning or expression writer.
- **Example:** Observes `imr_cap_status = DEDUP_SUPPRESSED` on `imr_record` — does not reschedule correction.
- **Normative home:** [20.70](20.70_mb_requirements.md).

#### Merge / Splitting — [20.130](20.130_splitting_and_merging_requirements.md)

- **Focus:** Deterministic lane branch (split) and lane combine (merge) with `lineage_delta` and ΔH% accounting.
- **When:** Pipeline A `splitting` and `merging` stages.
- **Why:** Parallel trace handling (`MI_CONTRA`) and global MTP assembly with auditable lineage.
- **Is not:** Pipeline B realization; TP promotion to COB; IB lifecycle merge.
- **Example:** `MI_CONTRA` forks `T_a` / `T_b` with shared `conflict_group_id` → separate lane TPs → Merge yields single MTP draft with recorded missing mass.
- **Normative home:** [20.130](20.130_splitting_and_merging_requirements.md), [20.17](20.17_messy_input_handling.md).

#### OpBeh / OBG / XlateR (B planning triple) — [20.41](20.41_opbeh_requirements.md), [20.42](20.42_obg_requirements.md), [20.43](20.43_xlater_requirements.md)

- **Focus:** B-side operational behavior selection, voice/register identity, and expression mapping on `exec_plan`.
- **When:** Pipeline B planning before OuB; recorded on `exec_plan` envelope.
- **Why:** Namespace-distinct execution primitives (HLR-20.012-015) — never alias OB/TR/RB.
- **Is not:** OB/TR/RB basins; seed does not pick OpBeh identity (planning is deterministic from frozen meaning + tables).
- **Example:** `exec_plan` carries `opbeh_id`, `obg_id`, `xlater_id` — OuB consumes plan; random seed affects expression pick only within OuB boundary.
- **Normative home:** [20.41](20.41_opbeh_requirements.md), [20.42](20.42_obg_requirements.md), [20.43](20.43_xlater_requirements.md).

#### TrigRB — [20.57](20.57_trigrb_requirements.md)

- **Focus:** B hot-path semantic trigger detection over frozen `semantic_core`.
- **When:** Pipeline B first stage after `mtp_update`.
- **Why:** Detect realization-relevant triggers without aliasing TR or RB.
- **Is not:** TR (Thought Router); RB (Relational Basin); SRP compiler.
- **Example:** Reads committed snapshot fields → emits trigger codes consumed by SRP lookup — no lane routing.
- **Normative home:** [20.57](20.57_trigrb_requirements.md).

#### SRP (Semantic Routing Planner) — [20.55](20.55_srp_requirements.md)

- **Focus:** Cold-path routing table compile; hot path = deterministic lookup by `routing_epoch_id`.
- **When:** B planning; publishes `routing_epoch_id` on B envelopes only.
- **Why:** Separates table maintenance from A-cycle RB fan-out.
- **Is not:** RB (Pipeline A); IMR (may consume `routing_epoch_id` read-only only).
- **Example:** Policy update compiles epoch E17 → B envelopes carry `routing_epoch_id = E17` → hot lookup selects OpBeh row — no A-cycle write.
- **Normative home:** [20.55](20.55_srp_requirements.md).

#### XP / `exec_plan` / `exec_trace` — [20.500](20.500_refactoring_for_dual_TS_pipeline.md), [20.207](20.207_execution_replay_specification.md)

- **Focus:** **XP** indexes one `exec_plan` + `exec_trace` (+ B audit) per `commit_id`; B audit partition strippable from meaning replay.
- **When:** Pipeline B; one logical XP per (`commit_id`, `cycle_id`) except approved IMR Type A retries.
- **Why:** Execution artifacts are regenerable; meaning replay uses `semantic_core` alone.
- **Is not:** TP; MTP; `semantic_core`; supervisory queue (separate envelope).
- **Example:** `exec_plan` frozen at commit; `exec_trace` holds OuB refs and `imr_record` entries append-only.
- **Normative home:** [20.500](20.500_refactoring_for_dual_TS_pipeline.md) §1.4, [20.207](20.207_execution_replay_specification.md).

#### `commit_id` / `semantic_snapshot_ref` — [20.120](20.120_mtp_schema_requirements.md), [20.36](20.36_canonical_end_to_end_trace.md)

- **Focus:** `commit_id` = post-`mtp_update` freeze marker; `semantic_snapshot_ref` = content-hash (or debug ref) of committed meaning at handoff.
- **When:** Emitted at `mtp_update`; consumed by B and IMR read-only.
- **Why:** Replay vocabulary tying A commit to B realization scope.
- **Is not:** `mtp_snapshot_id` (deprecated alias for `commit_id`); draft pre-commit ref (use `mtp_draft_snapshot_ref` where applicable).
- **Normative home:** [20.120](20.120_mtp_schema_requirements.md), [20.36](20.36_canonical_end_to_end_trace.md) HLR-20.036-048/050.

#### `routing_epoch_id` — [20.55](20.55_srp_requirements.md), [20.45](20.45_imr_requirements.md)

- **Focus:** Published SRP table epoch identifier carried on B envelopes and IMR audit records.
- **When:** B envelopes only; IMR consumes read-only; IMR SHALL NOT advance epoch.
- **Why:** Bind execution planning to a specific compiled routing table version.
- **Is not:** A-cycle RB routing state; mutable by IMR or OuB.
- **Normative home:** [20.55](20.55_srp_requirements.md), HLR-20.045-034 in [20.45](20.45_imr_requirements.md).

### Tier 3 — Metrics and Cross-Cutting Taxonomies

#### ΔH% (DeltaHPercent) — [20.130](20.130_splitting_and_merging_requirements.md), [20.115](20.115_mtp_requirements.md)

- **Focus:** Normalized per-lane hypothesis contribution metric at merge; missing mass logged on truncate.
- **When:** Pipeline A merge and ΔH normalization stages.
- **Why:** Auditable hypothesis mass accounting under overflow and underspec.
- **Is not:** Truth commitment; TCU; entropy functional (see Unified Entropy in registry).
- **Example:** `MI_VAGUE` unresolved slot increments missing-mass field; merge record lists per-lane ΔH% contributions.
- **Normative home:** [20.130](20.130_splitting_and_merging_requirements.md).

#### HPercent / `truth_hypotheses` — [20.60](20.60_tb_requirements.md), [20.140](20.140_truth_evaluation_requirements.md)

- **Focus:** Truth/uncertainty evaluation state bands feeding Truth/Done — not terminal completion by itself.
- **When:** TB writes hypotheses; Truth/Done reads downstream.
- **Why:** Separate interpretation output from done/terminal evaluation.
- **Is not:** `done_state` ([20.140](20.140_truth_evaluation_requirements.md)); user satisfaction signal; OuB text.
- **Example:** TB emits hypothesis band → Truth/Done evaluates `done_state` — "user satisfied" is external, not `done_state`.
- **Normative home:** [20.60](20.60_tb_requirements.md), [20.140](20.140_truth_evaluation_requirements.md).

#### TCU — [20.30](20.30_ts_functional_model.md)

- **Focus:** Normalized compute-cost unit for bounded resource accounting across primitives.
- **When:** Reported per tick / per primitive budget tables.
- **Why:** Deterministic cost envelopes for overload and degradation policy.
- **Is not:** Wall-clock time; token count from external LLM APIs (unless mapped by profile).
- **Example:** OpBeh plan cost vs OuB expression cost recorded separately in `exec_trace` budget fields.
- **Normative home:** [20.30](20.30_ts_functional_model.md).

#### Random Seed Boundary — [20.12](20.12_ts_invariants.md), [20.207](20.207_execution_replay_specification.md)

- **Focus:** Isolation rule confining nondeterministic selection to output expression/realization fields within B boundary.
- **When:** OuB / expression selection under `seed_scope`.
- **Why:** Meaning replay invariant: same inputs → same `semantic_core`; seed varies surface only.
- **Is not:** OpBeh planning identity selection; A-cycle basin ordering.
- **Example:** Seed A vs Seed B with identical `semantic_core` → `exec_trace` expression fields differ; `semantic_core` diff empty.
- **Normative home:** [20.12](20.12_ts_invariants.md), Class 1 assertions in [20.36](20.36_canonical_end_to_end_trace.md).

#### Truth/Done — [20.140](20.140_truth_evaluation_requirements.md)

- **Focus:** Downstream terminal evaluation over `truth_hypotheses` and `done_state` — strictly after interpretation stages.
- **When:** Pipeline A `truth_done_evaluation` before `mtp_update`.
- **Why:** Explicit completion detection separate from user feedback (IMR) and from TB interpretation output.
- **Is not:** IMR satisfaction; IB resolution; OuB delivery event.
- **Example:** `done_state` reached under clean completion rules — independent of whether user later files Type A IMR stylistic complaint.
- **Normative home:** [20.140](20.140_truth_evaluation_requirements.md).

#### Messy-input taxonomy (`MI_*`) — [20.17](20.17_messy_input_handling.md)

Not a single primitive — canonical detector classes on Pipeline A intake/meaning path:

| Class | Focus | Mini-example |
|-------|--------|--------------|
| `MI_CONTRA` | Mutually incompatible propositions in scope | "It is safe" + "It is dangerous" → parallel traces |
| `MI_VAGUE` | Underspecified referents/constraints | "Make it better" → `underspec_slots[]`, no default fill |
| `MI_AFFECT` | Affect tagging without propositional resolution | Tone marker only — does not resolve `MI_VAGUE` |
| `MI_INCOMP` | Commitment-blocked incompleteness | Missing slots → IB-Creation-Request queue |
| `MI_NOISE` | Surface noise (InB canonicalization scope) | Typos / encoding glitches — non-inferential fix |

- **Normative home:** [20.17](20.17_messy_input_handling.md).

## Wire Terms and IMR Taxonomy

### IB-Creation-Request — [20.17](20.17_messy_input_handling.md), [20.30](20.30_ts_functional_model.md)

- **Focus:** Supervisory-queue wire requesting GB evaluation before IB instantiation.
- **When:** Emitted on `MI_INCOMP` / incomplete-meaning detection; OuB may schedule via supervisory queue only.
- **Is not:** IB state; automatic inquiry; IMR trigger.
- **Normative home:** HLR-20.017-014/029, HLR-20.030-233 in parent modules.

### `evaluator_signal` / `evaluator_signal_code`

- **Focus:** Deterministic coded input to IMR classification — reproducible from artifact refs and policy tables, no latent inference.
- **When:** IMR evaluation stage; hashed into dedup key with `(trigger_type, exec_plan_ref, oub_artifact_ref)`.
- **Is not:** Free-text user message stored opaquely; IB clarification payload; IIInB repair hint.
- **Normative home:** HLR-20.045-002/018 in [20.45](20.45_imr_requirements.md).

### IMR Types A / B / C — [20.45](20.45_imr_requirements.md)

| Type | Name | Corrective authority |
|------|------|----------------------|
| **A** | Expression mismatch | Realization retry only (same `semantic_snapshot_ref`); no A writes |
| **B** | Semantic mismatch | May emit `CorrectionTrigger` for bounded partial A-cycle on listed fields |
| **C** | Safety mismatch | GB-gated; supervisory actions; no silent semantic rewrite |

- **Precedence:** Mixed signals resolve **C > B > A** with audit of suppressed secondary classes.
- **Normative home:** [20.45](20.45_imr_requirements.md) §IMR Trigger Taxonomy.

### `CorrectionTrigger` — [20.45](20.45_imr_requirements.md)

- **Focus:** Append-only supervisory signal scheduling bounded corrective pathways (A retry, B re-interpretation, or C GB route).
- **When:** Emitted by IMR; Type B consumed by Pipeline A **next cycle** only; `max_depth_remaining` enforced.
- **Is not:** Direct `semantic_core` write; chained B→A→B loop in same cycle.
- **Normative home:** [20.45](20.45_imr_requirements.md) §CorrectionTrigger Schema.

### `imr_record`

- **Focus:** Append-only IMR evaluation audit block on `exec_trace` including cap/dedup/cooldown visibility.
- **When:** Every IMR evaluation, including suppressed triggers.
- **Normative home:** [20.45](20.45_imr_requirements.md) §Required audit fields.

## Four-Envelope Model — [20.36](20.36_canonical_end_to_end_trace.md) HLR-20.036-008

| Envelope | Primary writers | Replay role |
|----------|-----------------|-------------|
| **`semantic_core`** | Pipeline A (`mtp_update`) | **Authoritative** meaning replay |
| **`exec_plan`** | Pipeline B planning | Strippable; regenerable |
| **`exec_trace`** | OuB, IMR | Strippable; regenerable |
| **`supervisory`** | GB, IMR triggers | Bounded triggers; append-only audit |

XP logically indexes `exec_plan` + `exec_trace` per `commit_id`. Stripping B envelopes shall yield `semantic_core` equivalent to A-only replay per HLR-20.012-011 ([20.12](20.12_ts_invariants.md)).

## Input Correction Terms (Track H — draft)

**Closure line (2026-06-07):** InB corrects surface form deterministically; semantic input error correction is a separate, profiled pre–Pipeline A program (**IIInB + clarification + UPI/USP**), not an InB, IB, or IMR responsibility.

| Term | Role |
|------|------|
| **Semantic input error correction** | Pre–Pipeline A repair of user-specific or ambiguous meaning; out of scope for InB |
| **IIInB** | Optional `input_semantic_repair` stage after InB (`InB → IIInB → RB`); consults USP; escalates unknowns to clarification |
| **UPI** | Writes user-specific shorthand rules to USP after clarification |
| **USP** | Versioned auditable rule store; read-only to IIInB at intake; governed under COB/GB policy |

- **Normative home:** [20.510](20.510_refactoring_for_input_correction_track_h.md); detail spec pending in 20.101–20.103.

## System Overview (Compact)

- **Thought Simulator (TS):** Deterministic fixed-tick engine for structured meaning construction and governed realization ([20.12](20.12_ts_invariants.md)).
- **Thought:** Minimal semantic unit represented and transformed within TS processing.
- **Observer (External):** Actor outside TS submitting inputs and receiving outputs.
- **Basin:** Deterministic processing container with bounded state and transition rules (primitive basins defined in catalog above).
- **Tick Cycle / TS Step Index:** One deterministic simulation update interval; monotonic step index ([20.30](20.30_ts_functional_model.md)).
- **Deterministic Mode:** Reproducible behavior under identical inputs, signature, and seed conditions.
