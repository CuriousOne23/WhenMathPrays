# 20.120 MTP Schema Requirements

## Normative Requirements
1. HLR-20.120-001: MTP schema SHALL define explicit fields for stance, affect, intent, hypotheses, and lineage.
2. HLR-20.120-002: Schema changes SHALL be versioned and backward-compatibility reviewed.
3. HLR-20.120-003: MTP updates SHALL be field-wise deterministic.
4. HLR-20.120-004: MTP records SHALL include identifiers required for replay and audit.
5. HLR-20.120-005: MTP schema SHALL include deterministic sequence-token and FIFO index fields required for CIL and COB ordering integrity.
6. HLR-20.120-006: MTP schema SHALL include deterministic snapshot and replay identifiers required for CIL snapshot coherence and COB replay-evidence linkage.
7. HLR-20.120-007: MTP schema SHALL include execution-signature/profile-version binding fields required for deterministic profile precedence across CIL, COB, and COP integrations.
8. HLR-20.120-008: MTP schema SHALL include lifecycle/audit correlation identifiers sufficient to trace CIL integration events, COB lifecycle transitions, and COP-visible proposal outcomes.
