# **20.40.060.700 — OuBA Field Reference (v0.5)**  
**Status:** Informational Reference  
**Scope:** Defines the meaning, origin, and consumption of all TP → OuBA → SSR fields for COB, CST, and Path B.  
**Excludes:** Normative requirements, Path‑A semantics, Path‑B truth determination logic, realization behavior.

---

# **0. Introduction**

This reference document explains the fields that flow through the OuBA primitive.  
These fields originate in the Thought Processor (TP), are frozen by OuBA, and are consumed by:

- **COB behavior engines**  
- **CST truth‑alignment engines**  
- **Path B truth and safety engines** *(tentative)*

Each field is described in terms of:

- what it **is**  
- what it **is not**  
- where it is **produced**  
- where it is **consumed**  
- a **realistic example**  

This document contains **no normative requirements**.

---

# **1. Purpose**

The purpose of this reference is to provide clear, architectural definitions for all fields present in:

- TP semantic state  
- TP metadata state  
- TP context state  
- OuBA input object  
- SSR output object  

This document helps readers understand the meaning and lifecycle of each field without needing to infer semantics from other specifications.

# **3. Field Definitions (with examples)**

All fields now include **COB**, **CST**, and **Path B** consumption.

---

## **3.1 `proposition_set[]`**

### **What it is**  
Meaning‑level propositions extracted or constructed during Path A processing.

### **What it is not**  
Not truth tags.  
Not safety flags.  
Not a logical proof.  
Not a global meaning store.

### **Produced by**  
OB, IB, TB.

### **Consumed by**  
COB behavior engines, CST truth‑alignment engines, Path B truth and safety engines.

### **Example**  
```
proposition_set[] = [
  "The user wants to compare two operating systems.",
  "The user expresses a preference for privacy.",
  "The user is considering switching to Zorin OS."
]
```

---

## **3.2 `truth_evidence[]`**

### **What it is**  
Raw meaning‑level evidence supporting or contradicting propositions.

### **What it is not**  
Not truth determinations.  
Not safety flags.  
Not authoritative truth.

### **Produced by**  
OB, IB; TB may annotate.

### **Consumed by**  
COB, CST, Path B.

### **Example**  
```
truth_evidence[] = [
  { "type": "support", "source": "OB", "detail": "User explicitly states preference." },
  { "type": "support", "source": "TB", "detail": "Lexical consistency across sentences." },
  { "type": "contradiction", "source": "OB", "detail": "Ambiguous phrasing in second clause." }
]
```

---

## **3.3 `completion_state`**

### **What it is**  
Indicator of whether TP meaning construction reached a stable state.

### **What it is not**  
Not truth.  
Not epistemic.  
Not safety.

### **Produced by**  
TP completion logic.

### **Consumed by**  
OuBA freeze, COB, CST, Path B.

### **Example**  
```
completion_state = "complete"
```

---

## **3.4 `h_percent`**

### **What it is not**

Not evidence.

### **Produced by**

### **Consumed by**  
COB, CST, Path B.

### **Example**


# **3.11 `TP.next_context.*` (COB‑required)**

### **What it is**  
Next‑turn context fields produced by TP for COB and CST.

Includes:

- topic  
- stance  
- intent  
- register  
- politeness  
- epistemic shading  
- continuity  
- direction  
- coherence  
- shift_required  
- importance  
- clarifying_fields[]  

### **What it is not**  
Not semantic propositions.  
Not truth evidence.

### **Produced by**  
TP context subsystem.

### **Consumed by**  
COB behavior engines, CST truth‑alignment engines.

### **Example**  
```
TP.next_context = {
  "topic": "OS_migration",
  "stance": "neutral",
  "intent": "informational",
  "register": "technical",
  "continuity": "maintain",
  "importance": 0.74
}
```

All fields originate in TP, are frozen by OuBA, and are consumed by:

- **COB behavior engines**
