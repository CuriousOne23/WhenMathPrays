# **1. Purpose**

This document defines the **complete, self‑contained architectural scaffold** required to run a **deterministic Path A logic simulation** using only:

1. **This document**, and  
2. **path_a_full_context_imr_test_run_cp.md**

No other 20‑series documents are required.

This scaffold includes:

- unified TP datapacket  
- explicit primitive read/write tables  
- envelope‑grouped field lists  
- deterministic entropy model  
- deterministic routing model  
- deterministic identity/provenance model  
- unified refinement loop  
- deterministic termination rules  
- deterministic early‑exit rules  
- TPU commit semantics  
- OuBA freeze rules  
- step‑by‑step simulation procedure  

IMR is removed.  
All metadata formerly carried by IMR is now stored directly in TP.

# **9. Deterministic Refinement Loop (Corrected)**

If **delta_h_percent > 0.25**, run:

```
IdOB → RBU → TR → CTP → ISc → RTU → RB
```

Repeat until **delta_h_percent ≤ 0.25**.

This is the canonical loop.

---

# **10. Deterministic Early‑Exit Requirements**

Early termination (ISc → OuBA) is allowed only if:

### **Semantic**
- `proposition_set[]`  
- `truth_evidence[]`  
- `semantic_tags[]`  
- `smob_semantic_geometry`

### **Context**
- full context envelope populated

### **Structural**
- `sob_structural_map`  
- `srob_structural_map`

### **Metadata**
- `delta_h_percent`  
- `entropy_history[]`  
- `difficulty_rating`  
- `mismatch_tags[]`  
- `anomaly_flags[]`

### **Provenance**
- `sob_id`  
- `srob_id`  
- `cnob_id`  
- `smob_id`

If any required field is missing, early exit is not permitted.

---

# **11. Deterministic Termination Criteria**

Termination requires:

1. `delta_h_percent ≤ 0.25`  
2. `smob_semantic_geometry` unchanged across last two cycles  
3. `context envelope` unchanged across last two cycles  
4. `cob_state_snapshot` unchanged across last two cycles  
5. `routing_path` ends in `stable`  

All five conditions must be met.

---

# **12. OuBA Freeze**

OuBA produces TPSnS containing:

- all envelopes  
- all provenance  
- all metadata  
- freeze fields  
- commit hash  
- commit timestamp  
- routing epoch  

TPSnS is immutable.

# **13. Simulation Procedure (Aligned + Deterministic)**

### **Step 1 — Intake**
InB → IIInB → IE

### **Step 2 — Context Extraction**
CEx → CE

### **Step 3 — Structural Pass**
SOB → SROB → CnOB → SmOB

### **Step 4 — Entropy Check**
ISc  
If stable → OuBA  
Else → continue

### **Step 5 — Meaning Construction**
SSG → STPX → RBU → TR → CTP → ISc → RTU → RB

### **Step 6 — Refinement Loop**
If RB says refine → run canonical loop:  
`IdOB → RBU → TR → CTP → ISc → RTU → RB`  
Repeat until stable.

### **Step 7 — OuBA Freeze**
Produce TPSnS.  
Simulation ends.
