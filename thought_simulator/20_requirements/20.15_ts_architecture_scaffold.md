# **1. Purpose of This Document**

This document defines the **complete, self‑contained architectural scaffold** required to run a **deterministic, faithful Path A logic simulation** without referencing any other 20‑series specifications.

It is designed so that **any AI** (Copilot, Grok, Claude, etc.) can:

1. Read **this document**  
2. Read the **path_a_full_context_imr_test_run_cp.md** example  
3. Perform a **correct, deterministic Path A simulation** on any input  

This scaffold includes:

- the full Path A pipeline  
- the unified TP datapacket  
- explicit read/write tables for every primitive  
- envelope‑grouped field lists  
- entropy model  
- routing model  
- identity/provenance model  
- refinement loop  
- termination rules  
- OuBA freeze rules  
- simulation procedure  

IMR is **removed**.  
All metadata formerly carried by IMR is now stored directly in the unified TP datapacket.

# **3. Full Path A Pipeline (Simulation Form)**

```
InB → IIInB → IE → CEx → CE → TPU
→ SOB → SROB → CnOB → SmOB → ISc
→ SSG → STPX → RBU → TR → CTP → ISc
→ RTU → RB → IdOB → RBU → … (refinement loop)
→ OuBA → TPSnS
```

IMR is removed.  
All metadata formerly carried by IMR is now read directly from TP.

# **9. Refinement Loop**

If **delta_h_percent > 0.25**, run:

```
IdOB → RBU → TR → CTP → ISc → RTU → RB
```

Repeat until **delta_h_percent ≤ 0.25**.

---

# **10. Termination Rules**

Terminate when:

- `delta_h_percent ≤ 0.25`  
- semantic geometry stable  
- context envelope coherent  
- identity snapshot stable  
- routing vector indicates stability  

Then run OuBA.

---

# **11. OuBA Freeze**

OuBA produces TPSnS containing:

- all envelopes  
- all provenance  
- all metadata  
- freeze fields  
- commit hash  
- commit timestamp  
- routing epoch  

TPSnS is immutable.

---

# **12. Simulation Procedure (Step‑by‑Step)**

This is the exact procedure an AI must follow.

### **Step 1 — Intake**
InB → IIInB → IE

### **Step 2 — Context Extraction**
CEx → CE

### **Step 3 — Structural Pass**
SOB → SROB → CnOB → SmOB

### **Step 4 — Entropy Check**
ISc  
If stable → OuBA  
Else → continue

### **Step 5 — Meaning Construction**
SSG → STPX → RBU → TR → CTP → ISc → RTU → RB

### **Step 6 — Refinement Loop**
If RB says refine → repeat Step 5  
If RB says terminate → OuBA

### **Step 7 — OuBA Freeze**
Produce TPSnS  
Simulation ends.
