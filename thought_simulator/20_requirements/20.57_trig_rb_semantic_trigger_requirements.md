# 20.57 TrigRB (Semantic Trigger) Requirements

**Document ID:** 20.57  
**Version:** 0.1  
**Date:** 2026-06-06  
**Status:** Approved v0.1 — Stage 4 GATE (2026-06-07; CuriousOne23, Copilot, Grok)

## Purpose

Defines **TrigRB** — the Pipeline B **semantic trigger detector** on the hot path. TrigRB evaluates frozen `semantic_core` and emits `exec_trigger_id` / trigger class codes for SRP row lookup.

**Namespace:** TrigRB ≠ Thought Router **TR** ≠ Relational Basin **RB** (HLR-20.012-015, 20.50 HLR-20.050-037).

**Stage order clarification (draft):** trig_rb → srp_lookup → exec_plan_commit — TrigRB fires first; SRP uses trigger output. This order is normative and aligned with 20.36 v0.4 and 20.207.

---

## 1. Boundary

1. **HLR-20.057-001:** TrigRB SHALL execute only on Pipeline B after `mtp_update` for the active `commit_id`.
2. **HLR-20.057-002:** TrigRB inputs SHALL be frozen `semantic_core` fields only — no TP, no `lane_id`, no RB `routing_metadata`.
3. **HLR-20.057-003:** TrigRB SHALL NOT write `semantic_core`, MTP, or TP fields.

---

## 2. Detection Semantics

4. **HLR-20.057-004:** TrigRB SHALL map explicit `semantic_core` signals (e.g. `done_state`, `messy_input_record` flags, `thought_router_fields` read-only semantics) to deterministic trigger class codes.
5. **HLR-20.057-005:** Trigger detection SHALL be reproducible from `(semantic_snapshot_ref, policy_signature)` with no seed influence (HLR-20.012-010).
6. **HLR-20.057-006:** TrigRB SHALL emit zero or more `exec_trigger_id` values per B pass; multiple triggers SHALL be canonically ordered before SRP consumption.

```text
trig_rb_output {
  commit_id,
  cycle_id,
  exec_trigger_ids[],       // canonical sort
  trigger_classes[],
  detection_rationale_codes[]
}
```

7. **HLR-20.057-007:** TrigRB SHALL append `trig_rb_record` to `exec_trace` before SRP lookup completes.

---

## 3. Hot-Path Constraints

8. **HLR-20.057-008:** TrigRB SHALL NOT compile routing tables (SRP cold path only).
9. **HLR-20.057-009:** TrigRB SHALL NOT resolve `(opbeh_id, obg_id, xlater_id)` triples — only trigger codes for SRP/20.41–43 chain.
10. **HLR-20.057-010:** TrigRB SHALL carry `routing_epoch_id` as read-only metadata on output records.

---

## 4. Messy-Input and Done-State Gating

11. **HLR-20.057-011:** TrigRB MAY read `messy_input_record` and `done_state` for trigger gating but SHALL NOT clear or smooth those fields (20.17, 20.31).
12. **HLR-20.057-012:** Under `overflow_flag`, TrigRB SHALL apply deterministic degraded trigger set per policy table with `trig_degraded_mode = true` logged.

---

## 5. Verification

13. **HLR-20.057-013:** Identical frozen `semantic_core` → identical `exec_trigger_ids[]` ordering.
14. **HLR-20.057-014:** Negative: TrigRB input includes `tp_id` → `FAIL_B_FORBIDDEN_TP_READ`.
15. **HLR-20.057-015:** Namespace audit: no identifier collision with TR/RB in fixtures.
