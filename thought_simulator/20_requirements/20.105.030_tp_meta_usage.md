# **20.105.030_tp_meta_usage.md**  
### **TP Metadata Usage — Downstream Consumption, Meaning Refinement, and Structural Interpretation**

---

## **1. Purpose**
This document defines how downstream primitives consume metadata fields within the Thought Packet (TP).  
Metadata usage ensures deterministic meaning refinement, stable routing, consistent truth‑relation mapping, and coherent conversation‑layer continuity.

---

## **2. Scope**
This specification covers:

- downstream consumption rules  
- read‑only constraints  
- usage boundaries  
- meaning‑refinement dependencies  
- structural and routing dependencies  

It does **not** redefine metadata fields (20.105.010) or provenance rules (20.105.020).

---

## **3. Metadata Usage Model**
Downstream primitives consume metadata fields produced upstream.  
Consumption is **read‑only**, except where a primitive is explicitly authorized to update a specific metadata field.

Metadata usage supports:

- identity‑conditioned meaning refinement  
- truth‑relation mapping  
- structural interpretation  
- routing‑conditioned semantics  
- entropy trajectory evaluation  
- conversation‑layer continuity

---

## **4. Normative Requirements**

### **4.1 Read‑Only Consumption**
**HLR‑20.105.030‑001**  
Downstream primitives **shall** treat all metadata fields as read‑only unless explicitly authorized to update a specific field.

### **4.2 Upstream Observation Preservation**
**HLR‑20.105.030‑002**  
Downstream primitives **shall** preserve upstream metadata observations without modification.

### **4.3 Meaning‑Refinement Usage**
**HLR‑20.105.030‑003**  
IdOB **shall** consume expressive_metadata, normalization_metadata, and structural_metadata when performing identity‑conditioned meaning refinement.

### **4.4 Truth‑Relation Usage**
**HLR‑20.105.030‑004**  
TR **shall** consume structural_metadata, routing_metadata, and expressive_metadata when mapping truth‑relations.

### **4.5 Routing‑Conditioned Usage**
**HLR‑20.105.030‑005**  
IdOB and TR **shall** consume routing_metadata when performing identity‑conditioned or truth‑conditioned interpretation.

### **4.6 Entropy Usage**
**HLR‑20.105.030‑006**  
OuBA **shall** consume entropy_metadata when producing the SSR‑A snapshot.

### **4.7 Continuity Usage**
**HLR‑20.105.030‑007**  
COB, CIL, and CST **shall** consume continuity_metadata when maintaining identity continuity, long‑horizon context, and stability evaluation.

### **4.8 No Re‑Derivation**
**HLR‑20.105.030‑008**  
Downstream primitives **shall** not re‑derive upstream observations already encoded in metadata fields.

### **4.9 Deterministic Replay**
**HLR‑20.105.030‑009**  
Metadata usage **shall** support deterministic replay, ensuring identical downstream behavior when the same TP is re‑executed.

---

## **5. Downstream Consumption Responsibilities**

### **5.1 IdOB**
Consumes:

- expressive_metadata  
- normalization_metadata  
- structural_metadata  
- routing_metadata  

IdOB uses metadata to refine meaning without modifying TP fields directly.

### **5.2 TR**
Consumes:

Consumes:
- TP.metadata.structural_metadata
- TP.metadata.routing_metadata
- TP.metadata.expressive_metadata

TR uses metadata to compute truth‑relations and update TP.TR.  
TR does not consume entropy_metadata.

### **5.3 OuBA**
Consumes:

- entropy_metadata  
- routing_metadata  
- structural_metadata  
- continuity_metadata  

OuBA produces SSR‑A using all relevant metadata.

### **5.4 COB / CIL / CST**
Consume:

- continuity_metadata  
- entropy_metadata  
- identity_anchors  
- referent_lineage  

These primitives maintain conversation‑layer stability and identity continuity.

---

## **6. Metadata Usage Equations**

### **6.1 Truth‑Relation Dependency**
Truth‑relation mapping depends on structural and routing metadata:

$$
TR = f(\text{structural}\_{metadata},\ \text{routing}\_{metadata},\ \text{expressive}\_{metadata})
$$

### **6.2 Meaning‑Refinement Dependency**
Identity‑conditioned meaning refinement depends on expressive and structural metadata:

$$
\text{IdOB}\_{meaning} = g(\text{expressive}\_{metadata},\ \text{normalization}|\_{metadata},\ \text{structural}\_{metadata})
$$

### **6.3 Entropy Update Rule**
Entropy trajectory is updated using:

$$
\Delta H\\% = \frac{H_{\text{current}} - H_{\text{previous}}}{H_{\text{previous}}} \times 100
$$
