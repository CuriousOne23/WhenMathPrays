# **II. TS PROCESSES**  
*(Processes performed *inside* primitives — not pipeline nodes)*

These are **not primitives** and must **never** appear in flow diagrams.

- **Merge** — Performed *inside TPU*  
- **Scoring** — Performed inside ISc  
- **Normalization** — Performed inside IIInB  
- **Semantic Collapse** — Performed inside OB  
- **Routing Arbitration** — Performed inside RB  
- **Clarification Triggering** — Performed inside IB  
- **Truth Evaluation** — Performed inside TB  
- **Global Constraint Enforcement** — Performed inside GB  

### **HLRs that govern processes**  
These HLRs apply to process behavior *inside* primitives:

- **HLR‑20.020‑012** (non‑overlapping responsibilities)  
- **HLR‑20.020‑013** (deterministic interfaces)  
- **HLR‑20.020‑014** (observability)  
- **HLR‑20.020‑015** (TCU cost metrics)  
- **HLR‑20.020‑016** (platform independence)  
- **HLR‑20.020‑017** (deterministic composition)  
- **HLR‑20.020‑018** (meaning stability)  
- **HLR‑20.020‑023** (Merge → TPU update envelope rules)  
- **HLR‑20.020‑024** (ISc → COP → Merge → TPU replay equivalence)

# **III. TS REFERENCE OBJECTS**  
*(Non‑pipeline, read‑only, global or contextual structures)*

These objects **inform** primitives but are **not primitives** themselves.

- **CIL** — Conversation Integration Layer  
- **COB** — Conversation Object Bank  
- **USP** — User State Profile  
- **MTP slices** — Referenced by CEx  
- **Lineage identifiers**  
- **Commitment structures**  
- **Active referent sets**  
- **Thread geometry**  

### **HLRs that govern reference objects**  
Reference objects are governed indirectly by:

- **HLR‑20.020‑012** (non‑overlap with primitives)  
- **HLR‑20.020‑014** (observability)  
- **HLR‑20.020‑016** (platform independence)

# **IV. TS GOVERNING OBJECTS**  
*(Supervisory, policy‑enforcing, post‑TS entities)*

These objects govern correctness, truth, and global constraints.

- **GB** — Governing Basin  
- **GBIB** — Governance for IB/TB  
- **TB** — Truth Basin (post‑TS)  
- **IB** — Inquiry Basin (post‑TS)  

### **HLRs that govern governing objects**

- **HLR‑20.020‑010** (IB triggers)
