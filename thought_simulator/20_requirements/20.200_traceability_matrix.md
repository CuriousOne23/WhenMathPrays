## Rules
1. HLR-20.200-001: Every 20-series requirement doc SHALL map to verification and design anchors.
2. HLR-20.200-002: Trace rows SHALL be updated in the same change set when 20-series docs are added, removed, or renamed.
3. HLR-20.200-003: No downstream layer edits SHALL be auto-executed from this matrix without explicit user direction.
