## TS-Level Invariants Summary
- **A/B Separation**: Path A constructs meaning deterministically (TPU is sole writer); Path B performs realization only (read-only on committed meaning).
- **Single-Writer Rule**: TPU is the only primitive allowed to modify TP in Path A.
- **Determinism & Replay-Safety**: All Path A operations are fully deterministic and replayable. Nondeterminism is isolated to Path B expression via the Random Seed Boundary.
- **Monotonic Entropy Reduction**: OB layers (SOB → SROB → CnOB → SmOB) reduce uncertainty; ΔH% tracks incremental changes (see 20.710).
- **Pre-Semantic Boundaries**: No semantic interpretation before SmOB.
- **Governance Gates**: TPTB, TPSF, and GBIB operate only on committed meaning from OuBA.
- **Provenance & Traceability**: All OB structures must carry complete provenance (see 20.710 normative structures).
- **Pluggability**: Rulesets and routing policies are swappable without violating structural invariants.
