# 20.30.085 Relational Semantic Geometry Primitive (RSG)**

### 1. Introduction (informative)
Relational Semantic Geometry (RSG) is the manifold-mapping primitive of the Thought Simulator. It transforms a Semantic State Representation SSR(t) into deterministic geometric structures within the engineered cognitive manifold. RSG performs no surface-form generation, stylistic variation, or lexical assembly. Its sole responsibility is to map meaning into stable geometric coordinates, basins, and relational structures for subsequent realization by RG.

### 2. Purpose (informative)
The purpose of RSG is to provide a deterministic, manifold-anchored geometric representation of meaning. It bridges the semantic state SSR(t) to the engineered geometry of the TS manifold, enabling stable, inspectable, and reusable cognitive structures.

### 3. Input Specification (informative)
RSG consumes:
- SSR(t) — the current Semantic State Representation
- Manifold geometry tables (basins, coordinates, attractors)
- Object basin definitions
- Relational basin definitions
- Coordinate mapping functions
- Projection metadata

RSG does **not** consume realization plans, stylistic metadata, seeds, truth/safety flags, or surface-form instructions.

### 4. Transfer / Process Specification (informative)
RSG performs the following deterministic steps:
1. SSR(t) → manifold lookup
2. Object basin identification
3. Relational basin mapping
4. Coordinate computation
5. Attractor alignment
6. Geometric projection into realization-ready structures

The process produces manifold-anchored geometric meaning structures with no surface-form operations, no seed variability, and no meaning mutation.

### 5. Output Specification (informative)
RSG outputs:
- Manifold coordinates
- Object basin IDs
- Relational geometry structures
- Attractor alignment scores
- Projection metadata
- Geometric realization structures for RG
- rsg_status
- reason_code

No output_text, tone/style metadata, or surface-form fields are produced.

### 6. High-Level Requirements (normative)

**HLR-20.30.085-001**  
RSG SHALL map SSR(t) into the engineered TS manifold using predefined geometry tables.

**HLR-20.30.085-002**  
RSG SHALL identify and retrieve appropriate object basins for elements in SSR(t).

**HLR-20.30.085-003**  
RSG SHALL compute relational basin mappings between identified objects.

**HLR-20.30.085-004**  
RSG SHALL calculate deterministic manifold coordinates for the current state.

**HLR-20.30.085-005**  
RSG SHALL perform attractor alignment and produce projection metadata.

**HLR-20.30.085-006**  
RSG SHALL output only geometric structures suitable for RG; it SHALL NOT perform any surface-form generation, stylistic variation, or lexical assembly.

**HLR-20.30.085-007**  
RSG SHALL operate deterministically with no seed-based variability.

**HLR-20.30.085-008**  
RSG SHALL abort and return appropriate reason_code if manifold lookup or mapping fails.

**HLR-20.30.085-009**  
RSG SHALL not modify SSR(t) or write back any state.

**HLR-20.30.085-010**  
All RSG outputs SHALL be fully traceable to manifold coordinates and basin definitions.
