## Entries

### Path A (Meaning Construction) — Process Block
**Path:** A  
**Purpose:** Constructs meaning deterministically from raw input, producing the authoritative TP for the turn.  
**Focus:** Input-side primitives and OB-set routing cycles until Truth/Done stabilizes the turn-final TP.  
**When:** Runs every input cycle until completion at OuBA.  
**Why:** Ensures meaning is built deterministically, replayably, and independently of realization.  
**Is not:** A realization pipeline; a truth evaluator; a generator of surface text.  
**Upstream primitives:** InB → IIInB → IE → CEx → CE → ISc → TPU → OB family → SSG → TR → RB → IdOB.  
**Downstream primitives:** OuBA → Truth/Done → CTP → Path B (if Done).  
**Normative home:** 20.705.

### Path B (Realization & Expression) — Process Block
**Path:** B  
**Purpose:** Realizes the finalized TP into surface-form output without altering meaning.  
**Focus:** LI-prm → MLI → REx → RPlan → RPU → ReB → OuBB; seed-isolated expression mapping.  
**When:** Runs after OuBA commits meaning.  
**Why:** Ensure expression is deterministic, replay-stable, truth/safety-aware, and consistent with Path-A meaning.  
**Is not:** A meaning writer; a semantic interpreter; a truth evaluator.  
**Upstream primitives:** OuBA → CTP → TPTB/TPSF/CoHI → SRP.  
**Downstream primitives:** REx → RPlan → RPU → ReB → OuBB → HC-Flow.  
**Normative home:** 20.111, 20.705, 20.30.080.

### Clarification Path (Path C) — Process Block
**Path:** Clarification  
**Purpose:** Resolve surface-level ambiguity, missing information, or user-intent gaps before meaning construction.  
**Focus:** Clarification prompts, missing-slot resolution, user-intent disambiguation.  
**When:** Selected at InB when ambiguity is high but resolvable without inference or Discovery.  
**Why:** Prevent premature meaning construction when user intent is unclear.  
**Is not:** Inference Path; Discovery Path; automatic meaning construction.  
**Upstream primitives:** InB → IIInB → IE.  
**Downstream primitives:** Path A (after clarification), or IB-Creation-Request (if unresolved).  
**Normative home:** 20.705.

### Inference Path (Path D) — Process Block
**Path:** Inference  
**Purpose:** Apply bounded, deterministic inference when meaning cannot be constructed directly from input.  
**Focus:** Local inference rules, missing-slot inference, bounded hypothesis expansion.  
**When:** Selected at InB when ambiguity requires inference but not Discovery.  
**Why:** Provide deterministic inference without invoking IB or governance.  
**Is not:** Clarification Path; Discovery Path; unbounded inference.  
**Upstream primitives:** InB → IIInB → IE → CEx → CE → ISc.  
**Downstream primitives:** Path A (if inference resolves), or IB-Creation-Request (if MI_INCOMP persists).  
**Normative home:** 20.705.

### Supervisory Processes (Cross-Pipeline Control) — Process Block
**Path:** Cross  
**Purpose:** Provides deterministic supervisory control for mismatch detection, correction gating, and nondeterminism boundaries.  
**Focus:** IMR evaluation, CorrectionTrigger, IB-Creation-Request, MB observation, Random Seed Boundary.  
**When:** Concurrent with or immediately after Path A/B events.  
**Why:** Ensure bounded, auditable correction and prevent unsafe escalation.  
**Is not:** A meaning writer; a realization primitive.  
**Upstream primitives:** OuBA, Truth/Done, ISc (for IMR), MB, Random Seed Boundary.  
**Downstream primitives:** TB, GBIB, GB, IB (if approved).  
**Normative home:** 20.17, 20.30, 20.45, 20.70, 20.207.

### Post-TS Processes (TB → IB → GBIB → GB) — Process Block
**Path:** Governance / Discovery  
**Purpose:** Executes the Interpretive Basin Chain after Path B to evaluate ambiguity, truth, safety, and governance outcomes.  
**Focus:** TB truth-state evaluation, IB inquiry analysis, GBIB governance filtering, GB final outcome.  
**When:** Runs only after Path B completes and a stable TP/MTP commit exists.  
**Why:** Ensure ambiguity handling and governance outcomes are deterministic, auditable, and policy-aligned.  
**Is not:** A meaning writer; a realization primitive.  
**Upstream primitives:** OuBB → CTP.  
**Downstream primitives:** TB → IB → GBIB → GB → HC-Flow (long-term updates).  
**Normative home:** 20.80.

### Four-Path Model (TS Processing Paths) — Process Block
**Path:** Core  
**Purpose:** Enforce four distinct, non-overlapping TS processing trajectories.  
**Focus:** Normal Path (A), Realization (B), Clarification (C), Inference / Discovery (D).  
**When:** Path chosen at InB based on ambiguity state and governance signals.  
**Why:** Ensure deterministic routing and isolate clarification, inference, and long-term analysis behaviors.  
**Is not:** Merged pipeline; semantic generator.  
**Upstream primitives:** InB (path selection).  
**Downstream primitives:** Path A, Path B, Clarification Path, Inference Path.  
**Normative home:** Architecture discussion.

### Truth/Done — 20.140
**Path:** A  
**Purpose:** Provides the explicit completion-detection gate that terminates a processing cycle.  
**Focus:** Terminal evaluation over truth_hypotheses and done_state.  
**When:** At the OuBA boundary.  
**Why:** Prevent runaway processing cycles.  
**Is not:** IMR satisfaction; IB resolution.  
**Upstream primitives:** OuBA, ISc (truth_hypotheses), TPU (if correction applied).  
**Downstream primitives:** IB-Creation-Request (if MI_INCOMP), Path B (if Done), Governance (if ambiguous).  
**Normative home:** 20.140.

### truth_hypotheses-prc — 20.44
**Path:** A  
**Purpose:** Provide a deterministic, bounded scoring procedure for ISc.  
**Focus:** Apply local truth-pattern rules to candidate_set{} using CE.  
**When:** Invoked only inside ISc during Path-A inference.  
**Why:** Enable deterministic candidate scoring without global state or TB.  
**Is not:** Truth evaluator; TB; global inference engine.  
**Upstream primitives:** CE, candidate_set{}, ISc.  
**Downstream primitives:** ISc scoring fields → TPU (if correction triggered).  
**Normative home:** 20.44.

### MLI (Meaning-Layer Inference) — Process Block
**Path:** B  
**Purpose:** Performs deterministic, non-neural reasoning over the meaning state before realization.  
**Focus:** Rule-based meaning-layer transformations inside LI-prm.  
**When:** At the start of Path B, after TP/MTP commit.  
**Why:** Ensure semantic reasoning is deterministic and auditable.  
**Is not:** A primitive; a basin; neural inference.  
**Upstream primitives:** CTP, LI-prm.  
**Downstream primitives:** REx, RPlan.  
**Normative home:** 20.111.

### IB-Creation-Request — 20.17, 20.30
**Path:** Supervisory  
**Purpose:** Trigger supervisory-queue evaluation before any IB instantiation.  
**Focus:** Supervisory signal requesting GB approval for Discovery path.  
**When:** Emitted on MI_INCOMP.  
**Why:** Prevent automatic inquiry escalation.  
**Is not:** IB state; automatic inquiry.  
**Upstream primitives:** Truth/Done, OuBA.  
**Downstream primitives:** TB → GBIB → GB → IB (if approved).  
**Attached to:** Truth/Done (anchor).  
**Normative home:** 20.17, 20.30.

### HC-Flow (Historical Conversation Flow) — Process Block
**Path:** Cross / Post  
**Purpose:** Provide long-horizon conversational perspective by processing turn-final TP snapshots.  
**Focus:** Transform TP into conversation objects, referential history, and long-range inference via MTP → COB → CIL → CoHI.  
**When:** After OuBB finalizes the turn-final TP.  
**Why:** Maintain deterministic long-term continuity without Path B reading raw history.  
**Is not:** Meaning-construction flow; truth evaluator.  
**Upstream primitives:** OuBB → CTP.  
**Downstream primitives:** COB, CIL, CoHI, long-term memory structures.  
**Normative home:** 20.705.
