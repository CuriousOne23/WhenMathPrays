# 10.50.2700_COB Requirements (Canonical)

## 1. Purpose

This document is the canonical Conversation Object Basin (COB) requirement anchor for promotion-governed COB lifecycle behavior.

## 2. Canonical HLR Set

- `HLR-20.031-003`: COB identity must preserve stable ID, lineage, merge/split history, deprecation state, and lifecycle state.
- `HLR-20.031-010`: Replay evidence export must be deterministic and mode-specific.
- `HLR-20.031-014`: Ordering-critical COB behavior must derive from deterministic sequence/token state only.
- `HLR-20.031-016`: Profile overlaps must resolve by execution-signature-bound profile precedence over environment defaults.
- `HLR-20.031-018`: Unsupported COB feature/profile/enum states must follow deterministic reject-with-audit behavior using fixed reason codes.
- `HLR-20.031-024`: COB lifecycle transitions must occur only at deterministic safe boundaries.

## 10.50.2700.TCU COB CPU Execution Cycle Requirements

### 10.50.2700.TCU.10 Bounded per-tick cost
- Requirement ID: 10.50.2700.TCU.10
- Statement: For any tick with fixed input cardinality N and fixed configuration, the subsystem
  MUST complete its work within a bounded number of CPU cycles C_max(cob) per tick phase,
  as constrained by 20.150. No unbounded or data-dependent worst-case growth is permitted.

### 10.50.2700.TCU.20 Deterministic behavior under fixed conditions
- Requirement ID: 10.50.2700.TCU.20
- Statement: For fixed seed, fixed input cardinality N, fixed configuration, and fixed hardware/runtime profile,
  the subsystem MUST exhibit deterministic CPU cycle consumption within
  [C_min(cob), C_max(cob)] for the same scenario ID, as defined in 20.150.

### 10.50.2700.TCU.30 Provisional vs measured budgets (promotion-controlled)
- Requirement ID: 10.50.2700.TCU.30
- Statement: The subsystem MUST maintain two distinct TCU budgets:
  - provisional-budget(cob): design-time estimate used for planning and scheduling.
  - measured-budget(cob): empirically measured values produced by 40_playground harnesses and verified in 30_verification capsules.
  These MUST NOT be conflated in normative documents.
  measured-budget(cob) MAY ONLY be updated through promotion-controlled evidence from 30.

### 10.50.2700.TCU.40 Tick budget share
- Requirement ID: 10.50.2700.TCU.40
- Statement: The subsystem MUST declare its target percentage of the global tick budget
  (per 20.150) as a provisional-budget(cob) value, and MUST be verifiable against
  measured-budget(cob) from 30_verification capsules.
