# Meaning group generation rules

How to add a `group_id` without pretending the six axes are finished science.

## A group is

- an integer name (`group_id`)
- a six-float prototype in \([0,1]^6\) (physicality … spatiality)
- a gloss
- optional nested unit bags (11 may ignore units)

## May add when

- a speaker-object contrast the current groups collapse
- the contrast is consequential (would change Δh on intended pairs)
- the prototype is not a duplicate of an existing group under a new id

## Must also

- list the new id only on map rows that should see it
- keep rank ⊆ map
- not put structure IDs inside the prototype

## Convict later

Idle axis, locked pair of axes, or two intended-distinct objects on one \(M\) → revision of groups or axes (`idob_stability_contract.md`).
