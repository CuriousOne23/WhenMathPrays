# Structure to meaning (crossing)

Long form: bench `idob_s2m_theory.md` and `idob_s2m_constructs.md`.  
If this file and the bench disagree, the bench wins.

## Stake

Language can be represented geometrically **for machine realization** as two instruments:

- **Structure** — combinatorial landscape (six IDs + key). What road the utterance is on.
- **Meaning** — six-axis stand-in of the speaker’s **intended projection**. Not listener uptake.

The map is a **door** (membership): this key may birth these `group_id`s. Rank only orders that set.

## Feel (rigorous enough to argue)

Structure is the landscape the utterance must travel.  
Meaning is the thought-object the utterance proposes to put on the table.  
The utterance is the carrier; it is not that object.
