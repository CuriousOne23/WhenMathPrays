# Bench walk 10 — which line to edit

**Look at:** the dictionary line, not a new theory.  
**Next:** [11_shut_door.md](11_shut_door.md)

Climb in order. Skipping a rung makes the next one look like a rename.

Payback is real only when before and after both exist: same utterance, freeze unchanged or explicitly extended, `registry_digest` changed, `act=1` or claim keys changed, replay still clean.

## Rung A — see the switch

No new world. Write the legacy fire rule beside `activation: {}` for the three teaching sentences. Payback: you can see why `locative` woke for *The book is on the table.* and why it did not wake for *The sky is blue.*

## Rung B — fill the card you already have

Move the legacy predicate into `activation`. Put the segment shapes it actually reads into `association.geometries` (live files use `[]`). Payback: the IdOBObject becomes a dictionary a paper can diff. Coverage of the five families does not grow. Resolution becomes inspectable.

## Rung C — bind notes the structure side already wrote

Prefer this over a new primitive. Conversation Space Exerciser rows already cue negation, imperative, request, coordination, conditional, fragment, first person, passive, quantifier, exclamative. The catalog does not yet own those notes as data.

Work: a claim key or `selected_op` on an existing card, plus a closed overlap edge, then the existing gate (runner, log, debugger, no packet-shape drift). Payback: those conversations stop being "Constraint Observation Block saw it, Identity Observation Block shrugged."

A new file is allowed here only when no current card may speak the force. Bare *Close the door.* must not be pretended into `copular_state`.

## Rung D — a new IdOBObject only under R6

A new YAML file, a family that is not a stolen sentence label, priority, near and far, contribution schema limited to keys it will actually write. First try on *The cat chased the mouse.*: fill `agent_action` and stop calling the result residual if the packet is actually an action claim. A new object is the later move if residual-family keeps mislabeling it. Cost: every existing sentence must still replay.

## Rung E — add a structure function only if the signed form cannot see the shape

Do not modify the Structural Observation Block through the Semantic Observation Block because the packet feels thin. Add there when the circle, the hat, the fit, or the scene is absent.

You will see the miss on the left column of the on-switch page. *She said the book is on the table.* has a reporting clause the current alphabet does not own. Adding only a YAML file cannot see a chunk no primitive wrote.

## How a miss looks

No circle: rung E. Circles exist and no stamp is on: rung A, B, or C. A stamp is on and the line you care about is absent: resolution, rung C or D. The card is complete and you want a coordinate: rung on the next page, not an IdOBObject hole.
