# Bench walk 7 — two clerks

**Look at:** initials if both clerks handled the same traveler.  
**Name:** object adjacency. `overlap.near` / `overlap.far`.  
**Next:** [08_stamped_card.md](08_stamped_card.md)

False image: words sitting next to each other, or a scene.  
On the bench: a note on the stamp card. If another named stamp also fires, the sum has a pair to record.  
Nearest picture: two clerks who must initial each other's work if both handled the same traveler.

Say which adjacency you mean.

1. String adjacency: circles next to each other. Structural Observation Block, Constraint Observation Block.
2. Basin adjacency: one picture. Semantic Observation Block.
3. Object adjacency: edges between stamp cards. This page.

*Locative* declares near `mixed_descriptive`. *Copular_state* declares near `locative`. Declaration is not the event. The event is written when both stamps are on, as `overlap_events` on the packet. Live overlap handling may record the pair and still leave `fields` empty. Do not pretend the initial already names a contested key.

*Where is the book that is on the table?* can show all three at once: *book* touches the relative clause; book and table stay one picture; more than one stamp can be on.

Mixed interrogative is overlap, not a seventh family.
