## Stage 2 purpose

Identify the minimum experimental dimensions and coverage needed to support a meaningful structural-confidence judgment about Category Selection before proceeding to the next TS development stage. Exhaustive characterization of Category Selection space is not the objective.

## 2A: Candidate Dimension Map

Nine candidate dimensions worth controlled challenge:

1. Source composition  
2. Category identity  
3. Competition  
4. Inventory composition  
5. Representability / support boundary  
6. Construction variation  
7. Source compatibility of probes  
8. Same-category cue combination  
9. Binary perturbations with known direction

## 2B: Classification

| Dimension | Experimental status | Research function |
|-----------|---------------------|-------------------|
| Source composition | Established local axis | Geometry/response axis |
| Category identity | Plausible axis requiring exploration | Structural-generalization test |
| Competition | Discrete control | Geometry/response axis + Boundary/edge test |
| Inventory composition | Discrete control | Structural-generalization test |
| Representability / support boundary | Later-stage research question | Boundary/edge test |
| Construction variation | Plausible axis requiring exploration (or robustness check) | Robustness/invariance test |
| Source compatibility of probes | Not presently controllable as independent dimension | Probe qualification constraint |
| Same-category cue combination | Not presently controllable | Later-stage research question |
| Binary perturbations with known direction | Discrete control | Robustness/invariance test |

Source composition is the single established local axis.

## 2C: Minimum Meaningful Coverage

Core confidence skeleton:

1. Ordered response (source-composition axis)  
2. Structural generality across categories (category identity)  
3. Competition (controlled multi-directional condition; discrete challenge is sufficient)  
4. Robustness to probe realization (construction variation and source compatibility as controls)  
5. Edge pressure (representability/support-boundary cases)

Inventory composition is retained as a strong optional architectural-generalization candidate but is not required in the minimum first coverage set.

Same-category cue combination and binary punctuation are not required for the minimum set.

No arbitrary numerical targets.

## 2D: Palette Requirements

The palette must be capable of expressing:

- At least one major with clean dual-source cues realizing the three-point source-composition contract under fixed controls.  
- Additional majors capable of the same or equivalent controlled contract.  
- More than one qualified lexical realization per major where practical.  
- At least two well-qualified category directions that can coexist for controlled competition.  
- Alternate constructions/scaffolds that preserve intended evidence while changing surface form.  
- Intentionally selected boundary-adjacent cases (clean, limited, unmapped, eventually inadequate).  
- (Optional) Inventory add/remove/substitute via data with informative observation.

Each requirement is labeled by expected fulfillment path (existing qualified content, new research/configuration content, unknown until inspection, potential capability gap). No capability gap was identified by the requirements themselves.

## 2E: Coverage Gap Map

| Required challenge | Gap type |
|--------------------|----------|
| Ordered response | Already possessed (initial `cold`); strategically addable (scaffolds) |
| Cross-category generality | Present but qualification-limited (physical); strategically addable (new dual-source content) |
| Competition | Present but qualification-limited; strategically addable (cleaner pairs) |
| Robustness to probe realization | Strategically addable |
| Edge pressure | Strategically addable |
| Inventory composition | Already possessed for data path; measurement-limited but not a capability gap |

## Stage 2 closeout

No demonstrated Category Selection capability gap. Stage 3 therefore remains closed/optional.

The present palette is insufficiently broad for the desired confidence program. The missing coverage is presently understood primarily as a research-content and qualification problem, not a mechanism limitation.

Stage 4 is authorized to construct the role-qualified palette against these requirements.

## Non-claims

This record does not:

- characterize Category Selection space  
- establish global axes  
- establish general evidence strength  
- select the final vocabulary or category inventory  
- establish that future characterization will never reopen Stage 3
