# Path A program — current face and intended face

**Date:** 2026-10-08
**Scope:** `pathA_short_sim` only.
**Does not implement.** The runner is unchanged by this page.

This page is the program agreed for this directory. Older notes that describe only the sum, or that call Structure-to-Meaning (S2M) a permanent shut door, are describing the current realization. They are not a law that Identity Observation Block (IdOB) can never map.

## Current realization

```
SOB → SROB → CnOB → SmOB
        structure floor
              │
              ▼
            IdOB
         sum of activated cards
              │
              ▼
         idob_packet
    meaning this path can claim today
```

Structural Observation Block (SOB), Structural Refinement Observation Block (SROB), Constraint Observation Block (CnOB), and Semantic Observation Block (SmOB) are writers in a fixed order. A later writer may use an earlier record. It may not reopen the cut to satisfy a claim the hearing already made.

IdOB, today, sums what that floor bound. The `idob_packet` is that sum. On this path, today, that packet is the meaning that may be claimed. If nothing bound, the legal result is no packet.

## Intended face, not running

IdOB was the mapping primitive from the start of the concept. The mapping is not what the runner does yet.

```
SOB → SROB → CnOB → SmOB → IdOB(S2M)
Meaning := mapped output over the composed floor
```

The packet remains the legal composition the mapping must consume. The mapping may not invent a segment, a label, or a constraint the floor did not write. Cognitive Identity Envelope (CIE), Meaning Signal Layer (MSL), and the vector \(M\) are not imported into the sum in this phase. The other bench, `testbenches/idob_structure_to_meaning/`, remains evidence. It is not a second home for the job, and it is not the parent of this note.

## Mechanics beside the floor

RBU, RB, TR, RTU, and CTP are mechanical routing. They are not the parent of SOB. They do not create the structural theory.

CTP exists so a parallel IdOB pass can leave residue for the next IdOB object to chew. That is a routing fact. It is not a structural stage.

Truth-Relation Update (TRU) may write `tru_hint`. It must not clobber a completed IdOB mood. Meaning Composition Block (MCB) is omitted. STPX and DCB are omitted. Those omissions are current realization, not the structure floor.

## What "synced" means

A reader of this directory can say all of the following without opening a second, conflicting note:

- The floor is SOB through SmOB.
- Meaning today is the packet.
- Meaning later is the mapped output of IdOB, after the ready line.
- Mechanics sit beside the cut.
- Unsupported forms stay named.
- S2M does not print yet.
