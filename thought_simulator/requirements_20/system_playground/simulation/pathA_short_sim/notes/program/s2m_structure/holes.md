# Holes

**Date:** 2026-10-08
**Status:** what the mapping does not know. Not an inference.

Front door: [README.md](README.md).

A hole is a written item. If it is not written, the report has failed, even when the claim string looks complete.

A hole is one of these.

- An asked relation whose endpoint is empty. *The sky is zyzzyx* has a theme and no state. The state relation is `missing`.
- An utterance with no packet objects. `LLhfds pw Ppen qqoubx&` has a neighborhood hole and no supported connection.
- A asked preference with no basis. This pass does not write that as a status. It is named in [pressure.md](pressure.md) if two supported relations stand and neither is preferred.

A hole is not a hidden object. The mapping does not fill it from grammar, from a likely word, or from an earlier utterance.

Two lists are required for every utterance. Supported connections. Holes. A pass that returns only the first list has inferred by omission.
