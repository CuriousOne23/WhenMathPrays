## Explicit boundary

Characterization observes and exercises the category-selection realization.

It does **not**:

- create a competing category-selection path,
- create a competing meaning path,
- define the final no-category decision function,
- define a threshold,
- define hysteresis,
- establish experimental results,
- authorize implementation in placeholder form.
