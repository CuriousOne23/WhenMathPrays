# token_classes.yaml

## Schema

```yaml
token_classes:
  <token>: <class>
```

## Current Mapping

- `the` -> `DET`
- `quick` -> `ADJ`
- `brown` -> `ADJ`
- `fox` -> `NOUN`
- `jumps` -> `VERB`
- `over` -> `PREP`
- `lazy` -> `ADJ`
- `dog` -> `NOUN`

## Usage

Used by segmentation logic to recognize lexical class runs that can satisfy segment templates.
