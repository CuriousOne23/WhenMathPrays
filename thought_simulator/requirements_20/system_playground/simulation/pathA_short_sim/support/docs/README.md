# PathA Short Simulation Support

This directory contains dictionary-driven support assets for the PathA short simulator.

## Contents

- `dictionaries/`
  - `token_classes.yaml`
  - `segment_patterns.yaml`
  - `role_patterns.yaml`
  - `constraint_rules.yaml`
  - `semantic_rules.yaml`
- `docs/`
  - `user_guide.md`
  - `token_classes.md`
  - `segment_patterns.md`
  - `role_patterns.md`
  - `constraint_rules.md`
  - `semantic_rules.md`
  - `primitive_dictionary_map.md`

These assets are loaded by primitives in `primitives_pathA_short.py` to build structured parsing and semantic extraction behavior.
