# Slide 00 — Contract

## Objective

Learn the wall before any numbers move.

IdOB sits on a three-layer cut:

1. **Structure** — meaning-blind geometry (upstream).
2. **Meaning** — six-float vector + identity envelope (IdOB).
3. **Truth / belief** — not this bench (OuBA and after).

If a field crosses the wall silently, later traces become unreadable.

## This slide must do

- Name every field used in later slides (`vocabulary.md`).
- Show the minimal packet shape (`idob_object_min.yaml`).

## This slide must not do

- Compute hashes, scores, or meaning_delta_h.
- Rank groups or apply CIE.

## Boundary to feel

Structure objects do not contain `physicality` ... `spatiality`.
Meaning objects do not rewrite `semantic_field_id` ... `subfield_id`.
