# Six fields (this instrument layout)

These are axes of one vector, not six dictionaries.

**physicality** — physical objects, bodily action, tangible events.
High: walk, push, rock, burst (physical). Low: idea, permission, belief.

**sociality** — social interaction, groups, interpersonal roles.
High: negotiate, crowd, family. Low: rock, sleep, temperature.

**temporality** — time, events, change, duration, sequence.
High: burst, transform, schedule. Low: object, shape, color.

**intentionality** — intention, agency, purpose, volition.
High: decide, plan, aim. Low: fall, break, melt.

**materiality** — substance, composition, material transformation.
High: melt, freeze, carve, build. Low: think, believe, negotiate.

**spatiality** — location, path, spatial relation.
High: beside, across, near. Low: emotion, belief, permission.

This list is this instrument layout. Changing membership of the list is a new machine revision.
