# Structure to Meaning: Theory Stake (Path A / IdOB)

**Status:** Unproven stake. Architects the machine; the machine does not prove the theory.
**Companion:** [idob_s2m_constructs.md](idob_s2m_constructs.md) (construct cards + glossary).
**Bench:** testbenches/idob_structure_to_meaning/
**Date:** 2026-08-27

## 1. What this paper is

Path A is being built around a theory of how structure meets meaning. The code and YAML already use the names. This paper states the theory those names are supposed to realize.

The theory can be wrong. It must be clear enough to walk around, convict, and revise. That is the point of a research vehicle.

This paper does not claim Path A is cognition. It claims Path A is architected as a crossing from meaning-blind geometry to a representable speaker meaning-object.

## 2. The stake (one paragraph)

Meaning, for this theory, is a structured internal object a speaker puts forward with an utterance; it is significant insofar as such an object can change later cognitive state in a person who takes it up. Path A does not model the listener's uptake and does not claim to be a person's meaning-object. It represents the speaker's meaning-object with named axes and a measurable change delta_h inside a machine-defined space. Structure is the meaning-blind geometry that makes that object admissible. Identity may pressure the stand-in object; it may not rewrite structure. Freeze must say why the object stopped moving. The six axes are the current hypothesized primitive basis of the stand-in—the kinds of consequence we know how to name and route—and are revisable if traces show collapse, dead axes, or distinctions the layout cannot carry.

## 3. What the theory asserts

1. An utterance is a carrier, not the meaning-object.
2. Structure is geometry, not content. It decides which meaning-objects are legal to compete. It does not score the six meaning axes.
3. Meaning is the speaker's object, not the listener's formed uptake. The listener is only the reference that makes consequence a real kind of significance in human life.
4. Consequence is the significance test, not a Path A measurement of a person.
5. Path A does not infer hidden motive, deception, speech-act force, or truth. Intent here means the structured object the speaker is advancing.
6. Identity is local pressure on the stand-in speaker-object (CIE), not a life-story and not listener uptake.
7. Progressive crossing: structure -> admissible groups -> chosen prototype M -> identity pressure -> logged delta_h -> named freeze.
8. Observability: keys, candidates, M, delta_h, stop reason. That is the duck for this vehicle.

## 4. What the theory refuses

- Equating the packet with a mind.
- Putting meaning scores inside the structural key.
- Letting CIE change the structural key.
- Calling a budget halt stable.
- Claiming the six axes are proven orthogonal, minimal, or complete.
- Claiming word-to-score is already a formula (group prototypes are assigned in this revision).
- Claiming four toy structure cards prove conversation coverage.

## 5. Why a crossing must exist

If structure already contained meaning, IdOB would only copy a score.
If meaning had no structure, every group would be legal.
If identity rewrote geometry, replay would die.
If freeze had no name, instrument limits would pose as meaning.

IdOB is the first machine site where the speaker-object is allowed to appear, given only structure.

## 6. How the theory would fail (revision, not shame)

- Distinct speaker-objects land on the same M -> layout too coarse.
- An axis never moves across intended contrasts -> axis idle.
- Two axes always move together -> suspected non-orthogonality.
- delta_h spikes only from CIE/budget leak -> instrument error.
- Most ordinary utterances cannot take a usable structure card -> six-ID stake too thin now.
- Near-neighbors that should differ collapse to one key -> discrimination failure.

Failed check: new named machine revision, not a silent retune.
