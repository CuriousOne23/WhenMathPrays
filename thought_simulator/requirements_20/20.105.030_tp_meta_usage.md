# ⭐ **20.105.030 TP Metadata Usage — CCR‑Aligned, Deterministic, Replay‑Safe**  
**Document ID:** 20.105.030  
**Version:** 1.0  
**Date:** 2026‑08‑06  
**Status:** Active — CCR, Semantic‑Importance, and CIL Usage Aligned  

---

# **1. Purpose**

This document defines how downstream primitives **consume** metadata fields within the Thought Packet (TP).  
Metadata usage ensures:

- deterministic meaning refinement  
- stable routing  
- consistent truth‑relation mapping  
- coherent identity continuity  
- correct CCR decision consumption  
- correct COB projection behavior  
- correct CIL substrate continuity  
- deterministic replay across all Path‑A primitives  

This document normatively extends **20.105_tp_requirements.md** and **20.105.010_tp_meta_fields.md**.

---

# **2. Scope**

This specification covers:

- downstream consumption rules  
- read‑only constraints  
- usage boundaries  
- meaning‑refinement dependencies  
- structural and routing dependencies  
- CCR‑aligned usage  
- semantic‑importance usage  
- CIL substrate usage  
- semantic‑residue usage  

It does **not** redefine metadata fields or provenance rules.

---

# **3. Metadata Usage Model**

Downstream primitives consume metadata fields produced upstream.  
Consumption is **read‑only**, except where a primitive is explicitly authorized to update a specific field.

Metadata usage supports:

- identity‑conditioned meaning refinement  
- truth‑relation mapping  
- structural interpretation  
- routing‑conditioned semantics  
- entropy trajectory evaluation  
- conversation‑layer continuity  
- CCR decision consumption  
- COB projection  
- CIL substrate continuity  

---

# **4. Important TP Layers (Usage Perspective)**

- **Intake Layer** — normalization and repair observations  
- **Structural Layer** — geometry and constraint residue  
- **Routing Layer** — arbitration and pathway decisions  
- **Meaning Signal Layer (MSL)** — qualifiers, clarifications, stance, shading, intent, direction, coherence, subculture  
- **Continuity Layer** — identity anchors, referent lineage, clarifying metadata  
- **Semantic‑Importance Layer (NEW)** — bounded semantic residues  
- **CCR Output Layer (NEW)** — alignment, scores, decision, selected conversation  
- **Semantic‑Residue Alignment Layer (NEW)** — CCR residue alignment  
- **CIL Substrate Layer (NEW)** — selected conversation, CIL reference  
- **Entropy & Trajectory Layer** — stability and change over time  

These layers enable precise, traceable consumption by downstream primitives.

All TP fields MUST be emitted and consumed using canonical nested paths.
Flattening is a primitive-local operation and MUST NOT modify the TP envelope.

---

# **5. Normative Requirements**

Downstream primitives SHALL treat all metadata fields as read‑only unless explicitly authorized to update a specific field.  
**HLR‑20.105.030‑001**

Downstream primitives SHALL preserve upstream metadata observations without modification.  
**HLR‑20.105.030‑002**

IdOB SHALL consume expressive_metadata, normalization_metadata, and structural_metadata for identity‑conditioned meaning refinement.  
**HLR‑20.105.030‑003**

TR SHALL consume structural_metadata, routing_metadata, and expressive_metadata for truth‑relation mapping.  
**HLR‑20.105.030‑004**

IdOB and TR SHALL consume routing_metadata for identity‑conditioned and truth‑conditioned interpretation.  
**HLR‑20.105.030‑005**

OuBA SHALL consume entropy_metadata when producing the SSR‑A snapshot.  
**HLR‑20.105.030‑006**

COB, CIL, and CST SHALL consume continuity_metadata for identity continuity and stability evaluation.  
**HLR‑20.105.030‑007**

Downstream primitives SHALL NOT re‑derive upstream observations already encoded in metadata fields.  
**HLR‑20.105.030‑008**

Metadata usage SHALL support deterministic replay.  
**HLR‑20.105.030‑009**

# **6. Clarifying‑Field Consumption**

IdOB SHALL consume clarifying‑field metadata for identity‑conditioned meaning refinement.  
**HLR‑20.105.030‑010**

TR SHALL consume clarifying‑field metadata for truth‑relations requiring identity continuity.  
**HLR‑20.105.030‑011**

OuBA SHALL consume clarifying‑field metadata for SSR‑A snapshots requiring identity continuity.  
**HLR‑20.105.030‑012**

COB, CIL, CST SHALL consume clarifying‑field metadata for continuity and stability evaluation.  
**HLR‑20.105.030‑013**

Downstream primitives SHALL treat clarifying‑field metadata as read‑only unless explicitly authorized to update clarifying importance or topology.  
**HLR‑20.105.030‑014**

Clarifying‑field metadata usage SHALL support deterministic replay.  
**HLR‑20.105.030‑015**

# ⭐ **7. Semantic‑Importance Usage (NEW)**

Semantic‑importance fields:

```
TP.semantic.importance.entities[]
TP.semantic.importance.facts[]
```

SHALL be consumed by:

- **CEx‑CCR** — for semantic‑residue alignment  
- **COB** — for projection into CIL  
- **CIL** — for continuity and lineage updates  
- **CST** — for stability evaluation  
- **IdOB** — for identity‑conditioned meaning refinement  
- **RBU / RB** — for routing influenced by importance roles  

**HLR‑20.105.030‑017**

All other primitives SHALL treat semantic‑importance as read‑only.  
**HLR‑20.105.030‑018**

Semantic‑importance usage SHALL support deterministic replay.  
**HLR‑20.105.030‑019**
