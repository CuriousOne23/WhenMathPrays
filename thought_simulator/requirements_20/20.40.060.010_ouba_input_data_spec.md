# **20.40.060.010 — OuBA Input Data Specification (Option‑C Rewrite)**  
**Document ID:** 20.40.060.010  
**Version:** 2.1 (Structural Optimization + TP‑Field Update)  
**Status:** Normative — Data Specification  
**Scope:** Defines the **OuBA input object** and the **TPSnS output object** (TP Snapshot State).  
**Excludes:** Path‑A semantics, Path‑B semantics, realization substrate, TPTB/TPSF, COB behavior logic, CST alignment logic.  

---

# **0. Informative Overview (No SHALLs)**

OuBA is the **final freezing primitive** of Pipeline A.  
It receives a **verbatim TP snapshot** and produces the **TPSnS**, the immutable meaning‑state consumed by:

- COB  
- CST  
- Path‑B  
- governance, replay, audit  

TPSnS is the **authoritative frozen TP state**.  
OuBA performs **no semantic inference**, **no routing**, **no structural recomputation**, and **no mutation** of TP fields beyond freezing them into TPSnS.

This document defines:

- the **OuBA input object schema**  
- the **TPSnS output object schema**  
- commit‑time invariants  
- fidelity rules  
- deterministic replay requirements  

---

# **1. Purpose (Informative)**

The purpose of this specification is to:

- define the **exact structure** of the OuBA input object  
- define the **exact structure** of the TPSnS output object  
- define **normative fidelity rules** for commit  
- ensure deterministic, auditable, reproducible meaning transfer from Path‑A → COB → CST → Path‑B  

This document does **not** define:

- truth determination  
- safety determination  
- realization behavior  
- Path‑B routing  
- COB behavior logic  
- CST alignment logic  

---

# **2. OuBA Input Object (Normative)**

OuBA receives a **frozen TP snapshot** at the end of Pipeline A.  
This snapshot is a **pure data object**, not a semantic engine.

## **2.1 Input Object Fields (Normative)**

The OuBA input object SHALL contain the following **verbatim TP fields**:

### **Semantic Envelope**
- `TP.semantic.semantic_core`
- `proposition_set[]`  
- `truth_evidence[]`  
- `completion_state`  
- `TP.semantic.semantic_tags[]`  
- `TP.semantic.lane_local_identity`  
- `TP.metadata.messy_input_record`  

### **Epistemic**
- `TP.metadata.delta_h_percent`  

### **Trace**
- `ob_trace[]`  
- `tb_trace[]`  

### **Policy**
- `policy_markers[]`  

### **Context Envelope (COB‑required)**
- `TP.next_context.topic`  
- `TP.next_context.stance`  
- `TP.next_context.intent`  
- `TP.next_context.register`  
- `TP.next_context.politeness`  
- `TP.next_context.epistemic_shading`  
- `TP.next_context.continuity`  
- `TP.next_context.direction`  
- `TP.next_context.coherence`  
- `TP.next_context.shift_required`  
- `TP.next_context.importance`  
- `TP.next_context.clarifying_fields[]`  

### **Provenance (COB‑required)**
- `TP.lineage_log[]`  

### **Identity‑Layer Snapshot (CST‑required)**
- `TP.cob_state_snapshot`  

### **Commit Metadata (COB/CST‑required)**
- `TP.metadata.contextual_alignment_record`
- `TP.metadata.identity_shift_record`
- `TP.metadata.topic_anchor_record`
- `TP.metadata.continuity_record`
- `TP.metadata.intent_record`

### **HLR‑20.40.060.010‑001 — Input Object Integrity**  
OuBA input **SHALL** be a verbatim, immutable copy of TP fields at commit time.  
No transformation, normalization, or recomputation is permitted.

---

# **3. TPSnS Output Object (Normative)**

TPSnS is the **TP Snapshot State**, the frozen meaning object consumed by COB, CST, Path‑B, governance, replay, and audit.

TPSnS SHALL contain the following fields:

### **Identifiers**
- `tpsns_id`  
- `commit_timestamp`  
- `commit_hash`  
- `routing_epoch_id`  

### **Semantic Envelope**
- `TP.semantic.semantic_core`
- `proposition_set[]`  
- `truth_evidence[]`  
- `completion_state`  
- `TP.semantic.semantic_tags[]`  
- `TP.metadata.messy_input_record`  
- `TP.semantic.lane_local_identity`  

### **Epistemic**
- `TP.metadata.delta_h_percent`  

### **Trace**
- `ob_trace[]`  
- `tb_trace[]`  

### **Policy**
- `policy_markers[]`  

### **Context Envelope (COB‑required)**
- `TP.next_context.*`  
(all fields listed in Section 2.1)

### **Provenance**
- `TP.lineage_log[]`  
- `sob_id, srob_id, cnob_id, smob_id, idob_id`  
- `routing_path`  
- `ruleset_ids[]`  
- `TP.metadata.entropy_history[]`  
- `TP.metadata.signature_history[]`  

### **Identity‑Layer Snapshot (CST‑required)**
- `TP.cob_state_snapshot`  

### **Commit Metadata (COB/CST‑required)**
- `TP.metadata.contextual_alignment_record`
- `TP.metadata.identity_shift_record`
- `TP.metadata.topic_anchor_record`
- `TP.metadata.continuity_record`
- `TP.metadata.intent_record`

TPSnS SHALL NOT contain:

- realization fields  
- truth tags (TPTB)  
- safety flags (TPSF)  
- Path‑B routing structures  
- global meaning stores  

### **HLR‑20.40.060.010‑002 — TPSnS Immutability**  
TPSnS SHALL be immutable once produced.

### **HLR‑20.40.060.010‑003 — TPSnS Completeness**  
TPSnS SHALL contain **all** fields listed in Section 3.  
No field may be omitted, elided, or lazily populated.

# **4. Commit‑Time Rules (Normative)**

Commit occurs when Path‑A completes meaning construction.

## **4.1 Deterministic Commit**

Commit SHALL be deterministic given:

- TP state  
- seed  
- OB/TB/IB traces  
- policy markers  
- context envelope  
- provenance envelope  

### **HLR‑20.40.060.010‑004 — Deterministic Commit**  
OuBA SHALL produce identical TPSnS output given identical TP input and identical seeds.

---

## **4.2 ΔH% Commit Rule**

### **HLR‑20.40.060.010‑005 — ΔH% Fidelity**  
TPSnS SHALL preserve `delta_h_percent` exactly as computed in TP.

---

## **4.3 Completion State Commit Rule**

### **HLR‑20.40.060.010‑006 — Completion Fidelity**  
TPSnS SHALL preserve `completion_state` exactly as computed in TP.

# **6. Routing Metadata (Normative)**

TPSnS includes a `routing_epoch_id` used by Path‑B, COB, and CST.

### **HLR‑20.40.060.010‑014 — Routing Epoch Determinism**  
`routing_epoch_id` SHALL be deterministically derived from commit‑time metadata.
