## 1. Purpose

State who may **write**, who may **read**, and what is **forbidden**, so testbenches can convict a leak without re-reading every primitive file.

Behavioral detail stays in the owning document. This file only locks the wall.

**HLR-20.116.020-001**  
A primitive SHALL write only the envelopes it owns in §2. All other listed envelopes SHALL be treated as read-only or forbidden as specified.

**HLR-20.116.020-002**  
A testbench that writes across a wall in §2 SHALL be treated as measuring machine leakage, not Path A cognition-space visibility (`20.15` §12.2).

## 3. IdOB authorized-write restatement

Matches `HLR-20.105-116` / `HLR-20.40.050-063`. Restated here so the catalog can be cited alone.

**HLR-20.116.020-003**  
IdOB-prm SHALL be permitted to write only: `TP.idob`, `TP.semantic.meaning_delta_h`, root `idob_complete` / `path_b_eligible` / `ready_for_ouba`, and (when foundation export is enabled) `TP.metadata.identity.*` plus export aliases `TP.semantic.idob_semantics[]` / `TP.semantic.meaning_semantics[]`. IdOB-prm SHALL NOT write `process.routing_filter`, DCB `geometric_state`, structural/SSG maps, `pack_ids[]`, or `TP.next_context{}`.

**HLR-20.116.020-004**  
MCB-prm SHALL NOT overwrite `TP.idob` or IdOB `meaning_delta_h`. IdOB-prm SHALL NOT require MCB in order to write the packet.

**HLR-20.116.020-005**  
CST-Mux SHALL deliver `unified_stability_packet` only to CIL. COB SHALL NOT consume USP.

**HLR-20.116.020-006**  
IdOB-prm SHALL be the sole writer of `TP.semantic.importance`. SOB, SROB, CnOB, and SmOB MAY retain local envelope importance only and SHALL NOT write `TP.semantic.importance`.

## 4. Official live stretch (pointer only)

Writer scheduling for identity-conditioned meaning follows 20.705 §2 as written (do not substitute a shorter chain). The neighborhood that reaches IdOB on that string is:

```
TR → CTP → RB → IdOB
```

The longer excerpt `WrdNm → ISc → RTU → TR → CTP → RB → IdOB → MCB → RBU` is a pointer into §2, not a replacement for §2. Authority: `20.705` §2, `20.15` §3, and `20.40.050-062`. Isolation fixtures remain authorized by `20.40.050-053`.
