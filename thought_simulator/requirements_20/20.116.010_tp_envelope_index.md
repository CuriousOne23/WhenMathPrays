## 1. Purpose

List every **top-level envelope** used by Path A with:

- canonical nested path
- authorized writer
- primary source document for field *contents*
- notes (aliases, isolation, freeze)

Nested children stay in the source document. This index locks the **root path** so structural programs do not grow a second tree.

**HLR-20.116.010-001**  
Structural programs and testbenches SHALL use the paths in this index as the only legal envelope roots for the objects named here.

**HLR-20.116.010-002**  
A primitive SHALL write only the roots it owns in §2. Writes to any other root listed here SHALL be treated as a catalog violation.

## 3. Runtime resolver note

Runtime resolvers treat paths **relative to the TP root**. Architecture text may write `TP.cst.core`; resolvers use `cst.core`. Both spellings name the same envelope.

**HLR-20.116.010-003**  
A leading `TP.` prefix in architecture text SHALL be treated as identical to the same path relative to the TP root.
