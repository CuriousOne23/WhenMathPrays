## 1. Purpose

732 says what Intake is.

733 says how a human classifies a sentence into $\{F?, A?, H\}$ without minting structure.

Seed `place()` is lookup, not a general translator. This note does not replace `place()`. It tests the mapping that *feeds* `place()`.

$$
u \mapsto \{F?,\, A?,\, H\}
$$

$H = 1$ whenever $F?$ is unresolved, $A?$ is unresolved, line-kinds are mixed, or $u$ is not an exact Seed gold replay.

## 2. Cue table (grammar → family candidate only)

Cues emit candidates. Two cues that pull two families → hole. No priority ladder.

| Cue (condition only) | $F?$ candidate | Not |
|---|---|---|
| Completed occurrence / change-of-state verb with no interrogative | `event_talk` | meaning of the event |
| Copula + time or condition word, assertion shape | `state_talk` | a calendar ontology |
| Imperative or explicit work-item frame, no question mark | `task_talk` | a to-do product |
| Stance / consider-this frame (`claim`, `true`, `false`) with no question mark | `claim_talk` | a belief axis |
| Interrogative mark or ask-verb (`can`, `did`, `what`) as the line-kind | `ask_talk` | an information need as meaning |
| Explicit update marker (`update:`, `now:` as revision of prior line) | `update_talk` | a log product |
| `If` and `But` in the same $u$ | none | a parser rule |
| `And` joining two different line-kinds | none | a conjunction calculus |
| Two rows of this table both fire | none | a winner-take-all parse |

`relation_talk` stays omitted.

---

## 3. Domain-group table (world category → about candidate only)

World groups never force an `about_id`. Only Seed About Index may appear as $A?$.

Seed About allow-list:

- `material_event_anchor`
- `timed_obligation_anchor`
- `person_load_anchor`

| World grouping (human observer) | $A?$ candidate (never forced) | Otherwise |
|---|---|---|
| Material change / concrete occurrence | `material_event_anchor` | $A?$ unresolved → $H=1$ |
| Timed obligation / deadline-as-state | `timed_obligation_anchor` | $A?$ unresolved → $H=1$ |
| Sustained personal burden | `person_load_anchor` | $A?$ unresolved → $H=1$ |
| Science, arts, politics, sports, family, nature, history, other | none in this revision | $A?$ unresolved → $H=1$ |

World tokens stay in the utterance column. They do not enter `structural_key`, `$M$`, family inventory, or six IDs.

## 4. Predicates

Exactly four. No fifth.

| Predicate | When it holds | What it may write |
|---|---|---|
| known placement | $u$ is an exact Seed gold replay and 731 already records a placement | nothing new; cite gold only |
| unresolved about | $A?$ is missing or not in Seed About | hole row only |
| unresolved family | $F?$ is missing, mixed, or omitted (`relation_talk`) | hole row only |
| hole-required | any unresolved field, mixed cues, off-gold $u$, or Gold 3 | hole row; `card_id` stays null |

Off-gold $u$ cannot be “known placement.” Seed `place()` is lookup.
