# **20.48.010_knc_prim.md — KnC Primitive Specification**

## **1. Introduction**

The **Knowledge Coarse Primitive (KnC)** is the first grounding stage in the TS knowledge pipeline.  
It operates immediately after **OuBA** has produced the initial SSR‑K projection and before **KnM** and **KnF** refine grounding further.

KnC performs **coarse grounding**, attaching broad, high‑confidence lexical and categorical knowledge to the SSR datastream. This grounding is intentionally coarse, providing TS with a safe, deterministic fallback abstraction tier for Path B expression and entropy‑conditioned routing.

KnC is the **lowest‑precision, highest‑entropy** grounding stage, but it is also the **most stable** and **least ambiguous**, ensuring TS always has a valid grounding baseline.

---

## **2. Purpose**

The purpose of KnC is to:

- attach **coarse identity**, **coarse relations**, **coarse domain anchors**, and **coarse qualifiers** to SSR‑K,
- compute **coarse grounding entropy** $H\_{Kn_{coarse}}$,
- populate the **coarse abstraction tier** for Path B,
- provide deterministic grounding even when Path A projection is incomplete or ambiguous,
- interface with the grammar‑atomic **KnDt** to retrieve coarse lexical entries,
- prepare SSR‑K for deeper grounding by KnM and KnF.

KnC ensures TS always has a **safe, generic grounding tier** available for expression or surgical questioning.

---

## **3. Discussion of the KnC Block**

KnC is the **first grounding primitive** in the KnB pipeline:

```
Path A → KnC → KnM → KnF → Path B
```

KnC reads the SSR datastream produced by Path A and extracts:

- identity keywords  
- relational keywords  
- domain anchor hints  
- qualifier hints  
- semantic tags  
- proposition fragments  

KnC then queries **KnDt** using these coarse lexical indicators.  
KnDt returns **grammar‑atomic entries**, which KnC attaches to SSR‑K in the **coarse tier fields**.

KnC does **not** perform:

- contextual disambiguation,  
- fine identity resolution,  
- deep truth validation,  
- multi‑hop grounding,  
- semantic inference.

KnC is intentionally shallow and deterministic.

KnC also computes:
  
$$
H_{Kn\_{coarse}} = 1 - \frac{precision_{coarse}}{max\_{precision}}
$$
  
This entropy value is used by Path B to determine whether coarse expression is appropriate or whether surgical questioning is required.

---

## **4. Field Definitions**

### **4.1 Fields Read from SSR**

KnC reads the following SSR fields:

- `proposition_set[]`  
- `semantic_tags[]`  
- `lane_local_identity`  
- `truth_evidence[]`  
- `messy_input_record`  
- `KnDt_keywords[]` (if present)  
- `KnDt_addresses[]` (if present)  
- `policy_markers[]`  
- `delta_h_percent` ($H_{SSR}$)

These fields provide the lexical and semantic cues required for coarse grounding.

### **4.2 Fields Written to SSR‑K**

KnC writes the following fields:

- `identity_coarse[]`  
- `relation_coarse[]`  
- `domain_anchor_coarse[]`  
- `qualifier_coarse[]`  
- `truth_validation_coarse[]`  
- `H_Kn_coarse`  
- `Kn_level = "KnC"`  

These fields form the **coarse abstraction tier** consumed by KnM, KnF, and Path B.

---

## **5. Interface to KnDt**

KnC interfaces with **KnDt (Knowledge Database)** using:

- `KnC_REQUEST`  
- `KnC_RESULT`  
- `KnC_VALIDATE`

KnC performs the following steps:

1. Extract coarse lexical indicators from SSR.  
2. Issue a `KnC_REQUEST` to KnDt.  
3. Retrieve grammar‑atomic entries via `KnC_RESULT`.  
4. Validate grounding using `KnC_VALIDATE`.  
5. Write coarse grounding fields into SSR‑K.  
6. Compute $H\_{Kn_{coarse}}$.

KnDt returns:

- coarse identity anchors  
- coarse relational primitives  
- coarse domain anchors  
- coarse qualifiers  
- coarse truth‑validation primitives  

KnC does not modify KnDt and does not perform multi‑hop queries.

---

## **6. SHALL Requirements (HLRs)**

### **Identity Grounding**
- **HLR-20.48.010-001** — KnC **shall** attach `identity_coarse[]` entries derived from grammar‑atomic identity anchors returned by KnDt.  
- **HLR-20.48.010-002** — KnC **shall** write coarse identity grounding only; it shall not attempt medium or fine identity resolution.

### **Relation Grounding**
- **HLR-20.48.010-003** — KnC **shall** populate `relation_coarse[]` using coarse relational primitives retrieved from KnDt.  
- **HLR-20.48.010-004** — KnC **shall** avoid contextual disambiguation when attaching coarse relations.

### **Domain Anchors**
- **HLR-20.48.010-005** — KnC **shall** populate `domain_anchor_coarse[]` using broad domain categories from KnDt.  
- **HLR-20.48.010-006** — KnC **shall** not refine domain anchors beyond coarse categorization.

### **Qualifiers**
- **HLR-20.48.010-007** — KnC **shall** attach `qualifier_coarse[]` entries representing broad descriptive features.  
- **HLR-20.48.010-008** — KnC **shall** not attach medium or fine qualifiers.

### **Truth Validation**
- **HLR-20.48.010-009** — KnC **shall** populate `truth_validation_coarse[]` using coarse truth‑validation primitives.  
- **HLR-20.48.010-010** — KnC **shall** not perform deep truth validation.

### **Entropy**
- **HLR-20.48.010-011** — KnC **shall** compute $H\_{Kn_{coarse}}$ using the formula:
  
$$
H_{Kn\_{coarse}} = 1 - \frac{precision_{coarse}}{max\_{precision}}
$$
  
- **HLR-20.48.010-012** — KnC **shall** write `H_Kn_coarse` into SSR‑K.

### **SSR‑K Update**
- **HLR-20.48.010-013** — KnC **shall** set `Kn_level = "KnC"` in SSR‑K.  
- **HLR-20.48.010-014** — KnC **shall** not overwrite medium or fine fields.

### **Pipeline Behavior**
- **HLR-20.48.010-015** — KnC **shall** operate deterministically and shall not perform inference.  
- **HLR-20.48.010-016** — KnC **shall** prepare SSR‑K for KnM and KnF without altering Path A fields.

## **7. Use by Future TS Blocks**

### **KnM**
KnM reads:

- `identity_coarse[]`  
- `relation_coarse[]`  
- `domain_anchor_coarse[]`  
- `qualifier_coarse[]`  

KnM uses these as **starting points** for medium grounding.

### **KnF**
KnF uses coarse grounding as a **fallback** when medium grounding is ambiguous.

### **Path B**
Path B uses:

- `identity_coarse[]`  
- `relation_coarse[]`  
- `domain_anchor_coarse[]`  
- `qualifier_coarse[]`  
- `truth_validation_coarse[]`  
- `H_Kn_coarse`

Path B selects coarse expression when:
  
$$
H_{total} = H_{SSR} + H\_{Kn_{coarse}}
$$
  
exceeds the coarse‑expression threshold.

### **Surgical Questioning**
If coarse grounding is too ambiguous, Path B uses coarse fields to generate targeted clarification questions.

---

## **8. Conclusion**

KnC is the foundational grounding primitive in TS.  
It attaches coarse, stable, deterministic knowledge to SSR‑K, ensuring TS always has a safe abstraction tier for expression and entropy‑aware routing. KnC interfaces with KnDt, computes coarse grounding entropy, and prepares SSR‑K for deeper grounding by KnM and KnF.

KnC is simple, deterministic, and essential for TS’s non‑LLM behavior.
