=== Design Numbering Alignment Plan ===
This script implements the uniform component numbering discussed for the
design layers (40, 30, 10.50, 50). 50.00-50.09 remain reserved for
50-series governance documents per 50.05.

POLICY: Nothing happens automatically. You may manually rename files or change
any internal names (module:, titles, references, etc.) to *anything* you want.
This script gives warnings/plans only by default and never auto-corrects or
auto-renames based on what it finds on disk. It only processes the explicit
entries you have added to RENAME_MAP in the CONFIG section at the top of this file.
File changes occur ONLY with explicit --apply --yes after you have reviewed the plan.

Planned file renames:
  50.09_geometry_engine_design.md  -->  50.10_geometry_engine_design.md
  50.50_data_structures.md  -->  50.55_data_structures.md

Files that will have content updated (in addition to any renames):
  50_thought_simulator_design\50.00_design_traceability_index.md
  scripts\align_design_numbering.py

Warnings / items requiring human review:
  - LLR identifiers embedded in frontmatter (e.g. LLR-50.09-001) will be updated
    to LLR-50.10-001 for the geometry file. Review that no external references
    (outside this repo or in historical docs) rely on the old LLR numbers.
  - The 50.00 index table will be updated automatically for the two rows.
  - Historical files like RENAMING_MIGRATION_REPORT.md are intentionally ignored.
  - **Python files (.py)**: String matches in code, comments, docstrings, or tests
    will be updated if they contain the old filename. These can have false positives.
    The script will list them prominently — review carefully before apply.
  - Titles: If an H1 or frontmatter title contains the old component number or filename,
    it will be caught by the string replacement (e.g. in links or explicit mentions).
  - After applying, run the full validation suite (see CONTRIBUTING_CHANGE_WORKFLOW.md).
  - Consider updating any external notes, old branches, or the 20-series if they
    hard-code the old 50.09 / 50.50_data names.
  - User guides, READMEs, and cross-layer references are included in the broad scan.

This was a dry-run. No files were modified.
Re-run with --plan for more detail, or --apply --yes after review.
