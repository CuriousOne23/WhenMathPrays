# 🤝 **CONTRIBUTING.md — Stewardship & Collaboration**

WhenMathPrays is a living system.  
It grows through curiosity, clarity, and care.  
If you want to contribute — whether through scenarios, tools, documentation, or research — this guide will help you understand how to participate.

---

# 🌱 1. Principles of Contribution

Contributions to WhenMathPrays should be:

- **Inspectable** — clear, readable, and easy to follow  
- **Minimal** — no accidental complexity  
- **Grounded** — aligned with the GRP recurrence and primitives  
- **Documented** — every change should help future stewards  
- **Reversible** — avoid breaking existing scenarios or tools  
- **Meaningful** — each addition should deepen understanding or capability  

If you’re unsure whether something fits, open an issue or start a discussion.

---

# 🧭 2. Ways You Can Contribute

### **A. Scenarios**
- Add new emotional arcs in `data/`  
- Ensure primitives are within valid ranges  
- Include timestamps and clear naming  
- Provide a short description in the PR  

### **B. Tools**
- Improve the Python cockpit  
- Add visualization helpers  
- Extend the Excel cockpit  
- Fix bugs or improve clarity  

### **C. Documentation**
- Clarify concepts  
- Add examples  
- Improve cross‑links  
- Expand the CONTENTS.md index  

### **D. Research & Validation**
- Stress tests  
- Edge‑case explorations  
- Empirical grounding  
- Comparative analysis  

---

# 🧪 3. Development Workflow

1. Fork the repository  
2. Create a feature branch  
3. Make your changes  
4. Add or update documentation  
5. Submit a pull request with a clear description  
6. A steward will review and discuss if needed
