# Lineage: ULep → UREP

This document preserves the editorial memory of WhenMathPrays, tracing the evolution from ULep to UREP.

## ULep (Love Equation of Presence)
- Defined relational intensity as love-specific orientation × magnitude.
- Anchored in emotional valence (positive/negative).
- Served as the seed for modular relational modeling.

## Transition Rationale
- ULep was too narrow: love-only, valence-bound.
- Needed a universal frame for relational intensity.
- Introduced cartesian averaging to prevent angle wrap artifacts.
- Removed valence bias → gates are neutral, nonnegative.

## UREP (Universal Relational Equation of Presence)
- Generalizes ULep into a universal relational framework.
- Orientation: γ_self(t, τ) as cartesian-averaged vector.
- Magnitude: W(t) as product of valence-neutral gates.
- Preserves modularity, interpretability, and stewardship ethos.

## Stewardship Notes
- ULep remains canonical as origin.
- UREP is the living vessel for expansion.
- Future stewards should annotate rationale for each transition.
