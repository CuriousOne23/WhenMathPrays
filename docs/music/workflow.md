# **3. Step‑by‑Step Generation Workflow**

## **Step 1 — Open `music_generation_prompts.md`**
Each section has a ready‑to‑paste prompt.

## **Step 2 — Paste a prompt into your AI music generator**
Do not modify the prompt unless you are fixing a violation.

## **Step 3 — Listen once for semantic correctness**
Check the output against:

- `instrumentation_overview.md` (semantic roles + constraints)  
- `instrumentation_overlay.md` (timeline)  
- `full_comp.md` (global architecture)

## **Step 4 — Reject outputs that violate the ontology**
Reject if the AI adds:

- drums  
- vocals  
- strings  
- rhythmic bass  
- arpeggiated pads  
- melodic marimba  
- aggressive sub‑bass  
- rhythmic woodblock  
- “build‑ups” or “drops”  

These break the semantic mapping.

## **Step 5 — Regenerate until correct**
Most sections generate correctly within 1–3 attempts.

## **Step 6 — Export the audio**
Use a consistent naming scheme:

```
section_00_abstract.wav
section_01_intro.wav
...
section_13_conclusion.wav
```

## **Step 7 — Assemble the full score**
Use any audio editor (Audacity, Logic, etc.):

- place sections in order  
- add **0.5–1.0 seconds** of silence between sections  
- do not crossfade unless the architecture calls for it  

The score should feel like a **conceptual progression**, not a continuous song.

# **4. Quality Control Checklist**

Before accepting a section, confirm:

### **Instrumentation**
- Only the allowed instruments appear  
- No extra layers  
- No rhythmic or melodic violations  

### **Semantic Role**
- Piano = agent  
- Marimba = relation  
- Pad = environment  
- Sub‑bass = embodiment  
- Airy synth = meaning  
- Woodblock = perturbation  

### **Regime Alignment**
Check `instrumentation_overlay.md` to ensure:

- correct instruments for the regime  
- correct transitions  
- correct density  

### **Dynamic Geometry**
Check `full_comp.md` to ensure:

- intensity matches  
- curvature matches  
- flow direction matches  

If any of these fail → regenerate.

# **5. Stitching the Full Score**

Once all 14 sections are generated:

1. Import all `.wav` files into an audio editor  
2. Arrange them in order  
3. Add **0.5–1.0 seconds** of silence between sections  
4. Normalize levels if needed (lightly)  
5. Export as:

```
architecture_of_dynamic_thought_score.wav
```

Optional: also export `.mp3` for lightweight sharing.

# **6. Troubleshooting**

### **The AI adds drums or vocals**
Regenerate.  
If it persists, add:  
“no drums, no vocals, no percussion, no rhythm section.”

### **The pad becomes rhythmic**
Add:  
“pad must be stable, non‑rhythmic, no pulsing.”

### **The marimba becomes melodic**
Add:  
“marimba must be structural, not melodic.”

### **The sub‑bass becomes punchy**
Add:  
“sub‑bass must be subtle, non‑rhythmic, non‑percussive.”

### **The airy synth becomes sharp**
Add:  
“airy synth must be soft, shimmering, non‑percussive.”

### **The generator changes the instrumentation**
Regenerate.  
Never allow substitutions.
